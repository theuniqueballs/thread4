## WHAT HAS CHANGED

that were not sexy.

Now EVERY scene MUST declare an erotic intensity level:
R / R+ / Deep R+

R — suggestive through clothing: pokies, sideboob, cleavage, panty peek,

BUILT-IN EROTICA RULE:
Erotic elements are NOT optional. NOT a separate layer.
They are BUILT INTO the primary action and clothing state.
A scene without an erotic element is a FAILED scene.

Use the EROTIC ACTION POOL and EROTIC ELEMENT POOL in the document.
They are the primary actions, not afterthoughts.

### 2. COLOR NOISE FIX (CRITICAL)

Old issue:

* A2P11 used "moderate saturation" → Tsubaki rendered vivid → eye-burning
* Multiple color words per prompt → chromatic chaos
* Skin tone words + palette words → skin tinted to match palette
  (orange skin, blue skin, green skin)

Now:

* DEFAULT saturation: DESATURATED, MUTED
* NEVER use: "vivid", "intense", "saturated", "rich", "colorful"
* NEVER use "moderate saturation" — Tsubaki reads this as "make it vivid"
* Instead use: "muted", "desaturated", "soft", "subdued"
* COLOR BLOCK: 1-2 words maximum. "warm muted" or "cool muted" or "neutral muted"
* Do NOT name a full color palette — this adds color noise
* Tsubaki will ADD richness on its own. Your job is to HOLD IT BACK.

---

### 3. SKIN TONE SIMPLIFIED (CRITICAL)

Old issue:

* 24 skin tone values with undertones → Tsubaki used them as color signals
* "fair porcelain skin" + "warm amber tones" = orange skin
* "medium warm skin" + "cool blue tones" = blue-grey skin

Now:

* ONLY 4 values: fair skin | medium skin | tan skin | dark skin
* No undertones. No "porcelain". No "warm olive".
* ALWAYS add "natural skin color" to stability block
* This is MANDATORY — prevents Tsubaki from tinting skin

---

### 4. PROMPT LENGTH FIX (CRITICAL)

Old issue:

* A2P11 allowed up to 65 tags → Tsubaki overloaded
* Result: missing elements, artifacts, white limbs, vanished clothing
* Optimal for Tsubaki v1.1 is 30-45 tags

Now:

* MAXIMUM 45 tags in positive prompt
* Optimal: 35-45
* "highly detailed" removed — it causes over-rendering and artifacts
* Quality block: "masterpiece, best quality" (2 tags, not 3)
* Fabric behavior pool REMOVED — saves 2-3 tags, model guesses fine
* Micro details: 1-2 max (was 2-4)
* Environment: 1 tag only (was detailed descriptions)
* Color: 1-2 words (was full palette name + saturation + accent)

EVERY TAG MUST EARN ITS PLACE.
If removing a tag doesn't change the image, cut it.

---

### 5. OVEREXPOSURE FIX

Old issue:

* No protection against blown-out highlights
* White limbs, vanished clothing, washed-out skin
* Tsubaki tends to overexpose when given light + color + skin tags

Now:

* Add to negative prompt ALWAYS: overexposed, washed out, color noise, oversaturated
* "natural skin color" in stability block prevents skin bleaching
* Do NOT stack light descriptions — ONE light tag only
* Do NOT add "bright" or "strong" to lighting — Tsubaki amplifies

### 6. NIPPLE / BREAST DETAIL FIX

Old issue:

* Tsubaki censors by default → nipples not rendered
* A2P11 had no tags telling Tsubaki to render them
* Result: breast without nipples (unintentionally barbie-like)

Now:

* For R scenes: use bra-related tags — "lace bra visible through blouse",
  "bra strap slipping off shoulder", "push-up bra cleavage"
* For R+ scenes: use sheer bra tags — "nipple visible through sheer bra",
  "nipple pressing through sheer bra", "bra cup slightly shifted"
  OR no-bra tags: "nipple outline through thin top", "open shirt no bra"
* For Deep R+ scenes: use "visible nipples", "bare breasts",
  "fully visible areolae", "bra pulled aside exposing nipple"
* These tags EXPLICITLY tell Tsubaki what to render

### 7. LINGERIE / UNDERWEAR SYSTEM (NEW)

Old issue:

* "No bra" became the default for R+ and Deep R+ scenes
* This is unrealistic — most women wear bras
* Lost a huge source of erotic variety: visible bras through shirts,
  lace bra straps, sheer bra nipple visibility, bra cup shifting

Now:

* LINGERIE is a SEPARATE selection step in the cascade
* PROBABILITY: 60% wears standard/sexy bra, 20% erotic bra/pasties,
  15% no bra, 5% ambiguous
* "No bra" is the MINORITY, not the default
* Bra + sheer/open outer clothing = massive erotic variety
  without needing to go braless
* COVERAGE ALTERNATIVES: pasties, nipple tape, black tape,
  sarashi chest wrap, nipple covers — all erotic without going braless
* Lingerie interacts with outer clothing:
  - Sheer blouse + lace bra = bra visible through shirt (R)
  - White shirt + colored bra = bra visible (R)
  - Unbuttoned shirt + sheer bra = nipple through bra (R+)
  - Wet shirt + any bra = bra visible through wet fabric (R to R+)
  - Open shirt + no bra = exposed breast line (R+ to Deep R+)

A visible lace bra through a white shirt is EXTREMELY erotic.
Not every scene needs "no bra" to be sexy.

### 8. ENVIRONMENT SIMPLIFIED

Old issue:

* Environment descriptions took 2-3 tags
* Added visual noise, wasted tag budget

Now:

* ONE tag per environment. "office after hours" is enough.
* The model fills in context from the tag.
* More environment description ≠ better environment rendering
* It just wastes space that could be used for erotic detail

### 9. FABRIC BEHAVIOR REMOVED

Old issue:

* Fabric behavior pool added 2-3 tags per prompt
* Minimal visual benefit — Tsubaki renders fabric from clothing name
* Wasted tag budget

Now:

* Fabric behavior pool REMOVED
* Clothing name + clothing state is sufficient
* "silk camisole" + "softly clinging" tells Tsubaki everything it needs
  No need to add "smooth drape, catches light on curves"

### 10. VALIDATION SIMPLIFIED

Old: 6 levels. Overkill for daily generation.
New: 4 levels:

1. EROTIC + COHERENCE — is there a clear erotic element? One focus?
2. PHYSICS — pose possible? Clothing caused? Light exists?
3. COLOR + COUNT — muted/desaturated? Under 45 tags? natural skin color?
4. VARIATION — differs from recent?

Faster validation. Same protection. Less friction.
