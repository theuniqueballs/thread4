## §62 FIRST-PASS (V21): культура фикс-пассов закрыта

Вердикт автора: «система пишет неправильно и чинит постфактум; pipeline
легализовал фикс-пассы как норму». N29-квиток: первый прогон house_lint
60 ошибок → 4 фикспасса → 0. Все 67 находок были ИЗВЕСТНЫМИ законами —
писец писал без них в операционной форме. Лечение структурное:
- **КОНТРАКТ**: `spine.py` эмитит `writer_contract` в spine JSON — все
  законы трёх органов, числа из их же констант (дрейф невозможен);
  ловушки N29 = `FIRST_PASS_TRAPS T1-T14`, каждая уже оплачена.
- **ЦЕЛЬ**: первый прогон линта = целевое состояние (FIRST_RUN_CLEAN);
  N30 — первый батч, так и градуируется. «правки → фикс» — инцидент.
- **ОПЛАТА**: случился фикс-пасс → root-cause в worklog + пункт контракта
  (ловушка → константа/строка контракта) — иначе та же ловушка куплена
  снова. Неплаченные фикс-пассы = долг, как рендер-долг.
- **ЛЕДЖЕР**: `system/LINT_RECEIPTS.tsv` — каждый настоящий прогон
  house_lint пишет рецепт (date/slug/run/sha10/errors); sha-дельта между
  прогонами = фикс-пасс; pipeline печатает §62-строку с вердиктом.

## Ритуал цикла (V21: контракт-фёрст, §62 FIRST-PASS)
1. `python scripts/spine.py compile n30` — спайн + **КОНТРАКТ ПИСЦА**
   (writer_contract в JSON: законы трёх органов; ловушки T1-T14) —
   читать ДО письма прозы
2. Правки законов → `system/` → `python scripts/export_system_md.py`
3. `python scripts/verify_system.py` — PASS обязателен
4. Письмо и сборка ПРОТИВ контракта; дельты → блок в `house_configs.yaml`
   (`python scripts/house_lint.py --contract n30` — контракт с конфигом)
5. `python scripts/house_lint.py --slug n30` — **ПЕРВЫЙ ПРОГОН: цель 0
   ошибок** (рецепт пишется в LINT_RECEIPTS.tsv — это и есть graded state)
6. `python scripts/pipeline.py n30` — все гейты разом + §62-строка
   (first-run вердикт · счёт фикс-пассов)
7. Если фикс-пасс случился — оплата §62(3): root-cause в worklog + пункт
   контракта (ловушка → константа/строка) — иначе покупка повторится
8. Сдано → worklog (Task ID по порядку); легаси-линты батча → archive/
