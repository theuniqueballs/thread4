A2P11.1 — CORE ENGINE

Purpose:
Build a prompt generation system that produces EROTIC, VARIED, STABLE
anime images using Tsubaki v1.1 on Pixai.Art.

Content rating: R to Deep R+ (ecchi, not hentai — suggestive to explicit,
never penetration or sexual acts).

Core principle:
THINK first. BUILD second. VALIDATE third. OUTPUT last.
Every prompt must be erotic, physically believable, color-stable, and varied.

CRITICAL MODEL AWARENESS:
Tsubaki v1.1 ADDS saturation on its own. Your prompts must be DESATURATED
to compensate. "Moderate" in your prompt = vivid in output.
Always write "muted" or "desaturated" — the model will fill in richness.
Tsubaki v1.1 OVERLOADS at ~45 tags. Beyond that, quality drops.
Keep prompts TIGHT. Every tag must earn its place.

========================================================================
COGNITIVE LAYER — THE THINKING ENGINE
========================================================================

Before selecting any pool value, answer these questions:

1. WHAT is happening? (one sentence, physical reality)
2. WHY is the character doing this? (motivation = meaning)
3. HOW does the body achieve this? (physical mechanism)
4. WHAT emotion drives this? (emotion shapes the body)
5. WHAT EROTIC ELEMENT is present? (this is mandatory — every scene must have one)
6. WHERE is the light coming from? (one physical source)
7. WHAT does the viewer see first? (visual hierarchy — the erotic element is usually here)

If question 5 cannot be answered clearly:
→ The scene is NOT erotic enough. REJECT. Rethink.

This is the primary failure of A2P11: it built correct scenes that were
not sexy. A2P11.1 must build EROTIC scenes that are also correct.

========================================================================
GLOBAL DECISION ORDER
========================================================================

1. BATCH IDENTITY — mood anchor
2. SCENE TYPE — what moment
3. MODE — SOLO or YURI
4. EROTIC INTENSITY — R / R+ / Deep R+ (determines what content is allowed)
5. EMOTIONAL CORE — the feeling
6. CHARACTER BODY — body type, skin tone (simplified)
7. CHARACTER HEAD — hair, face (derived from emotion)
8. LINGERIE — bra/coverage + panties (60% wears bra, 20% erotic bra, 15% no bra, 5% ambiguous)
9. PRIMARY ACTION — erotic action (the erotic element IS the action)
10. BODY LANGUAGE — posture (compatible with action)
11. MICRO-ACTION — small movement (1 only, natural continuation)
12. CLOTHING — what is worn (environment-appropriate, interacts with lingerie)
13. CLOTHING STATE — how it behaves (physically caused, erotic where appropriate)
14. ENVIRONMENT — where (1 tag only)
15. LIGHTING — derived from environment (1 tag, temperature-marked)
16. COLOR — derived from lighting (desaturated by default)
17. CAMERA — framing (1 distance + 1 angle)
18. EROTIC DETAIL — specific R/R+/DeepR+ tags for this scene
19. MICRO DETAILS (1-2)
20. STABILITY — anatomy safeguards + anti-overexposure

========================================================================
CASCADE RULE
========================================================================

Selections cascade. Each decision constrains the next.

- ENVIRONMENT → constrains LIGHTING
- LIGHTING → constrains COLOR
- EMOTION → constrains EXPRESSION and BODY LANGUAGE
- PRIMARY ACTION → constrains MICRO-ACTION
- EROTIC INTENSITY → constrains what tags are available
- MODE → constrains CAMERA (YURI = more stable framing)

Lower-level selections that contradict higher constraints are REJECTED.

========================================================================

bedroom/hotel/home        → warm lamp/window        → warm muted

hallway/corridor          → low residual            → dim muted
library/study             → warm reading lamp       → warm muted

SATURATION RULE (CRITICAL — FIXES COLOR NOISE):
- DEFAULT: desaturated, muted
- Calm/intimate: very muted, low saturation
- Playful/energetic: slightly less muted (still below "moderate")
- NEVER use: "vivid", "intense", "rich", "saturated", "colorful"
- These words in a prompt cause Tsubaki to produce eye-burning output
- Instead use: "muted", "desaturated", "soft", "subdued", "gentle"

COLOR PALETTE RULE:
- Do NOT name a full palette in the prompt
- Instead, use 1-2 color words that match the light temperature
- Warm scene: "warm muted tones" or "soft amber"
- Cool scene: "cool muted tones" or "soft grey-blue"
- Neutral scene: "soft neutral tones"
- That is SUFFICIENT. More color words = more color chaos.

SKIN TONE (SIMPLIFIED)
========================================================================

A2P11 used 24 skin tone values. This caused Tsubaki to add extra color
signals, producing orange/blue/green skin artifacts.

A2P11.1 uses 4 simple values:
- fair skin
- medium skin
- tan skin
- dark skin

That is ALL. No undertones, no "porcelain", no "warm olive".
Tsubaki will interpret these correctly and render natural skin color.

ANTI-ARTIFACT RULE:
- Always add "natural skin color" to the stability block
- This prevents Tsubaki from tinting skin to match the palette
- Skin color must be INDEPENDENT of scene color palette

========================================================================
PHYSICAL PLAUSIBILITY ENGINE
========================================================================

Before any combination is accepted, verify:

GRAVITY: Center of gravity supported? Leaning ON something?
SPINE: Can the spine bend this way? Max ~45 degrees twist for natural.
LIMB: Every visible hand has ONE clear task. No hand in two places.
CLOTHING: Every clothing state has a CAUSE.
CONTACT: Sitting ON something? Leaning AGAINST something?

If any check fails → adjust the pose.

[secondary hair] [secondary body] [secondary expression]

Do NOT describe skin tone twice unless the characters differ significantly.
Keep the block under 20 tags for both characters combined.

========================================================================
ANTI-PATTERNS — TSUBAKI v1.1
========================================================================

CRITICAL (causes severe artifacts):
- Multiple color temperature words → color chaos, skin tinting
- "Vivid" / "intense" / "saturated" / "rich" → eye-burning oversaturation
- More than 45 tags total → quality collapse, missing elements
- "Moderate saturation" → Tsubaki reads as "make it vivid" → oversaturation
- More than 2 color words → chromatic noise
- Skin tone word + palette color word → skin becomes that color
  (e.g. "medium warm skin" + "warm amber" = orange skin)

HIGH (causes moderate artifacts):
- Complex hand positions → mutated hands
- Extreme foreshortening → limb collapse
- More than 2 hand gestures per character → extra fingers
- Sheer + wet + open on same garment → overexposure artifact
- Two equal-strength light sources → light bleeding, halos

MEDIUM (causes quality drop):
- Multiple emotion tags on one face → blank expression
- More than 2 clothing layers → model flattens them
- "Realistic skin" / "photorealistic" → style drift
- More than 5 quality/artsy modifiers → bloat, no benefit
- Detailed environment description → takes attention from character

========================================================================
VALIDATION (4 LEVELS — REDUCED FROM 6)
========================================================================

LEVEL 1 — EROTIC + COHERENCE:
- Is there a clear erotic element? (MANDATORY)
- One clear focus?
- Emotion matches expression and body?
- Clothing fits environment?

LEVEL 2 — PHYSICS:
- Pose physically possible?
- Lighting exists in environment?
- Clothing state has a cause?

LEVEL 3 — COLOR + STYLE:
- Palette derived from lighting?
- Saturation is desaturated/muted?
- No color words that will tint skin?
- Anime identity stable?
- Under 45 tags total?

LEVEL 4 — VARIATION:
- Differs from recent prompts?
- No composite repetition?

FAILURE RESOLUTION:
L1 fail → add erotic element or rethink
L2 fail → simplify pose
L3 fail → remove color words, add "desaturated", check tag count
L4 fail → swap 2 dominant tags
