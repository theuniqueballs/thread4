# Prompt Renderer Physics (закон №28 «ПРОСВЕТ-ЧЁТКОСТЬ»)

## Зачем

Рендер (PixAI/Tsubaki2 → Yadayo) рисует соски через ткань гораздо охотнее,
чем декларирует заявка слота. Каждое расхождение ↑ (заявка R+, факт X) —
это не «модель постаралась», это **несуществующий канал доставки,
вписанный в промпт**. Закон №28 закрывает класс целиком.

## Канальная система (рецепт v1.9.0)

| Заявка | Канал доставки | Легален? |
|---|---|---|
| X (соски видны через ткань) | через-ткань любого рода | ДА — это и есть X |
| R+ бугорки (bumps, без цвета) | P30-коктейль: тёмная ткань + сухая ткань (dark garment + dry fabric) | ДА, только так |
| R+ соски цветом через светлую/мокрую ткань | — | НЕТ: nipples-through / wet-clothes / sheer — FORBIDDEN на R+ |
| Светлый/mid верх | каналов через-ткани НЕТ | bumps запрашивай только на тёмном и сухом |
| Купальник | исключение-золото P21 | ДА — единственный легальный «просвет» на R+ |

- **Кластер светлых ≤ 3**: не больше трёх подряд слотов со светлым верхом,
  иначе площадка сама дорисует просветы (вердикт T4-31: P25–P31 — цепочка X).
- **Салиенс-цепочка**: главный сигнал кадра должен совпадать с заявкой
  канала; если lead = chest на R+, в промпте обязан стоять P30-коктейль,
  а не sheer/wet.
- **Веса weights_raw легализованы** (0.8–1.2, максимум 3 слота на батч):
  вес поднимает существующий канал, но **канал весом не обходится** —
  если канала нет, 1.2 его не создаст.

## Pitfalls (собраны из вердиктов T4-26..T4-31, дословные уроки автора)

- **Белая ткань**: сосок «прям прорисован» — белое прозрачнее, чем кажется
  (T4-31 P04). На белом R+-бугорков не бывает.
- **Свитер**: «через свитер розовые соски вообще не могут просвечивать»
  (T4-31 P09) — плотная ткань = ноль каналов, честна только X-заявка.
- **Жёлтая кофта**: «сиськи через жёлтую кофту, которая не просвечивается»
  (T4-31 P12) — цветная непрозрачная ткань рисует соски красными = X.
- **Мокрая ткань**: wet-clothes на R+ — детонатор (T4-26..27): мокрое
  просвечивает всегда, заявляй X.
- **Чёрный сатин/майка**: тёмное + сухое = правильный bumps-фон
  (T4-31 P10 «хорошая сатиновая чёрная — эротично» — канал работает).
- **Мерная лента вокруг груди** (T4-31 P03): аксессуар-провокатор,
  площадка читает как X — не вписывай на R+.

## Как применять

1. Слот со заявкой R+ и lead chest/breasts → проверь: тёмная ткань? сухая?
   Нет → смени ткань или понижай заявку до R (без канала) / X (с каналом).
2. `fabric-lint` (команда) по собранному батчу — до сдачи, не после вердикта.
3. Каждый новый вердикт с расхождением ↑ по каналу → Pitfall сюда.
