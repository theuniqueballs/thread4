## Формула R+ — ГИПОТЕЗА, n=3, не изолирована (Кенни, Issue #29; вердикты T4-19/T4-20-EXP/T4-20)

> **R+ ≈ (конкретная физика ткани на теле) × (эротическая поза / действие / напряжение тела)**

Один множитель без другого = R или слабый R+. Подтверждается третьим батчем (T4-20: P13 цепи / P22 ремни / P23 кукольные нити — «скудно», «такое» — физика без заряда позы → PG-13; P02 ooze ↑1, P11 дождь, P21 гирлянды — ткань разоблачает → R+). Статус по Кенни: гипотеза с n=3 — переменные батчей не изолированы; для «измеренного факта» нужен EXP из 3–4 A/B-пар «тот же слот, с мусором и без». Проверено батчами:
- T4-19: поэзия без физики → R+ 2/14 («вообще ни о чём»).
- T4-20-EXP: физика без эротического намерения → «почти везде R» (позы аккуратные, стерильные).

Квадрант (из двух экспериментов):
- **физика + эротическое действие = R+** (цель);
- физика без эротики = R (SLIPPOINT);
- эротика без физики = лотерея PG-13–R (nipple outline ловушка T4-19);
- тема/окружение не двигают тир — не тратить на них бюджет внимания в R+.

**Побочный золотой результат**: чистый промпт без визуального мусора даёт самую чёткую прорисовку тела (вердикт: «девушки получились самые чётко-прорисованные»). Не возвращать декоративный мусор «для атмосферы». Excess-детали легальны, только если конвертированы в давление на тело.
