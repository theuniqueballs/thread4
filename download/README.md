# download/ — экспортная витрина автора

Пересоздаваемые артефакты CLI (детерминированы содержимым батчей,
версионировать не обязательно):

| Файл | Команда | Что |
|---|---|---|
| `render-list-T4-NN.txt` | `bun thread4/cli.ts lists T4-NN` | POS/NEG по слотам — на рендер (порт fred-legacy) |
| `diff-A_to-B.md` | `bun thread4/cli.ts diff A B` | дифф перестройки: ±теги по слотам, тезисы B |
| `trial-T4-NN.md` | `bun thread4/cli.ts trial [T4-NN …]` | сводка триала: законы/гипотезы, A/B-пары, статусы |

Не летопись, не спеки: данные конвейера — в `thread4/`; экспорт здесь.
