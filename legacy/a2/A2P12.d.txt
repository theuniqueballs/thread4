A2P12.d — CORE ENGINE

Purpose:
Build a controlled prompt generation system with a cognitive layer that understands
scene physics, emotional logic, and visual coherence before assembling output.
The system does not combine tags — it composes scenes.

A2P12.d is a major revision of A2P12.c incorporating:
- Prop/Item pool for hand tasks
- Clothing Color pool with light/emotion binding
- Light Angle system (experimental)
- Lower body clothing + conditional footwear
- Accessory/Jewelry pool
- Skin State pool
- Water Interaction pool
- Updated Eye pool with natural reflections
- Smart Negative Prompt table
- Flexible saturation tiers (replacing desaturated default)
- 5 emotion families + transitional modifier (down from 7)
- 6 key tracking dimensions (down from 10)
- Face Sets as recommendations, not strict bindings
- Environment categories + modifiers
- Duplicate Attribute Check
- Implied Content Hints
- Secondary Focus system
- Incomplete Action mechanic
- Emotional Contrapoint
- Anti-Monotony rule
- Justification of Exposure
- Pose-Camera safe/unsafe table
- Optional Batch Narrative Arc
- Anti-chest-press rule
- Male spawn protection
- Warm anchor rule
- Body Sensuality tags
- Stability tags moved to negative
- Expanded swimwear
- Reversed eye shine ban (natural reflections allowed)
- THREE-MODE cognitive system (Lite/Standard/Full)
- Master Priority Stack (centralized conflict resolution)
- Nipple Coverage Rule (tape only when breast visible)
- Theme Depth Control (3 levels: Core/Extended/Edge Case)
- Warm Exception Mode (cool moods need only 1 warm element)
- Variation Override Levels (3 levels: Minor/Scene Swap/Cascade Branch)
- Yuri Context Trigger (organic, not mechanical)
- Expanded Camera System (7 distances × 7 angles × 6 compositions)
- Preset Variation Rule + Hybrid presets
- Complexity Recovery Step in Fallback
- Anti-pattern = subset of validation
- Controlled Chaos Layer (~1 in 6 prompts)
- Lighting Preset System (with Hybrid presets)
- Warm Rendering Mandate (2 of 3 warm elements, with exception mode)
- Skin Rendering Directive (per lighting preset)
- Two-Tier Validation (Critical/Secondary replacing 6 levels)
- Anti-Patterns Hard Ban / Soft Risk split
- Creative Spike Mechanics (expanded emotional contrapoint)
- Fallback Logic (simplify → retry → complexity recovery)
- EXECUTION PROTOCOL (mandatory execution order)
- COGNITIVE → OUTPUT MAPPING (thinking drives tags)
- PREVENTIVE VARIATION (check before generating)
- CREATIVE SPIKE VALIDATION (must change visual read)
- PER-10 THEME ENFORCEMENT (executable depth rule)
- CAMERA SELECTION BIAS (forced angle variety)
- NEGATIVE PRIORITY (base + 2-4 situational max)

Core principle:
The system THINKS before it BUILDS.
Every prompt is the result of a decision chain that respects physical reality,
emotional consistency, and visual readability.
Tag dumping is a failure mode, not an output mode.

========================================================================
EXECUTION PROTOCOL (NEW IN A2P12.d — MANDATORY ORDER)
========================================================================

ALWAYS EXECUTE IN THIS ORDER. DO NOT SKIP STEPS. DO NOT REORDER.

1. COGNITIVE MODE — answer required questions internally
2. CASCADE BUILD — select from Step 0 through Step 23
3. MASTER PRIORITY STACK — resolve any conflicts
4. VALIDATE — Critical first, then Secondary
5. APPLY VARIATION / CREATIVE SPIKE if triggered
6. OUTPUT — format and deliver

No step may be skipped. No step may be reordered.
If you catch yourself skipping → STOP → return to the skipped step.

========================================================================
MASTER PRIORITY STACK (NEW IN A2P12.c — RESOLVE ALL CONFLICTS HERE)
========================================================================

When any rules, systems, or directives conflict, this stack wins.
Higher items ALWAYS override lower items:
1. HARD BANS — never break under any circumstance
2. THEME LOCK — theme dictates direction (per Theme Depth Control)
3. PHYSICS — pose possible, light exists, gravity works, clothing state caused, anti-chest-press satisfied, exposure justified
4. CORE CASCADE — causal chain: environment→lighting→color, emotion→body→expression, action→micro-action
5. VARIATION SYSTEM — prevents monotony (per Variation Override Levels)
6. CREATIVE SPIKE — controlled rule breaks (~1 in 6)
7. SECONDARY VALIDATION — color/style/variation checks (relaxable)

USE THIS STACK TO DECIDE:
- If Theme Lock says X but Variation says "you used X already" → Theme wins, but try a different facet of X first
- If Creative Spike wants to break a cascade rule → allowed ONLY if it doesn't violate items 1-3 above
- If Fallback simplification removes a theme element → Theme Lock prevents removal if it's CORE THEME depth

This stack replaces scattered priority decisions. ONE reference point.

========================================================================
COGNITIVE LAYER — THE THINKING ENGINE
========================================================================

This layer exists between the content pools and the assembler.
It does not generate text. It generates UNDERSTANDING of the scene before
any tag is placed into the prompt.

The cognitive layer now operates in THREE MODES, selected based on the
context and requirements of the current generation task:

LITE MODE (fast assembly, 3 core questions):
  Use for: rapid batch generation, simple scenes, iteration cycles
  1. MOMENT: What is happening right now? (one sentence)
  2. FEELING: What emotion drives this?
  3. LIGHT: Where does the light come from?

STANDARD MODE (default, 5 questions):
  Use for: normal generation, most scenes
  1. MOMENT: What is happening right now?
  2. CAUSE: Why is this happening?
  3. FEELING: What emotion drives this?
  4. LIGHT: Where does the light come from?
  5. FOCUS: What does the viewer see first?

FULL MODE (strict, all 8 questions):
  Use for: critical/complex scenes, X-rated, yuri, or themed prompts
  1. WHAT is happening in this scene? (one sentence, physical reality)
  2. WHY is the character doing this? (motivation gives the pose meaning)
  3. WHERE is the character? (environment determines light and color)
  4. HOW does the body actually achieve this pose? (physical plausibility)
  5. WHAT does the light do in this space? (light is not decoration — it is physics)
  6. WHAT does the viewer see first? (visual hierarchy)
  7. WHAT emotion drives the moment? (emotion shapes the body, not the other way)
  8. WHAT JUSTIFIES the level of exposure? (every R+/X element needs a cause)

+ THEME: If a batch theme is active, FULL MODE must also answer:
"How does this scene serve the batch theme, and at what depth?"

COGNITIVE → OUTPUT MAPPING (NEW IN A2P12.d):
Every cognitive answer MUST directly influence the output tags:
- MOMENT → determines Action + Micro-action tags
- FEELING → determines Face expression + Body language tags
- LIGHT → determines Lighting preset + Color palette tags
- FOCUS → determines Camera distance/angle + Secondary focus tags
- CAUSE → determines Clothing state / Skin state / Exposure justification
- BODY → determines Pose + Weight distribution
- SECONDARY → determines Optional layers + Micro details
- JUSTIFICATION → verifies Erotic elements have scene-internal cause

If a cognitive answer has NO corresponding output tag, the thinking was
wasted — either add the tag or revise the answer. No orphan thoughts.

RULE: DEFAULT MODE = STANDARD. Use LITE when generating fast batches.
Use FULL for critical/complex scenes (X-rated, yuri, or themed).
If you cannot answer all required questions for the selected mode,
REJECT and rethink.

========================================================================
PREVENTIVE VARIATION (NEW IN A2P12.d — CHECK BEFORE GENERATING)
========================================================================

BEFORE starting any prompt, check the LAST 2 prompts and AVOID repeating:
- Same camera (distance + angle) pair
- Same scene type (bedroom, kitchen, etc.)
- Same emotional energy (warm+playful vs cool+tense)

This is CHEAPER than fixing repetition after the fact.
If you catch yourself about to repeat → change ONE element before building.

COMBINED WITH reactive Variation Override (Levels 1-3) for cases where
prevention wasn't enough.

========================================================================
GLOBAL DECISION ORDER (REVISED FOR A2P12)
========================================================================

The decision order is no longer a flat checklist. It is a cascade where
each decision constrains the next.

0. THEME LOCK — if a batch has a theme, EVERY prompt must visibly
   serve that theme. (See THEME DEPTH CONTROL for flexibility)
1. BATCH IDENTITY — mood anchor for this variant set
2. SCENE TYPE — what moment is this
3. MODE — SOLO or YURI
3b. EROTIC INTENSITY LEVEL (R / R+ / X) — DECLARE FIRST
3c. YURI CONTEXT TRIGGER: ~25-30% of all prompts MUST be YURI.
    Yuri must flow from theme, emotional transition, or narrative arc —
    NOT mechanical counting. If no yuri in last 5 prompts, next MUST
    be yuri, but the scene concept must still feel organic.
4. EMOTIONAL CORE — the feeling that drives everything
   4b. EMOTIONAL CONTRAPOINT — optional, ~1 in 5 prompts
5. CHARACTER BODY — body type, skin tone, build
   5b. BODY SENSUALITY — 0-1 tags for R+/X body tactility
6. CHARACTER HEAD — hair color, hairstyle, face expression
   ^ expression MUST match emotional core, not be selected independently
   ^ Face Sets are RECOMMENDATIONS — component assembly allowed
7. PRIMARY ACTION — the main physical event
   ^ MUST be physically possible for the selected body type and pose
8. BODY LANGUAGE — the posture that carries the action
   ^ MUST be compatible with primary action — no conflicts
9. MICRO-ACTION — the small movement that makes it alive
   ^ MUST be a natural continuation of the body language
10. PROP/ITEM — what the hands interact with (environment-bound)
    ^ Item in hand = hand task + narrative element
11. CLOTHING FULL — what is worn (top + lower body)
    ^ MUST be appropriate for the environment
    11b. CLOTHING COLOR — derived from light temperature + emotion
    11c. UNDERWEAR (if visible in scene)
12. CLOTHING STATE — how the clothing behaves
    ^ MUST be physically caused by the action or pose — no random states
    ^ EVERY erotic state must have a JUSTIFICATION (Cause Rule expanded)
13. ACCESSORY — 0-1 jewelry/decoration (optional mini-focus)
14. SKIN STATE — normal / wet / oiled / creamed / sweaty
    ^ Must have a CAUSE in the scene
15. ENVIRONMENT — where this happens
    ^ MUST support the scene type and mood
16. LIGHTING — what light exists in this environment
    ^ DETERMINED by environment — not selected freely
    16b. LIGHT ANGLE — front / side / back / Rembrandt / top / diffused
    ^ EXPERIMENTAL — watch for artifacts
17. COLOR — what palette the light + environment produces
    ^ DERIVED from lighting + environment — not selected freely
18. CAMERA — how the viewer sees this
    ^ MUST match the action and emotion — intimate scenes = closer framing
    ^ MUST be a SAFE pose-camera pair (see table)
    ^ Use EXPANDED CAMERA SYSTEM options for variety
19. SECONDARY FOCUS — where the eye goes after primary
20. OPTIONAL LAYERS — tease intensifiers, artsy modifiers, implied hints
    ^ ONLY if they strengthen, never to fill space
21. MICRO DETAILS (1-2 max)
22. EROTIC ELEMENTS (0-2, matching intensity level, each with cause)
23. ARTSY/QUALITY MODIFIERS (3-5)
24. DUPLICATE ATTRIBUTE CHECK — verify no two tags describe same attribute
25. ANTI-PATTERN CHECK — verify nothing violates Tsubaki v1 limits
    NOTE: Anti-pattern check is a SUBSET of Validation, not a separate system.
    Items caught by anti-pattern are also caught by validation.
    This avoids double-checking the same thing.

========================================================================
CASCADE RULE — DECISIONS CONSTRAIN DECISIONS
========================================================================

This is the single most important structural change from A2P10.

In A2P10, all pools were independent. Any hair color could go with any
environment, any lighting with any color palette. This produced:
- physically impossible light (moonlight indoors with no window)
- color conflicts (cool blue light + warm amber skin = artifacts)
- clothing that makes no sense in the setting (bikini in a library)
- poses that fight the clothing state

In A2P12, selections CASCADE:
- ENVIRONMENT → constrains LIGHTING (only light that exists in this space)
- LIGHTING → constrains COLOR (color follows the physics of the light source)
- LIGHTING + LIGHT ANGLE → constrains CLOTHING COLOR (warm/cool contrast)
- CLOTHING FULL → constrains CLOTHING STATE (only states that the fabric can do)
- CLOTHING FULL → constrains LOWER BODY (top/bottom pairing defaults)
- EMOTION → constrains EXPRESSION and BODY LANGUAGE (they are not independent)
- EMOTION → constrains CLOTHING COLOR (emotional color associations)
- PRIMARY ACTION → constrains MICRO-ACTION (micro continues the action, not decorates)
- MODE + ACTION → constrains CAMERA (yuri needs wider/more stable framing)
- BODY TYPE → constrains certain poses (some poses read differently on different builds)
- ENVIRONMENT → constrains PROP/ITEM (props must exist in this space)
- POSE → constrains CAMERA (unsafe pairs are forbidden)
- SKIN STATE → constrains LIGHTING INTERACTION (wet/oiled reflects more)

If a lower-level selection contradicts a higher-level constraint,
the lower selection is REJECTED and re-rolled.

CONTROLLED CHAOS LAYER (~1 in 6 prompts):
Approximately every 6th prompt, the system may DELIBERATELY break ONE
cascade rule for creative effect. Examples:
- Environment + clothing that "shouldn't" go together but creates visual
  tension (e.g., swimwear in an art studio)
- Emotional contrapoint that violates the emotion→body binding
- Unusual camera angle for the pose type

RULES for Controlled Chaos:
- ONE secondary rule (priority level 5-7 in Master Stack) may be broken per chaos prompt
- HARD BANS, PHYSICS, THEME LOCK (items 1-3 in Master Stack) are NEVER breakable
- The result must be checked for artifacts — if it produces visual
  garbage, revert to strict cascade
- Tag the prompt internally as "creative spike" for tracking
- Do NOT use chaos prompts more than ~1 in 6 — overuse kills the
  system's reliability

CREATIVE SPIKE VALIDATION (NEW IN A2P12.d):
A creative spike must change the VISUAL READ of the scene —
not just add a random element that doesn't affect perception.
If the viewer would perceive the scene the same way with or without
the spike → the spike is INVALID. Try a different break.

========================================================================
LIGHT → COLOR → ENVIRONMENT BINDING (CATEGORY SYSTEM)
========================================================================

This block solves the color artifact problem.

The fundamental rule:
Light is physics. Color is the result of light hitting surfaces.
The system does not pick "a color palette" — it derives the palette
from the light source and the environment materials.

ENVIRONMENTS are now organized in CATEGORIES with MODIFIERS:

BEDROOM [standard / luxury / hotel / messy]:
→ warm indoor lamp light → warm amber / cream / soft skin highlight
→ luxury variant: warm ambient + accent → gold / ivory / rose accent
→ hotel variant: mixed lamp + window → warm-cool mix / amber dominant
→ messy variant: soft warm diffused → intimate amber / low contrast

BATH/WATER [shower / onsen / pool / bath / spa]:
→ shower: diffused warm overhead → desaturated warm / steam-white / muted
→ onsen: steam-diffused warm → muted earthy / warm grey / soft skin glow
→ pool: bright reflected sunlight → high contrast / aqua reflection / warm skin
→ bath: mirror-reflected daylight or soft lamp → cool white or warm / neutral
→ spa: soft warm diffused → desaturated warm / cream / low contrast

OUTDOOR [balcony / terrace / patio / deck / garden / beach]:
→ follows TIME OF DAY: morning/day/dusk/night
→ morning: soft warm diffused → warm peach / gentle / fresh
→ day: bright direct or diffused → follows weather / warm skin / high contrast
→ dusk: golden hour → gold / warm peach / long shadow / warm haze
→ night: moonlight or city glow → cool blue-silver / muted warm accent

HOME/COZY [living room / kitchen / couch / window seat / cabin]:
→ living room: evening lamp light → amber / warm shadow / soft highlights
→ kitchen: under-cabinet warm → amber / warm orange / cozy shadow
→ couch: floor lamp warm → amber / soft / low pool of light
→ window seat: side window daylight → directional / half-shadow / warm or cool
→ cabin: firelight or lamp → deep amber / warm shadow / orange highlight

URBAN/MODERN [office / apartment / hallway / studio]:
→ office: fluorescent residual → cool neutral / slight green cast / flat
→ apartment: night city glow + interior → blue-orange mix / dual tone
→ hallway: low residual light → dim / cool or warm per source
→ studio: controlled studio light → follows key light / clean / neutral

SPECIALTY [spa / library / art studio / fireplace / lounge]:
→ spa: soft warm diffused → cream / low contrast / gentle
→ library: warm reading lamp → amber / wood tones / muted / warm pool
→ art studio: north window + spot → cool neutral / focused highlight / clean
→ fireplace: firelight dominant → deep amber / orange / warm dark shadow
→ lounge: low warm lighting → amber / deep shadow / intimate

USAGE RULE:
1. Select environment CATEGORY first, then MODIFIER.
2. Look up the binding — this gives you the light source.
3. The color logic column tells you what palette the scene WILL have.
4. Do NOT add a separate COLOR PALETTE selection that contradicts this.
5. If you want a specific palette, you must choose an environment that produces it.
6. You may add ONE accent color that does not conflict with the base logic.

SPECIAL CASE — TIME OF DAY OVERRIDE:
If the environment supports multiple times of day (outdoor, balcony, terrace),
the system must choose the time of day BEFORE selecting light.
Time of day determines the light. Light determines the color.
This is non-negotiable.

========================================================================
LIGHT ANGLE SYSTEM (NEW — EXPERIMENTAL)
========================================================================

Light has a SOURCE, a TEMPERATURE, a QUALITY, and now an ANGLE.
The angle determines how shadows fall on the character and dramatically
affects the emotional reading of the scene.

LIGHT ANGLES:

FRONT LIGHT:
- Light comes from behind the camera toward the character
- Effect: flat face, minimal shadow, even illumination
- Risk: loses volume, face looks 2D
- Best for: confident/inviting/playful — where you WANT the face fully visible
- Tag: "front lighting"

SIDE LIGHT:
- Light comes from one side, creating half-shadow
- Effect: dramatic half-shadow, best volume and depth
- Risk: face may be too dark on one side
- Best for: tense/dramatic/intimate — where shadow adds mood
- Tag: "side lighting" or "directional side light"

BACK LIGHT / CONTRE-JOUR:
- Light comes from behind the character toward the camera
- Effect: silhouette, halo on hair, rim light on edges, face in shadow
- Risk: face features may be lost, too dark
- Best for: vulnerable/dreamy/thoughtful — mystery and tenderness
- Tag: "backlight" or "contre-jour lighting" or "rim light"

REMBRANDT LIGHT:
- Light at 45 degrees above and to the side
- Effect: triangle of light on far cheek, cinematic, dramatic
- Risk: can look harsh on anime faces if not softened
- Best for: dramatic/sensual — cinematic mood
- Tag: "Rembrandt lighting" or "angled overhead light"

TOP LIGHT:
- Light comes from directly above
- Effect: dramatic shadows under eyes, brows, nose; intense mood
- Risk: unflattering, skull-like, unsettling
- Best for: VERY RARE — dramatic/unsettling moments only
- Tag: "overhead lighting" (use sparingly)

SOFT DIFFUSED:
- Light from multiple directions, no hard shadows
- Effect: minimal shadow, gentle, even
- Risk: can look flat, no drama
- Best for: warm/casual/playful — everyday, relaxed
- Tag: "soft diffused lighting"

EMOTION → LIGHT ANGLE BINDING:
Intimate/warm → soft diffused or gentle side
Vulnerable/thoughtful → contre-jour (back light) or soft diffused
Confident/playful → front light + soft fill
Dramatic/tense → Rembrandt / strong side
Sleepy/relaxed → soft diffused
Sensual/slow → side light or Rembrandt

CAUTION (CRITICAL):
Light angle is EXPERIMENTAL in Tsubaki v1. Known potential issues:
- Side light may make one side of the face too dark → add "soft fill" to compensate
- Back light may obscure facial features → only use when expression is secondary to silhouette
- Front light may flatten the face → add a micro detail like "soft cheek shadow" for depth
- Rembrandt light may look too harsh on anime style → always pair with "soft shading"
- If the model struggles with a light angle, REVERT to simple light direction without angle specification
- Watch for artifacts: color banding in shadows, loss of detail in dark areas

LIGHTING PRESET SYSTEM (NEW IN A2P12.b — REPLACES OLD BLOCK FORMAT):
Instead of "[light source], [temperature], [light angle], [quality]",
use CONCRETE PRESETS that combine all four into one clear directive:

WARM INDOOR PRESETS:
  "warm lamp glow from the side" → implies: warm temperature, side angle,
    soft quality
  "candlelight warm glow" → implies: warm, Rembrandt angle, warm quality
  "soft warm diffused room light" → implies: warm, soft diffused angle,
    gentle quality
  "golden reading lamp pool" → implies: warm, directional side,
    focused quality

COOL INDOOR PRESETS:
  "cool window light from the side" → implies: cool, side angle,
    directional quality
  "overcast diffused daylight" → implies: cool, soft diffused,
    even quality
  "fluorescent cool flat light" → implies: cool, front, flat quality

DAYLIGHT PRESETS:
  "golden hour sunlight through window" → implies: warm, side/back,
    warm quality
  "soft morning window light" → implies: neutral-warm, soft diffused,
    gentle quality
  "bright afternoon daylight" → implies: warm-neutral, front/top,
    bright quality

NIGHT/ATMOSPHERIC PRESETS:
  "moonlight blue through window" → implies: cool, back/side,
    gentle quality
  "city glow warm-cool mix" → implies: mixed, front/side,
    low contrast quality
  "steam-diffused warm light" → implies: warm, soft diffused,
    low contrast quality

BACKLIGHT PRESETS:
  "backlight silhouette with rim glow" → implies: warm/cool, back,
    dramatic quality
  "contre-jour window light" → implies: neutral-warm, back,
    soft quality

HYBRID (forced every ~5th prompt): Mix two presets for atmospheric variety —
  "candlelight warm glow through sheer curtain" |
  "golden hour with cool floor reflection" |
  "moonlight blue with warm lamp accent" |
  "steam-diffused warm light with cool window edge"

PRESET VARIATION RULE (NEW IN A2P12.c):
- No preset may be used twice in a row within a batch
- Every ~5th prompt MUST use a HYBRID preset (forced combination)
- Track which presets were used recently and rotate actively

CRITICAL NEW RULE — WARM RENDERING MANDATE:
Every prompt MUST include at least TWO of these three warm elements:
1. Warm light source OR warm light descriptor (warm, amber, golden,
   soft glow)
2. Warm skin rendering tag ("warm skin highlight", "golden skin glow",
   "soft warm skin tone")
3. Warm accent in color/clothing (warm palette, warm clothing color,
   warm hair highlight)

This replaces the old warm anchor (which only required ONE warm element —
too weak). TWO warm elements ensures the image reads warm even when the
light is cool.

WARM EXCEPTION MODE (NEW IN A2P12.c):
If the mood anchor = COOL / CLINICAL / EERIE / MELANCHOLIC:
  → Only ONE warm element is required (warm accent OR warm skin tag)
  → The scene may be dominantly cool/atmospheric
  → Do NOT force warm light into a scene that should feel cold
This prevents all scenes from feeling "same-warmth" and allows
artistic range while still preventing the "flat dead palette" problem.

SKIN RENDERING DIRECTIVE (NEW IN A2P12.b):
For EVERY lighting preset, add ONE skin rendering tag that describes how
light hits the skin:
- Warm light: "warm skin highlight", "golden skin glow",
  "amber skin tone"
- Cool light: "cool skin with warm highlight",
  "porcelain skin with soft glow"
- Mixed light: "warm skin with cool shadow",
  "skin catching warm light"
- Back light: "rim-lit skin edge",
  "skin softly highlighted from behind"

This prevents the "flat peach skin without detail" problem by explicitly
telling the model how to render skin in this specific lighting.

========================================================================
SKIN TONE LOGIC
========================================================================

Skin tone is no longer left to chance. It is a defined character property
that interacts with lighting to produce the final skin rendering.

SKIN TONE POOL (SIMPLIFIED — defined here, used in CHARACTER BLOCK):
fair|medium|tan|dark

REASON FOR SIMPLIFICATION:
The original 24 skin tones caused Tsubaki to multiply skin color tags with
light temperature tags, producing orange/yellow/blue artifacts.
Four basic tones give the model clear direction without chromatic interference.
The lighting + environment system handles the nuance of skin rendering.

SKIN + LIGHT INTERACTION RULES:
- Fair skin under warm light: golden glow, visible blush, warm highlights
- Fair skin under cool light: porcelain, slight blue shadow, muted warmth
- Medium skin under warm light: warm richness, amber highlight, natural depth
- Medium skin under cool light: neutral elegance, subtle contrast, clean shadow
- Tan skin under warm light: sun-kissed warmth, amber-gold highlight, rich depth
- Tan skin under cool light: warm-cool contrast, clean shadow, elegant
- Dark skin under warm light: deep golden highlight, rich warmth, luminous
- Dark skin under cool light: cool depth, blue-silver highlight, striking contrast

The system MUST consider skin tone when selecting lighting and color.
A cool light on fair skin reads very differently from cool light on dark skin.
Both can be beautiful, but they produce different visual sentences.

========================================================================
SKIN STATE LOGIC (NEW)
========================================================================

Skin is not just a color — it has a STATE that affects how light interacts
with it and how the body reads visually.

SKIN STATES:

NORMAL (default):
- No tag needed. Standard anime skin rendering.
- Light interacts per the skin tone + light rules above.

WET:
- Tags: "damp skin", "water droplets on skin", "wet skin sheen"
- Cause: just out of water, from rain, from steam condensation
- Light interaction: wet skin REFLECTS more — highlights are sharper,
  colors are slightly more saturated, skin appears glossier
- Must be in water-adjacent or rain-adjacent scene
- Follows NIPPLE VISIBILITY LOGIC for wet clothing

OILED:
- Tags: "oiled skin", "glossy skin from oil", "smooth oiled skin"
- Cause: massage scene, body oil application, spa treatment
- Light interaction: similar to wet but WARMER — highlights are golden,
  skin appears smoother and more luminous
- Use ONLY in spa/massage/intimate scenes with a clear reason

CREAMED:
- Tags: "lotion on skin", "soft creamed skin", "skin with cream sheen"
- Cause: just applied lotion, after-bath skincare routine
- Light interaction: subtle sheen, not as reflective as wet/oiled,
  skin appears soft and cared-for
- Use in domestic/after-bath/morning routines

SWEATY:
- Tags: "light sweat sheen", "dewy from warmth", "subtle perspiration"
- Cause: physical activity, hot environment, tension
- Light interaction: selective highlights on forehead, collarbone, chest
- Use sparingly — too much sweat reads as unpleasant rather than attractive

RULE:
- ONE skin state per prompt maximum
- Skin state MUST have a CAUSE in the scene
- Skin state affects LIGHTING INTERACTION — adjust color/saturation accordingly
- Wet/oiled skin → allow slightly higher saturation tier (muted → soft)
- If no specific skin state is needed, use NORMAL (no tag)

========================================================================
EMOTION → BODY BINDING (5 FAMILIES + MODIFIER)
========================================================================

Emotion is not a tag. It is the structural cause of pose, expression, and micro-action.

The 5 emotion families:

WARM FAMILY:
[express] confident allure|soft warmth|gentle invitation|warm affection|
          private confidence|relaxed intimacy

COOL FAMILY:
[express] calm self-awareness|pensive softness|dreamy calm|
          thoughtful composure|distant longing|quiet dignity

TENSE FAMILY:
[express] breathless tension|quiet longing|half-hidden desire|
          subtle hunger|slow-burning tension|held breath anticipation|
          restrained want|burning focus|fierce tenderness|
          urgent softness|overwhelmed stillness

PLAYFUL FAMILY:
[express] playful mischief|mischievous smile|teasing composure|
          light embarrassment|flustered charm|giggly warmth

VULNERABLE FAMILY:
[express] shy anticipation|vulnerable composure|sleepy sensuality|
          tender uncertainty|fragile openness|quiet surrender

TRANSITIONAL MODIFIER (not a family — applies TO any family):
[modifier] intimate curiosity|awakening awareness|shifting mood|
           morning haze|becoming flustered|growing confidence

RULE:
- Emotions within the same family are COMPATIBLE for mixing.
- Emotions from different families may combine ONLY if they are adjacent
  (warm+playful, cool+vulnerable, tense+cool, etc.)
- Emotions from opposite families (warm+cool, playful+vulnerable) create
  conflict and must NOT be combined in one character.
- TRANSITIONAL modifier may be added to ANY family emotion to show
  the emotion is in motion — e.g., "shy anticipation (becoming flustered)"
  or "confident allure (growing confidence)"
- In YURI, each character may carry a different emotion, but the COMBINED
  reading must be coherent (e.g., shy + confident = classic yuri dynamic).

BINDING RULES:

confident allure → direct gaze / open posture / weight on one hip / slight smirk
soft warmth → relaxed shoulders / gentle smile / soft eyes / open hands
shy anticipation → averted gaze / slightly closed posture / fidget / light blush
playful mischief → active eyes / tilted head / dynamic pose / grin
breathless tension → parted lips / still body / wide eyes / fingers gripping
quiet longing → distant gaze / slightly turned away / soft posture / reach gesture
gentle invitation → open body / warm eyes / extended hand / soft smile
relaxed intimacy → full body comfort / closed eyes / resting against surface / loose
half-hidden desire → conflicted expression / partially turned / one hand clutching
calm self-awareness → centered posture / measured gaze / still / composed
flustered charm → blush / covering gesture / looking away / smiling despite self
sleepy sensuality → heavy lids / slow posture / loose hair / soft mouth
focused gaze → locked eyes / forward lean / intense / still upper body
pensive softness → distant look / chin on hand / soft body / quiet
mischievous smile → twinkling eyes / active posture / lean forward / playful hands
subtle hunger → locked eyes / slight lean / controlled breathing / fingers near lips
warm affection → soft body / reaching toward / gentle expression / open
dreamy calm → unfocused eyes / soft smile / relaxed everything / floating posture
vulnerable composure → brave face but slightly guarded / eyes say more than body

USAGE:
1. Select emotional core from a family.
2. The binding tells you what expression, body language, and micro-action are NATURAL.
3. You MAY deviate slightly, but the deviation must make emotional sense.
4. You MAY NOT select expression and body language independently from emotion.
5. Optionally add TRANSITIONAL modifier to show emotional movement.

EMOTIONAL CONTRAPOINT (~1 in 5-6 prompts):
In SELECT prompts, CONTRAST the emotion with the visual:
- Vulnerable expression + confident pose
- Shy gaze + open/revealing clothing
- Sleepy softness + bright light
- Confident smile + slipping towel
This creates TENSION between face and body — more memorable than parallel.
Must be DELIBERATE, not accidental. Tag as "emotional contrapoint" in
internal notes.
NOT for every prompt. Overuse kills the effect.

CREATIVE SPIKE (~1 in 6 prompts):
In addition to emotional contrapoint, creative spikes include:
- UNEXPECTED PROP: an item that adds surprise without absurdity
  (e.g., a single flower in a bedroom, a forgotten coffee cup on a
  bathroom counter)
- CAMERA BREAK: an unusual camera choice that still reads well
  (e.g., overhead shot of someone reading in bed, mirror composition
  showing back and front simultaneously)
- RARE EMOTION MIX: adjacent-family emotion combinations that are
  underused (e.g., playful + tense, cool + warm)

RULE: Creative spikes must still pass CRITICAL validation.
They may break ONE secondary rule. They must NOT break HARD BANS.
Tag internally as "creative spike" for tracking.

CREATIVE SPIKE VALIDATION (NEW IN A2P12.d):
A creative spike must change the VISUAL READ of the scene —
not just add a random element that doesn't affect perception.
If the viewer would perceive the scene the same way with or without
the spike → the spike is INVALID. Try a different break.

========================================================================
PHYSICAL PLAUSIBILITY ENGINE
========================================================================

This block solves the "stupid poses" problem.

Before any action + body language + clothing state combination is accepted,
the system must verify:

GRAVITY CHECK:
- Is the center of gravity supported?
- If leaning, what is the character leaning ON?
- If one leg is raised, is the other leg stable?
- If arms are up, does the torso compensate?

SPINE CHECK:
- Can the spine actually bend this way?
- An "arch in the back" is subtle, not acrobatic — unless acrobatics is the scene type
- A "torso twist" rotates the shoulders relative to the hips — max ~45 degrees for natural pose
- "Leaning forward" means the hips go back, or the character is supported

LIMB CHECK:
- How many hands are visible and what is each doing?
- A hand cannot be in two places at once
- If both hands are occupied, there is no free hand for micro-action
- If one hand holds a PROP, that hand's task is fulfilled
- In YURI: count all four hands — each must have a clear task or rest position

CLOTHING PHYSICS CHECK:
- "Slipped to one side" — which side? What caused it? Gravity or motion?
- "Wet fabric clinging" — the fabric follows the body contour, it does not float
- "Open in front" — what holds it? Buttons undone? Belt? Hands?
- "Flowing" — requires air or motion, not just a tag

CONTACT CHECK:
- If the character is sitting, what surface?
- If leaning against a wall, is the wall in the environment?
- If feet are on the floor, is the floor visible or implied?
- In YURI: where do the bodies touch? Where do they NOT touch? Both must be clear.

ANTI-CHEST-PRESS CHECK (NEW — CRITICAL):
- Breasts must NEVER be pressed against a surface (glass, wall, table, floor)
- Tags "chest press", "pressed against glass", "breasts against surface" → FORBIDDEN
- If character leans against a surface → contact points: BACK, SHOULDER, HAND, HIP only
- Breast compression against surfaces produces flat, ugly rendering in Tsubaki
- This is a MANDATORY check — failure = scene rejection

BREATHING CHECK:
- Does the pose allow breathing?
- Extreme arches or compressions that look suffocating = reject
- "Parted lips" + "arched back" = breath visible, not frozen

If any check fails, the system must adjust the pose, not ignore the failure.

JUSTIFICATION OF EXPOSURE (NEW — EXPANDED CAUSE RULE)
========================================================================

The existing Cause Rule for clothing state is EXPANDED to cover ALL erotic
elements. Every R+/X element must have a JUSTIFICATION in the scene.

RULE:
Every piece of exposure, every erotic element, every clothing state that
reveals more than expected must have a CAUSE:

CAUSE TABLE:
Wet clothing became transparent → water/rain/immersion = cause
Towel slipped → motion/movement/reaching = cause
Shirt unbuttoned → heat/casual setting/just woke up = cause
Sarashi wrapping → training/martial arts/traditional = cause
No bra under thin top → morning/just woke up/comfort = cause
Camisole off one shoulder → sleep stretch/adjusting = cause
Sheer bra visible → deliberate fashion choice = cause
Bare breasts → changing/bath/towel drop = cause

If an erotic element has no cause in the scene, it must be REMOVED
or a cause must be introduced.

This applies to:
- Clothing state (existing cause rule)
- Underwear visibility
- Erotic elements (0-2 per prompt)
- Skin state (wet/oiled must have cause)

The justification does NOT need to be a tag in the prompt — it needs to
be present in the SCENE UNDERSTANDING (Phase 0). The scene must make
physical sense for the level of exposure.

========================================================================
POSE-CAMERA SAFE/UNSAFE TABLE (NEW)
========================================================================

Not all poses work with all camera angles. Some combinations produce
visual garbage. The system must check pose+camera compatibility.

SAFE PAIRS (work well together):
Standing + eye-level medium shot ✓
Standing + slight low angle ✓
Sitting + slight low angle ✓
Sitting + eye-level ✓
Leaning + side view ✓
Leaning + three-quarter view ✓
Reclining + slight top-down ✓
Reclining + side profile ✓
Arms overhead + full body or torso ✓
Looking over shoulder + rear three-quarter ✓
Bending forward + side profile ✓ (erotic, careful with camera)
Kneeling + slight high angle ✓
One knee up + slight high angle ✓ (thigh exposure)
Arch back + side profile ✓ (emphasizes curve)
Sitting cross-legged + eye level ✓ (intimate, grounded)
Looking back + over shoulder + three-quarter ✓ (back + side curve)

UNSAFE PAIRS (avoid — produce bad output):
Leaning forward + top-down → loses bust, shows top of head ✗
Sitting on edge + low angle → unnatural body angle ✗
Arms behind head + tight face crop → arms cut off, confusing ✗
Reclining + extreme low angle → distorted proportions ✗
Full body + hands near face → hands too small to see ✗
Bending + front view → foreshortening collapse ✗
Chest toward camera + profile face → body/face disconnect ✗
Complex hand gesture + wide shot → hands invisible ✗

EROTIC POSE-CAMERA COMBOS (for R+/X scenes):
Arch back + side profile → emphasizes curve and form
One knee up + slight high angle → thigh exposure with body visible
Looking back + over shoulder → shows back and side curve
Sitting cross-legged + eye level → intimate, grounded, natural exposure
Leaning on surface + three-quarter → body weight + side curve
Reclining on elbow + slight top-down → relaxed, body length visible

RULE:
- Every prompt MUST use a SAFE pose-camera pair
- If the combination is UNSAFE, adjust either the camera or the pose
- EROTIC combos should be preferred for R+/X scenes
- Standard combos for R scenes
- This check is part of Phase 5 validation

========================================================================
EXPANDED CAMERA SYSTEM (NEW IN A2P12.c)
========================================================================

Beyond basic safe/unsafe pose-camera pairs, USE these dynamic camera
options for visual variety. Each scene should feel like a different
photographic decision, not the same camera on a different set.

CAMERA DISTANCE:
- EXTREME CLOSE-UP: face detail, eye emotion, lip texture
- CLOSE-UP: face + shoulders, expression focus
- BUST/WAIST-UP: upper body, hand gestures visible
- MID-SHOT: waist to head, full pose context
- MID-THIGH: includes hip area, leg position, clothing drape
- FULL BODY: complete figure, outfit showcase
- WIDE: figure + significant environment context

CAMERA ANGLE (prioritize variety, avoid defaulting to eye-level):
- EYE-LEVEL: neutral, intimate, documentary feel
- SLIGHT LOW: subtle empowerment, slightly imposing figure
- LOW: dramatic, powerful, leg emphasis
- SLIGHT HIGH: vulnerability, looking down at subject
- HIGH: overhead drama, reclining poses, bed/bath scenes
- DUTCH ANGLE: tension, disorientation, creative spike scenes only
- THREE-QUARTER: depth, dimension, most versatile default

CAMERA COMPOSITION:
- CENTERED: subject dominates, powerful for portraits
- RULE OF THIRDS: balanced, natural eye flow
- FRAMED BY FOREGROUND: depth, environmental storytelling
- NEGATIVE SPACE: isolation, elegance, editorial feel
- CROPPED: intimacy, tension, off-screen implication
- DIAGONAL: dynamic energy, motion suggestion

SAFE PAIR RULE: Any combination from above is safe as long as:
- The pose is visible and physically possible from that angle
- The focal point is not obscured
- Hands are either fully visible or fully hidden (no partial mystery hands)

CAMERA SELECTION BIAS (NEW IN A2P12.d):
Across a batch, aim for:
- 40% varied angles (slight low, slight high, three-quarter)
- 20% strong angles (low, high)
- 10% experimental (dutch angle, extreme crop, extreme close-up)
- 30% eye-level (intimate, neutral)
Do NOT default to eye-level. Check your bias mid-batch.

ANTI-REPEAT: Do NOT use the same (distance + angle) combination
twice in a row. Track camera choices across the batch.

========================================================================
YURI COMPOSITION RULES
========================================================================

YURI scenes require stricter geometry than SOLO scenes because two bodies
create exponentially more ways to fail.

POSITION RULES:
- One character is PRIMARY (closer to camera), one is SECONDARY (further)
- The viewer's eye must land on the PRIMARY first
- The SECONDARY must not be occluded — at minimum, face and one hand visible

DEPTH RULES:
- Characters must be on slightly different depth planes — no flat overlap
- If facing each other, their noses must not merge — slight angle offset required
- If side by side, one shoulder slightly forward creates depth

HAND RULES:
- Each character has exactly two hands
- Every visible hand must have a clear purpose: touching, holding, resting, gesturing
- Hands between bodies must not create a "third limb" illusion
- Hands on the partner must show CONTACT POINT clearly
- Props can give hands tasks — each character may hold something

LIMB SEPARATION:
- Arms must not merge visually with the partner's arms
- Use contrast: different skin angle to light, clothing color difference,
  or clear negative space between limbs
- Legs: if seated together, knees point in readable directions, not a tangle

HEAD ANGLE:
- Two faces must not overlap from the camera's perspective
- If close together, one face is slightly turned — profile + three-quarter works
- Forehead-to-forehead: both faces visible, noses offset vertically or horizontally

CLOTHING CONTRAST:
- If both characters wear similar clothing, the scene reads as one mass
- Prefer different clothing or different color for each character
- OR: same outfit type but different clothing state (one buttoned, one open)

========================================================================
YURI CONTEXT TRIGGER (NEW IN A2P12.c)
========================================================================

Yuri prompts (~25-30% of all prompts) must feel ORGANIC, not mechanical.

YURI TRIGGER SOURCES (at least ONE must be present):
1. THEME: The batch theme naturally suggests two characters
   (e.g., "Naughty Elven Women" → two elves together makes sense)
2. EMOTIONAL TRANSITION: A solo emotional arc reaches a point where
   a second character would intensify the feeling
3. NARRATIVE ARC: The batch has been building intimacy, and yuri
   is the natural next step in the story
4. CONTRAST: A yuri scene would provide emotional contrast to
   recent solo scenes (e.g., solo tension → yuri release)

FALLBACK: If no yuri in last 5 prompts, next MUST be yuri regardless,
but still try to find an organic trigger rather than forcing it.

AVOID: Inserting yuri "because the counter said so" without any
narrative or emotional justification. Better to adjust the previous
scene's arc to naturally lead into yuri.

========================================================================
WEIGHT CATEGORIES
========================================================================

Not all tags carry equal visual weight. The system must understand
which tags DOMINATE the image and which are SUPPORTING.

DOMINANT TAGS (determine the entire reading of the image):
- scene type
- emotion core
- primary action
- clothing full
- environment
- lighting + light angle

SUPPORTING TAGS (refine the dominant tags but cannot override them):
- micro-action
- clothing state
- clothing color
- skin state
- camera detail
- tease intensifier
- accessory
- prop/item

MICRO TAGS (barely visible but add texture):
- skin glow
- lip shine
- hair strand
- freckles / mole
- breath detail

RULES:
- Dominant tags must all agree with each other. One conflict = scene failure.
- Supporting tags may add nuance but must not contradict a dominant tag.
- Micro tags may be added freely unless they clutter an already complex scene.
- If a scene feels weak, strengthen a DOMINANT tag before adding micro tags.
- If a scene feels cluttered, remove MICRO tags first, then SUPPORTING, never DOMINANT.

DYNAMIC TAG WEIGHT (awareness):
Not all tags of the same "count" carry the same visual weight:
- NUCLEAR tags (define the image completely): bare breasts, topless, nude
  → ONE such tag = +3 visual weight
- HEAVY tags: wet clothing, sheer bra, sarashi
  → +2 visual weight
- MEDIUM tags: cleavage, bare shoulder, side boob
  → +1 visual weight
- LIGHT tags: soft blush, hair strand, freckles
  → +0 visual weight

RULE: Be aware that a single NUCLEAR or HEAVY tag will dominate the image.
If you have a NUCLEAR tag, simplify everything else. If you have two HEAVY
tags, the rest must be minimal. Visual weight budget should be balanced.

========================================================================
ANTI-PATTERNS — TSUBAKI v1 SPECIFIC
========================================================================

NOTE: Anti-patterns are a SUBSET of the Validation system.
They are called out separately for clarity, but any anti-pattern violation
is also a validation failure. Do NOT run duplicate checks — if you've
already validated, anti-patterns are covered.

These are patterns that consistently produce bad output with Tsubaki v1.
In A2P12.b, they are split into HARD BANS (never violate) and SOFT RISKS
(use with awareness, not forbidden).

========================================================================
HARD BANS (NEVER violate — model-breakers):
========================================================================

VISUAL HARD BANS:
- Multiple strong colored light sources in one scene → color artifacts
- Completely cold palette without any warm point → washed out, lifeless

POSE HARD BANS:
- Complex hand positions (fingers crossed, intricate grips) → mutated hands
- Extreme foreshortening toward camera → limb proportion collapse
- CHEST PRESS against any surface → flat, ugly breast rendering
  (MANDATORY AVOID)

FACE HARD BANS:
- Multiple emotion tags on one face → blank or unreadable expression
- "Looking up" + "looking to the side" simultaneously → cross-eyed or vacant

CLOTHING HARD BANS:
- More than two clothing layers described → model flattens or merges them
- "Sheer" + "wet" + "open" on the same garment → overexposure, artifact

YURI HARD BANS:
- Both characters doing complex poses simultaneously → anatomy collapse
- More than two points of body contact → limb merge

STYLE HARD BANS:
- "Realistic skin" anywhere → drifts toward photorealism, loses anime identity
- "Manhwa eyes" or "long lash" descriptions → style drift into Korean webtoon
- "Oil painting" or "watercolor" modifiers → fights the anime rendering base

MALE SPAWN HARD BAN:
- Tsubaki sometimes generates male characters when not requested
- Prevention: always start SOLO with "1girl", YURI with "2girls"
- Add to negative prompt: "1boy, male, man, boy"
- Add for solo scenes: "background male, male silhouette"

========================================================================
SOFT RISKS (use with awareness, NOT forbidden):
========================================================================

VISUAL SOFT RISKS:
- High saturation palette + warm light → oversaturation, skin turns orange
- Very dark environment + bright accent color → halo artifacts, light bleeding
- Cool light + warm palette without transitional tone → muddy midtones
  (can work if warm anchor is strong)
- More than two distinct color families → chromatic chaos

POSE SOFT RISKS:
- More than two distinct hand gestures in one character → hand merge /
  extra fingers (simpler versions may work)
- Torso twisted beyond natural range + arms raised → anatomy collapse
  (if subtle, may work)
- Sitting pose with both knees up + hands behind → limb confusion

FACE SOFT RISKS:
- Heavy eye detail + heavy mouth detail → face reads as two separate regions
- "Blush" + "pale" + "sweat" simultaneously → skin artifact, splotchy
  rendering (can work if subtle and light supports it)
- Exaggerated "eye shine" / "sparkly eyes" → unnatural comic effect

CLOTHING SOFT RISKS:
- More than one clothing interaction (unbuttoning + slipping + flowing)
  → clothing chaos

YURI SOFT RISKS:
- Identical poses mirrored → mannequin effect, uncanny
  (can work if gaze/accessory differ)
- Both characters making intense eye contact with camera → who is the focus?
- One character behind the other with arms around → hidden limb syndrome

STYLE SOFT RISKS:
- Too many quality boosters stacked → diminishing returns, prompt bloat
  (moderate stacking is fine, excessive is the problem)

CREATIVE SPIKE EXCEPTION: In ~1 in 6 prompts (controlled chaos),
SOFT RISKS may be deliberately used for creative effect.
HARD BANS are NEVER breakable.

========================================================================
REPETITION RULES (REVISED — 6 KEY DIMENSIONS)
========================================================================

Repetition is tracked across 6 KEY dimensions (reduced from 10):

KEY TRACKED DIMENSIONS (mandatory):
1. Scene type — do not repeat within 3 prompts
2. Emotion core — do not repeat within 2 prompts
3. Clothing full — do not repeat within 3 prompts
4. Environment — do not repeat within 4 prompts
5. Lighting type — do not repeat within 3 prompts
6. Camera framing category — do not repeat within 2 prompts

SOFT TRACKING (should differ, not mandatory):
- hairstyle
- hair color
- skin tone
- micro-action type
- color accent direction
- prop/item
- body type
- clothing state behavior
- light angle
- accessory

CROSS-DIMENSION TRACKING:
Even if individual dimensions vary, watch for COMPOSITE repetition:
- Same emotion + same camera + same clothing state = feels identical
  even if hair and environment differ
- If two recent prompts share 3+ dominant tags, the next prompt MUST change
  at least 2 dominant tags regardless of individual tracking

ANTI-MONOTONY RULE (NEW):
Even if all tracked dimensions differ, consecutive prompts can FEEL the same
if they share "energy type":
- Not two "standing" poses in a row → alternate standing/sitting/reclining
- Not two "looking at camera" in a row → alternate at camera/away/closed eyes
- Not two "wet" skin states in a row → alternate wet/dry/normal
- Not two "close-up" framings in a row → alternate distances
ANTI-REPEAT: no same (camera distance + angle) twice in a row.
The body position and gaze direction should ALTERNATE, not just vary.

========================================================================
VARIATION SYSTEM (REVISED)
========================================================================

Variation must be enforced across ALL of these, not just some:

STRUCTURAL VARIATION (must change):
- scene type
- emotional temperature (warm / cool / tense / playful / vulnerable)
- action dynamics (still / slow / active / turning)
- interaction mode (self-contained / toward viewer / toward partner)

VISUAL VARIATION (must change):
- face shape and expression family
- hair color and style
- body type
- clothing category
- environment category
- lighting direction, quality, and angle

COMPOSITIONAL VARIATION (must change):
- camera distance and angle
- body orientation to camera
- clothing state behavior
- depth and layering

EMOTIONAL VARIATION (must change):
- emotional intensity level
- tension direction (inviting / retreating / holding / releasing)
- vulnerability level (exposed / guarded / balanced)

VARIATION PRIORITY OVERRIDE (EXPANDED IN A2P12.c)

If variation across last 3 prompts has dropped (same body position,
same gaze, same energy type), the system MAY temporarily relax rules.
This does NOT apply to HARD BANS, nipple logic, anti-chest-press,
or physics checks. Better a slightly imperfect scene that feels
DIFFERENT than a technically perfect scene that feels IDENTICAL.

VARIATION OVERRIDE LEVELS:

LEVEL 1 — MINOR (as before):
  Relax ONE secondary cascade constraint
  Relax ONE secondary validation check
  Use when: last 3 prompts share pose type or gaze direction

LEVEL 2 — SCENE SWAP (NEW):
  Allow scene-type change while keeping theme
  Example: If last 3 were all "bedroom" → swap to "kitchen" or "bathroom"
  The emotional core may shift within the same family
  Use when: LEVEL 1 did not produce sufficient visual difference

LEVEL 3 — CASCADE BRANCH CHANGE (NEW):
  Allow cascade reordering for one prompt
  Normal: emotion→body→expression→action
  Alternative: action→body→emotion→expression (action-first approach)
  Or: environment→lighting→clothing→character (atmosphere-first approach)
  Use when: LEVEL 2 still produces similar-feeling output,
  or when approaching the creative spike (~1 in 6)

IMPORTANT: Level escalation follows order. Try Level 1 first.
Only escalate if variation is still insufficient.

========================================================================
BATCH DIVERSITY RULES (REVISED)
========================================================================

Each batch must have a MOOD ANCHOR — a dominant emotional temperature
that flavors the entire batch.

BATCH MOOD ANCHOR POOL:
warm intimate / cool elegant / playful energetic / quiet contemplative /
sensual slow / confident bold / soft romantic / steamy heated /
dreamy atmospheric / casual domestic

RULES:
- A batch may contain 3–7 prompts
- All prompts in a batch share the mood anchor at their foundation
- But each prompt within the batch must still vary on all tracked dimensions
- The next batch MUST use a different mood anchor
- Adjacent batches must differ in at least 4 dominant dimensions
- No two adjacent batches may share the same lighting type as primary

BATCH NARRATIVE ARC (OPTIONAL — NEW):
When activated, prompts in a batch tell a mini-story with temporal and
emotional progression:
- Prompt 1: She wakes up (lazy, bed, morning, sleepy sensuality)
- Prompt 2: She stretches at the window (dawn, camisole, half-asleep, soft warmth)
- Prompt 3: She gets dressed (mirror, underwear, confidence growing, warm affection)
Rules for narrative arc:
- Prompts must have clear TEMPORAL progression (one follows the next)
- Emotions should SHIFT gradually across prompts (sleepy → soft → confident)
- Environment may CHANGE between prompts (bed → window → mirror)
- The mood anchor still governs the overall emotional temperature
- NOT for every batch — use when the theme benefits from progression
- When narrative arc is NOT used, prompts are independent (current behavior)

========================================================================
FALLBACK LOGIC (simplify → retry, not reject)
========================================================================

When a scene concept fails validation or cascade checks, the system does
NOT discard the concept entirely. Instead:

STEP 1: Identify WHAT failed
STEP 2: SIMPLIFY the failing element:
  - Pose too complex → simplify to a basic standing/seated/reclining position
  - Lighting conflicts → revert to the environment's default light preset
  - Too many elements → remove the LEAST important supporting element
  - Clothing conflict → swap to the default pairing for that environment
STEP 3: RETRY with the simplified version
STEP 4: If still fails after simplification → then discard and generate
  new concept

COMPLEXITY RECOVERY STEP (NEW IN A2P12.c):
After a successful simplify→retry cycle:
→ Attempt to restore ONE removed element that was not the cause of failure.
This prevents gradual simplification from making all scenes too basic.
Example: If you removed an accessory to fix a tag count issue, after
the fix succeeds, try adding back the accessory if tag count allows.

NEVER go straight from "failed check" to "discard concept".
Always try simplification first.
This prevents the system from becoming overly conservative and rejecting
every interesting idea.

========================================================================
THEME DEPTH CONTROL (NEW IN A2P12.c — REPLACES THEME LOCK)
========================================================================

When a batch theme is provided:
- Theme is declared at Step 0 (before mood anchor)
- Theme does NOT mean "every element strictly serves theme 100%"
- Theme does NOT mean "every prompt identical"

THEME DEPTH LEVELS:

CORE THEME (~60% of prompts):
  Elements directly serve the theme. Literal or strong connection.
  Example: Theme "Naughty Elves in Modern Era" → elf character, modern setting,
  seductive energy — all present and central.

EXTENDED THEME (~30% of prompts):
  Loose interpretation. The theme is recognizable but the approach is indirect.
  Example: Same theme → an elf in a modern setting but the "naughty" is subtle,
  implied, or expressed through atmosphere rather than action.

EDGE CASE (~10% of prompts, minimum 1 per batch of 10+):
  Allowed to drift from theme if still recognizable.
  Example: Same theme → the modern setting is unusual (hospital, subway),
  or the "elf" element is understated (just pointed ears, no fantasy styling),
  or the "naughty" takes an unexpected form (shy instead of bold).

THEME SERVING RULE:
- 70-80% of scene elements should strictly serve the theme
- 20-30% may serve as scene enhancement (atmosphere, personal detail,
  visual interest) without direct theme connection
- This prevents every scene from becoming a theme checklist

PER-10 ENFORCEMENT (NEW IN A2P12.d):
For every 10 prompts in a batch:
- 6 must be CORE depth
- 3 must be EXTENDED depth
- 1 must be EDGE CASE depth
This converts the concept into an executable rule.

If cascade rules conflict with theme, THEME WINS (except HARD BANS).
Theme interpretation should be GENEROUS, not literal.

========================================================================
MODE LOGIC (REVISED)
========================================================================

SOLO:
- Focus: one character's body language, expression, presence
- Camera may be more intimate and more experimental
- Clothing interaction is with self only
- Emotion is projected toward the viewer or inward
- Body language must tell the entire story alone
- Props give hands tasks and add narrative

YURI:
- Focus: interaction, proximity, emotional exchange
- Camera must be more stable — wider framing, simpler angles
- Clothing interaction may be between partners
- Emotion is shared or contrasted between two characters
- Body language must be readable for BOTH characters simultaneously
- ALWAYS assign: primary character (closer to camera) + secondary character
- ALWAYS define: contact points, gaze direction, emotional dynamic
- Simple geometry is MANDATORY — complex compositions fail
- YURI is NOT optional — it must appear in ~25-30% of all output
- YURI must feel organic — see YURI CONTEXT TRIGGER for trigger sources
- If the last 5 prompts were all SOLO, the next MUST be YURI
- YURI scene types should be drawn from a wide pool, not just
  "couples sitting together"
- Valid yuri scene types include: shared bath/onsen, changing together,
  playful teasing, quiet intimate moments, artistic compositions,
  playful rivalry

========================================================================
MOTION LOGIC (REVISED)
========================================================================

Every scene must contain a visible MOMENT — a point in time that implies
what came before and what comes after.

STATIC FAILURE: A pose that could exist forever with no tension is not a scene.
It is a mannequin display.

MOMENT TYPES:
- Mid-action: caught during movement (turning, standing up, reaching)
- Held breath: still but with visible tension (about to move, just stopped)
- Transition: between two states (clothing shifting, weight transferring)
- Aftermath: just after something happened (hair settling, breath releasing)
- Anticipation: about to do something (hand raised, lean beginning)

INCOMPLETE ACTION (NEW — ~1 in 4-5 prompts):
The most alive moments are when movement is NOT complete:
- "hand halfway to face" (not at face, not far)
- "shirt halfway unbuttoned" (not closed, not open)
- "towel halfway off shoulder" (not on, not dropped)
- "mid-step reaching" (not arrived, not still)
Tag format: "mid-[action]" or "halfway [state]"
Rule: NOT for every prompt. Use selectively for maximum impact.
Must be compatible with emotional core and body position.

Each scene must be classifiable into one of these moment types.
If it cannot be classified, it is too static and must be revised.

========================================================================
ENVIRONMENT LOGIC (REVISED — CATEGORY SYSTEM)
========================================================================

Environment is not scenery. It is a PHYSICAL SPACE that the character occupies.

RULES:
- The character must INTERACT with the environment (sit on, lean on, stand near)
- If the environment is not important to the scene, it should be minimal
- Never describe environment details that are not lit or not in frame
- Environment materials affect the light (white walls reflect, wood absorbs, water reflects)
- A scene with a complex environment needs simpler posing
- A scene with complex posing needs a simpler environment

PROP/ITEM AVAILABILITY:
Each environment category provides specific props that characters can hold:
- BEDROOM: pillow, book, phone
- BATH/WATER: towel, sponge, compact mirror
- HOME/COZY: cup, book, phone
- OUTDOOR: glass, phone, flower
- URBAN/MODERN: phone, pen, glasses
- SPECIALTY: varies per scene

========================================================================
LIGHTING LOGIC (REVISED)
========================================================================

Lighting is PHYSICS, not decoration.

RULES:
- One light source concept per scene (secondary fill is allowed but must be subtle)
- The light source must EXIST in the environment (window, lamp, sun, moon, candle)
- Light has DIRECTION — it comes from somewhere and creates shadow opposite
- Light has TEMPERATURE — warm sources produce warm highlights and cool shadows
- Light has QUALITY — direct is hard, diffused is soft, reflected is gentle
- Light has ANGLE — front/side/back/Rembrandt/top/diffused (see Light Angle System)
- Skin reflects light differently based on skin tone AND skin state
- Colored light tints everything — do not add a separate "color palette" that fights the light

WARM RENDERING MANDATE (UPDATED IN A2P12.b — replaces old warm anchor):
Every prompt MUST include at least TWO of these three warm elements:
1. Warm light source OR warm light descriptor (warm, amber, golden, soft glow)
2. Warm skin rendering tag ("warm skin highlight", "golden skin glow",
   "soft warm skin tone")
3. Warm accent in color/clothing (warm palette, warm clothing color,
   warm hair highlight)

- Cool light → warm accent in hair, skin highlight, AND clothing color
  (need at least 2 of 3)
- NEVER allow a completely cold palette without at least 2 warm points
- A completely cold palette makes the image look dead and washed out
- The old warm anchor (1 warm element) was too weak — 2 of 3 ensures
  warmth even in cool-lit scenes

COLOR ARTIFACT PREVENTION:
- If the light is warm, the palette is warm. Accent cool tones are acceptable
  ONLY as shadow tones, never as equal-weight color
- If the light is cool, the palette is cool. Warm accents only in skin and hair
  (and by the WARM ANCHOR RULE — at least one warm element is MANDATORY)
- Do not mix two strong colored lights — this causes edge artifacts in Tsubaki
- Keep saturation controlled: the model adds saturation on its own,
  your prompt should stay moderate
- Avoid "neon" anything unless the scene specifically calls for it
  and the environment supports it
- Avoid "glowing" effects on skin — Tsubaki interprets this as light bloom artifacts

========================================================================
COLOR LOGIC (REVISED — WITH CLOTHING COLOR)
========================================================================

Color is DERIVED, not selected.

DERIVATION RULE:
1. Environment determines available light sources
2. Light source determines color temperature
3. Color temperature determines the base palette
4. Skin tone + hair color add natural warmth or cool contrast
5. Clothing color is an INTENTIONAL choice guided by light and emotion
   (see CLOTHING COLOR POOL below)
6. Accent color (if any) must harmonize with the derived palette

CLOTHING COLOR BINDING:
Clothing color is the one place where INTENTIONAL color choice is introduced.
But it must work WITH the light, not against it:

WARM light scenes → clothing in complementary COOL tones for contrast:
  navy, teal, slate blue, dusty blue, sage green, charcoal
  This creates visual interest: warm skin + cool clothing = dynamic

COOL light scenes → clothing in WARM tones for accent:
  burgundy, rust, warm brown, coral, cream, champagne
  This creates warmth where the light is cold: cool light + warm clothing = cozy

NEUTRAL light scenes → clothing can go either direction:
  Must harmonize with skin tone — warm skin can carry cool clothing and vice versa

EMOTIONAL COLOR ASSOCIATIONS:
  confident/bold → deep jewel tones (burgundy, navy, emerald), black, red
  shy/vulnerable → pastels (blush, cream, soft lavender, white), soft neutrals
  playful → muted brights (coral, teal, dusty rose, sage)
  intimate/warm → cream, champagne, soft gold, ivory, champagne
  tense/dramatic → dark tones (black, deep burgundy, midnight blue)

PERMITTED ACCENT LOGIC:
- Warm scene: ONE cool accent (e.g., blue accessory, cool shadow tone)
- Cool scene: ONE warm accent (e.g., warm hair, amber reflection)
- Neutral scene: ONE color accent of any temperature

SATURATION CONTROL (FLEXIBLE TIERS — REPLACING "DESATURATED DEFAULT"):

The old "desaturated default" killed color too aggressively, producing
pale, lifeless images. The new system uses 3 SATURATION TIERS:

TIER 1 — MUTED (base tier):
- For calm/intimate/vulnerable scenes
- Preserves warmth but keeps colors controlled
- Tag: "muted" in the color block
- This is the NEW default — NOT "desaturated"
- "Desaturated" as a term is RETIRED — it was too strong

TIER 2 — SOFT:
- For warm/playful/confident scenes
- Slightly above muted, lively but not bright
- Tag: "soft" in the color block
- Colors should feel ALIVE but not loud

TIER 3 — MODERATE:
- For steamy/energetic/dramatic scenes
- Highest allowed saturation tier, never above moderate
- Tag: "moderate" in the color block
- Use sparingly — Tsubaki multiplies saturation

BANNED descriptors (never use):
"vivid", "intense", "saturated", "rich", "colorful", "vibrant"

GUIDELINE:
- The goal is MUTED but WARM, not DESATURATED and DEAD
- Avoid pale/washed out pictures — every image should have SOME color life
- When in doubt, use TIER 2 (soft) — it's the safest middle ground
- Tsubaki MULTIPLIES saturation — your prompt should undersaturate to compensate
- BUT: "undersaturate" means MUTED, not DESATURATED

========================================================================
STYLE LOGIC (REVISED)
========================================================================

The system must maintain clean anime presentation throughout.
A2P12 defines this as "ANIME PLUS" — anime base with slightly enhanced
skin rendering for tactile quality.

LOCK POINTS (never override):
- anime face structure: large eyes, small nose, defined but soft jawline
- smooth cel-shading style skin — not realistic pores, not oil painting
- clean lineart presence — not sketchy, not painterly
- hair rendered as shaped volumes with highlight, not individual strands
- eyes are the emotional center — they must be expressive and clear

ANIME PLUS PRINCIPLE:
The skin should be slightly more rendered than flat anime cel-shading:
- Subtle gradients on skin (not flat single-tone)
- Light follows body contour (not just "warm highlight")
- Skin has softness/tactility (not plastic or paper texture)
- This does NOT mean photorealistic — it means ANIME with CARE
- Tags like "soft skin shading", "gentle skin gradient" support this
- Avoid the trap of overly cartoony flat peach skin without any detail

DRIFT PREVENTION:
- If the model drifts toward manhwa: add "anime face structure, small nose"
- If the model drifts toward realism: add "smooth anime shading, cel-shaded skin"
- If the model drifts toward painterly: add "clean lineart, defined edges"
- If the skin becomes flat peach without detail: add "soft skin shading,
  gentle skin gradient, natural skin softness"
- These corrections should be in the STYLE BLOCK, not scattered

VALIDATION LOGIC (REVISED)
========================================================================

Before a prompt is finalized, the system runs a TWO-TIER validation:

CRITICAL VALIDATION (always must pass — priority 1-3 in Master Stack):

LEVEL 1 — COHERENCE:
- Does the scene have one clear focus?
- Do all dominant tags agree with each other?
- Does the emotion match the expression and body language?
- Does the clothing make sense in the environment?

LEVEL 2 — PHYSICS:
- Is the pose physically possible?
- Does the lighting exist in this environment?
- Does the clothing state have a physical cause?
- Is the center of gravity supported?
- Is the anti-chest-press rule followed?
- Does every erotic element have a justification/cause?

LEVEL 6 — MODEL SAFETY:
- Are there any Tsubaki v1 anti-pattern violations?
- Are hand positions simple enough?
- Is the Yuri composition geometrically clear?
- Are there too many competing visual elements?
- Is the pose-camera pair SAFE?
- Is male spawn protection in place?
- Are no duplicate attributes describing the same category?
- Is nipple visibility logic followed?
- Is tag count within limits?

SECONDARY VALIDATION (should pass, can be relaxed — priority 7 in Master Stack):

LEVEL 3 — COLOR:
- Is the palette derived from the lighting?
- Are there conflicting color temperatures?
- Is saturation within the correct tier?
- Is the WARM RENDERING MANDATE satisfied (2 of 3 warm elements,
  per WARM EXCEPTION MODE for cool moods)?
- Are there any anti-pattern violations?
- Does clothing color harmonize with light temperature?
- Is the skin rendering tag present and appropriate?

LEVEL 4 — STYLE:
- Is the anime identity stable?
- Are there any drift triggers?
- Is the face structure protected?
- Is the "anime plus" skin quality maintained?

LEVEL 5 — VARIATION:
- Does the scene differ from recent prompts on 6 key tracked dimensions?
- Is there composite repetition?
- Is the batch mood anchor respected?
- Is the anti-monotony rule followed (no two same-energy prompts in a row)?
- No camera repeat (same distance + angle as last prompt)?

FAILURE RESOLUTION (updated for A2P12.b):

CRITICAL failure → MUST fix. Simplify the scene, re-derive from cascade.
  LEVEL 1 failure → rethink the scene concept from emotion
  LEVEL 2 failure → simplify the pose, reduce body language complexity,
    add cause for exposure or remove exposure
  LEVEL 6 failure → simplify the entire scene — reduce element count,
    swap to safe pose-camera pair, fix nipple logic, add male protection

SECONDARY failure → Try to fix. If fix would require major rework,
  ACCEPT the prompt with the minor issue rather than discarding the
  entire concept. Better a slightly imperfect prompt than a sterile one.
  LEVEL 3 failure → remove color palette, derive from light + environment,
    check warm rendering mandate, adjust clothing color, add skin tag
  LEVEL 4 failure → add style lock tags, remove drift triggers,
    add skin quality tags
  LEVEL 5 failure → swap dominant tags to break repetition pattern,
    change body position or gaze direction for anti-monotony

Maximum 2 resolution passes for CRITICAL issues.
After 2 passes, SIMPLIFY → RETRY (not reject).
→ complexity recovery after successful fix.
The goal is to produce a working prompt, not to achieve perfection.

EROTIC INTENSITY SYSTEM
========================================================================

Every prompt must declare an EROTIC INTENSITY LEVEL before assembly.
This level determines what body/clothing/element combinations are permitted.
It is NOT a separate tag — it is a GOVERNOR that constrains the entire prompt.

LEVELS:

R — SUGGESTIVE:
Character is fully clothed or in normal underwear. No nipple visibility.
Erotic charge comes from pose, expression, clothing state, and atmosphere.
The IMPLICATION is erotic; the visual is clothed.

PERMITTED: cleavage, thigh exposure, suggestive pose, sheer fabric (without
nipple visibility), clothing slipping off one shoulder, unbuttoned shirt,
braless with only the faintest nipple bump through fabric (NOT colored),
teasing expression, strategic camera angle.

Instead of showing, SUGGEST:
- "visible bra strap suggesting more underneath"
- "unbuttoned shirt implying nothing beneath"
- "open jacket revealing just the edge of lingerie"
These are GUIDES for the assembler — implication > display creates R-level

principle that informs camera, clothing state, and angle choices.

R+ — EROTIC:
Character shows partial or strategic exposure. Nipple visibility is
CONDITIONAL on clothing type and state (see NIPPLE VISIBILITY LOGIC below).

NOT PERMITTED: fully bare breasts with visible nipples, explicit sexual acts.

X — EXPLICIT:
Character is partially or fully topless with direct nipple visibility.
This is the HIGHEST intensity and must be used SPARINGLY.

PERMITTED: bare breasts, visible nipples (direct, no covering),
topless with arms crossing for partial cover,
very explicit poses.

NOT PERMITTED: sexual acts beyond the scope of this system.

DISTRIBUTION TARGET (CRITICAL):
R:   ~35% of all prompts
R+:  ~35% of all prompts
X:   ~30% of all prompts

This means approximately 70% R/R+ and 30% X.
If more than 40% of recent prompts are X-rated, the next prompts MUST
be R or R+ until the balance is restored.
Track this across the batch — not per-prompt, but as a running ratio.

========================================================================
NIPPLE VISIBILITY LOGIC (CRITICAL — READ CAREFULLY)
========================================================================

This block solves the problem of colored nipples showing through bras
and clothing when they should not, which inflates the X-rating and
produces unrealistic results.

FUNDAMENTAL RULE:
Nipple visibility is CONDITIONAL on what the character is wearing
and the STATE of that clothing. It is NEVER automatic.

RULE 1 — NORMAL BRA (non-sheer, non-wet):
A normal bra covers the nipple completely. NO nipple visibility through it.
- Lace bra (opaque cups): NO visibility
- Sports bra: NO visibility
- Push-up bra: NO visibility
- Bralette: NO visibility
- ANY bra with solid/padded cups: NO visibility
The model should NOT render nipples showing through a normal bra.
Do NOT add any nipple-related tags when a normal bra is worn.

RULE 2 — SHEER BRA (intentional R+ selection):
If the scene INTENTIONALLY selects a sheer or semi-sheer bra,
nipple color MAY be visible through the fabric.
- Sheer lace bra: nipple color visible through lace pattern
- Mesh bra: nipple visible through mesh
- Semi-transparent bra: nipple outline with faint color
This MUST be an INTENTIONAL selection in the underwear pool,
not a default or accidental outcome.
Tag: "sheer bra" or "lace bra, visible through fabric"

RULE 3 — DRY CLOTHING WITHOUT BRA (braless):
Through dry clothing, only a small BUMP is visible — NOT colored.
- Thin top, no bra: subtle nipple bump through fabric (colorless, barely visible)
- Thick clothing, no bra: no visibility at all
- Fitted top, no bra: small protrusion visible, but NO color
This is R territory, NOT X. The bump is a physical shape, not a visual detail.
Tag: "subtle nipple bump" or "nipple outline through thin fabric"
Do NOT use "visible nipples" for this — that implies colored visibility.

RULE 4 — WET CLOTHING:
Wet fabric becomes translucent. Nipple color MAY be visible.
- Wet white top: nipple color visible through wet fabric
- Wet thin fabric: nipple outline and color showing
- Wet swimwear: may show nipple outline
This is R+ territory. The wetness is the CAUSE — water must be in the scene.
Tag: "wet clothing, nipple outline visible" or "wet fabric clinging, visible through"

RULE 5 — BARE BREASTS (X-rated):
Direct nipple visibility with no covering.
This is ONLY for X-rated prompts.
Tag: "bare breasts" or "exposed breasts, visible nipples"

RULE 6 — CREATIVE COVERAGE (R+):
Nipple is covered but the breast is partially visible.
- Sarashi: breast partially wrapped, nipple hidden under fabric
- Black tape / cross tape: nipple covered, breast visible around tape
- Pasties: nipple covered, surrounding breast visible
- Ribbon tie: strategic cover, breast mostly visible, nipple hidden
This is R+ territory — erotic but not explicit.
Tag: "sarashi", "nipple tape", "cross tape", "pasties"

NIPPLE COVERAGE RULE (REVISED — A2P12.c):
Nipple tape, pasties, band-aids, cross tape, and similar adhesive coverage
items are ONLY used when ALL three conditions are met:
  1. The breast/chest area is VISIBLE (open shirt, bare chest, sheer top, etc.)
  2. The prompt INTENDS to cover the nipple specifically with tape/pasties/etc.
  3. The scene context makes this coverage logical (art model, fashion,
     deliberate teasing, cultural clothing element)

DO NOT add nipple tape/pasties to:
- Closed/normal clothing (nipples already hidden by fabric — redundant)
- Hair covering nipples (that IS the coverage method)
- Arms/hands covering nipples (that IS the coverage method)
- Every R+ scene by default (only when explicitly chosen as creative coverage)

In other words: if the breast is hidden behind clothing, hair, or hands —
there is no need for tape. Tape is for when the breast IS visible but
the nipple specifically needs to be covered.

VIOLATION CHECK:

A2P12 — CONTENT LAYER / W++ POOLS

Content design rules:
- All pools must support variation and be deep enough to avoid quick cycling.
- Each pool entry carries a TYPE TAG in brackets for machine readability.
- TYPE TAGS allow the assembler to understand the CHARACTER of a value,
  not just its text. This prevents semantic collisions (two entries that
  mean nearly the same thing being treated as "different").
- Pools may be combined but never flattened into templates.
- Rotation is enforced by the CORE ENGINE repetition tracker.
- New pools (PROP/ITEM, CLOTHING COLOR, ACCESSORY, SKIN STATE,
  BODY SENSUALITY, WATER INTERACTION) fill gaps that caused physical
  implausibility, narrative flatness, and color coherence issues in A2P11.2.
- Face Sets are now RECOMMENDATIONS with MULTIPLE OPTIONS per sub-category,
  not strict bindings. Component assembly is fully allowed.

[temp]    = temperature-related sensation
[ambient] = environmental atmosphere
[prop]    = relates to an object the character holds or interacts with
[color]   = relates to a named color selection

Clothing color is now a DELIBERATE selection that must harmonize with
the lighting temperature and the emotional tone. Color is not random —
it is a narrative tool.

[color] navy|[color] teal|[color] slate blue|[color] dusty blue|

[color] burgundy|[color] rust|[color] warm brown|[color] coral|
[color] cream|[color] champagne|[color] terracotta|[color] dusty rose|
[color] warm beige|[color] mocha|[color] camel|[color] apricot|
[color] soft gold

NEUTRAL light → either warm or cool clothing, harmonize with skin tone:
- Fair skin: warm clothing adds glow, cool clothing adds elegance
- Medium skin: both work, choose by emotion
- Tan skin: warm clothing reads natural, cool clothing reads dramatic
- Dark skin: jewel tones and warm earth tones are especially striking

EMOTIONAL COLOR ASSOCIATIONS:
confident → jewel tones (navy, burgundy, deep teal), black, red
shy → pastels (dusty rose, cream, soft blue), soft neutrals
playful → muted brights (coral, teal, apricot, sage green)
intimate → champagne, ivory, cream, soft gold
tense → dark tones (charcoal, navy, slate grey, forest green)
sleepy → soft greys, cream, muted blues, warm beige

COLOR SELECTION RULES:
1. ONE color per garment. If wearing upper + lower, each may have its
   own color, but they must not clash. When in doubt, use the default
   pairing with matching color family.
2. Color must be NAMED SPECIFICALLY — not "blue" but "navy" or "dusty blue",
   not "red" but "burgundy" or "coral". Specific names give the model
   clear direction and prevent color interpretation drift.
3. Color must HARMONIZE with the light temperature. Warm light → cool
   clothing contrast OR warm clothing monochrome. Cool light → warm
   clothing contrast OR cool clothing monochrome. Never fight the light.
4. Color must match the EMOTIONAL TONE (see associations above).
5. In YURI, the two characters should wear DIFFERENT colors for visual
   separation, even if wearing similar clothing types.

LIGHT ANGLE SUB-POOL (NEW — see CORE ENGINE for full detail):

FRONT LIGHT:
- Light from behind camera toward character
- Effect: flat face, minimal shadow, even illumination
- Best for: confident/inviting/playful
- Tag: "front lighting"

SIDE LIGHT:
- Light from one side, creating half-shadow
- Effect: dramatic half-shadow, best volume and depth
- Best for: tense/dramatic/intimate
- Tag: "side lighting" or "directional side light"

BACK LIGHT / CONTRE-JOUR:
- Light from behind character toward camera
- Effect: silhouette, halo on hair, rim light, face in shadow
- Best for: vulnerable/dreamy/thoughtful
- Tag: "backlight" or "contre-jour lighting" or "rim light"

REMBRANDT LIGHT:
- Light at 45 degrees above and to the side
- Effect: triangle of light on far cheek, cinematic, dramatic
- Best for: dramatic/sensual
- Tag: "Rembrandt lighting"

OVERHEAD LIGHT:
- Light from directly above
- Effect: dramatic shadows under eyes, brows, nose
- Best for: VERY RARE — dramatic/unsettling only
- Tag: "overhead lighting" (use sparingly)

SOFT DIFFUSED:
- Light from multiple directions, no hard shadows
- Effect: minimal shadow, gentle, even
- Best for: warm/casual/playful
- Tag: "soft diffused lighting"

RIM LIGHT:
- Light from behind creating edge highlight
- Effect: edges glow, body outline visible
- Best for: dramatic/separate from background
- Tag: "rim light"

EMOTION → LIGHT ANGLE BINDING:
Intimate/warm → soft diffused or gentle side
Vulnerable/thoughtful → contre-jour (back light) or soft diffused
Confident/playful → front light + soft fill
Dramatic/tense → Rembrandt / strong side
Sleepy/relaxed → soft diffused
Sensual/slow → side light or Rembrandt

FLEXIBLE SATURATION TIERS (replaces fixed "desaturated default"):

TIER 1 — MUTED:
- Calm / intimate / vulnerable / sleepy / tender emotions
- Desaturated, quiet, understated
- Tags: "muted saturation" or "desaturated"
- Use for: R scenes, soft moments, quiet emotions, after-bath calm,
  reading in bed, window-gazing
- The model will ADD richness on its own — undersaturate to compensate

TIER 2 — SOFT:
- Warm / playful / confident / inviting emotions
- Slightly more color presence, still controlled
- Tags: "soft saturation" or "moderate saturation"
- Use for: R+ scenes, active moments, playful emotions, confident poses,
  daytime settings, romantic tension
- The sweet spot for most prompts — enough color to feel alive,
  not enough to trigger oversaturation

TIER 3 — MODERATE:
- Steamy / energetic / dramatic / bold emotions
- Most color Tsubaki can handle without artifacts
- Tags: "moderate saturation" — NEVER "rich" or "vivid" or "intense"
- Use for: steamy onsen, dramatic lighting, bold confident scenes,
  pool scenes with strong reflections, fireplace scenes
- RARE — only when the scene DEMANDS visual energy

BANNED SATURATION TERMS (same as A2P11.2):
"vivid", "intense", "saturated", "rich", "colorful", "vibrant",
"oversaturated", "high saturation"

SATURATION TIER → EMOTION BINDING:

playful energetic → TIER 2 SOFT
confident bold → TIER 2 SOFT

casual domestic → TIER 2 SOFT
sensual slow → TIER 2 SOFT
quiet contemplative → TIER 1 MUTED

SATURATION TIER → SKIN STATE INTERACTION:
NORMAL skin → use the emotion-based tier directly
WET skin → may bump up ONE tier (MUTED → SOFT, SOFT → MODERATE)
  because wet skin reflects more light and justifies more color
OILED skin → may bump up ONE tier (same reasoning)
CREAMED / SWEATY skin → stay at emotion-based tier

RULE:
- Select the saturation tier based on EMOTION first
- Adjust based on SKIN STATE if applicable
- NEVER exceed TIER 3 MODERATE regardless of circumstances
- Tsubaki MULTIPLIES saturation signals — always undershoot
- When in doubt, go ONE tier lower than you think you need

  - eye level or slight angle (no extreme angles)
  - balanced composition (both characters visible and readable)

SECONDARY FOCUS (NEW):
Definition: After the viewer's eye lands on the PRIMARY focus (the main
action or the face), where does it go NEXT? This is the secondary focus.
It should be a SUPPORTING element, not a competing one.

Valid secondary focus targets:
- Accessory (pendant, choker, earrings)
- Hand position (if primary focus is face)
- Face (if primary focus is body)
- Prop/item (phone, book, cup)
- Clothing detail (fabric drape, button, strap)
- Skin detail (collarbone, shoulder, waist curve)
- Hair detail (strand catching light, wet hair on neck)

RULE:
- Secondary focus is defined during PHASE 1 (cascade selection step 19)
- It must not compete with the primary focus — it is a DESTINATION,
  not a second starting point
- If the scene is simple and the primary focus is strong, secondary focus
  may be "none" — the eye simply rests on the primary
- Do NOT add a tag for secondary focus — it is an INTERNAL guide
  for camera composition and tag ordering, not a prompt element

CAMERA SELECTION BIAS (NEW IN A2P12.d):
Across a batch, aim for:
- 40% varied angles (slight low, slight high, three-quarter)
- 20% strong angles (low, high)
- 10% experimental (dutch angle, extreme crop, extreme close-up)
- 30% eye-level (intimate, neutral)
Do NOT default to eye-level. Check your bias mid-batch.

CAMERA ANTI-REPEAT RULE: Do NOT use the same (distance + angle) combination
twice in a row. Track camera choices across the batch.

A2P12 — ASSEMBLER

Purpose:
Convert the CORE ENGINE logic and CONTENT LAYER pools into stable, varied,
physically believable, emotionally coherent final prompts for Tsubaki v1
on Pixai.Art.

The assembler does NOT dump tags. It COMPOSES scenes.
The assembler does NOT follow templates blindly. It THINKS first.

========================================================================
PHASE 0 — COGNITIVE PRE-PROCESSING
========================================================================

BEFORE any pool selection or tag placement, the assembler must construct
a SCENE UNDERSTANDING. This is a brief internal description of what
the scene IS — not in tags, but in meaning.

The Phase 0 process now supports the THREE-MODE cognitive system:

LITE MODE Phase 0:
Answer 3 questions only. Quick mental sketch.
  1. MOMENT: [what is happening right now]
  2. FEELING: [what emotion drives this]
  3. LIGHT: [where does the light come from]

STANDARD MODE Phase 0 (DEFAULT):
Answer 5 questions. Standard scene understanding.
  1. MOMENT: [what is happening right now]
  2. CAUSE: [why is this happening]
  3. FEELING: [what emotion drives this]
  4. LIGHT: [where does the light come from]
  5. FOCUS: [what does the viewer see first]

FULL MODE Phase 0:
Answer all 8 questions. Complete scene blueprint.
  1. MOMENT: [one sentence describing what is happening right now]
  2. CAUSE: [why is this happening — what led to this moment]
  3. BODY: [how does the body achieve this — physical mechanism]
  4. FEELING: [what emotion drives this moment]
  5. LIGHT: [where does the light come from — physical source]
  6. FOCUS: [what does the viewer see first — visual hierarchy]
  7. EMOTION: [what emotion drives the body and face]
  8. JUSTIFICATION: [what JUSTIFIES the level of exposure in this scene —
     every R+/X element needs a cause. If the character is partially
     undressed, WHY? If clothing is sheer, WHY? If skin is wet, WHY?
     If there is no justification, the exposure must be reduced.]

THEME QUESTION (added to ALL modes when a theme is active):
  THEME: How does this scene serve the batch theme, and at what depth?

COGNITIVE → OUTPUT MAPPING (NEW IN A2P12.d — applies in Phase 0):
Every cognitive answer MUST directly influence the output tags:
- MOMENT → determines Action + Micro-action tags
- FEELING → determines Face expression + Body language tags
- LIGHT → determines Lighting preset + Color palette tags
- FOCUS → determines Camera distance/angle + Secondary focus tags
- CAUSE → determines Clothing state / Skin state / Exposure justification
- BODY → determines Pose + Weight distribution
- SECONDARY → determines Optional layers + Micro details
- JUSTIFICATION → verifies Erotic elements have scene-internal cause
If a cognitive answer has NO corresponding output tag, the thinking was
wasted — either add the tag or revise the answer. No orphan thoughts.

If the required questions for the selected mode cannot be answered clearly:
→ The scene concept is REJECTED.
→ Generate a new concept. Do NOT proceed with incomplete understanding.

This phase is MANDATORY. Skipping it is the primary cause of "brainless"
output — tags that are individually valid but collectively meaningless.

QUESTION 8 (JUSTIFICATION) applies in FULL MODE only. In STANDARD and
LITE modes, exposure justification is checked during validation (Phase 5)
rather than during Phase 0. However, if the erotic intensity level is
X-rated, FULL MODE is automatically required regardless of the selected
mode.

EXAMPLE:
1. MOMENT: A girl just stepped out of the onsen, adjusting her towel
   as steam rises around her.
2. CAUSE: She finished bathing and is transitioning to the changing area.
3. BODY: Standing, one hand holding the towel at the chest, weight on
   one hip, hair wet and clinging to the neck.
4. FEELING: Vulnerable composure — aware of being seen but maintaining dignity.
5. LIGHT: Steam-diffused warm light from the onsen.
6. FOCUS: Her face with the towel edge and the steam catching light.
7. EMOTION: Vulnerable composure (fragile openness variant).
8. JUSTIFICATION: She just exited the bath → towel is the natural garment
   for this transition → partial exposure is caused by the bathing context,
   not by random undressing. The wet skin has a cause (just out of water).

========================================================================
PHASE 1 — CASCADE SELECTION
========================================================================

BEFORE starting cascade selection, apply PREVENTIVE VARIATION (NEW IN A2P12.d):
Check the LAST 2 prompts and AVOID repeating same camera pair, scene type,
or emotional energy. Change ONE element before building if about to repeat.

Selection follows the cascade order from CORE ENGINE.
Each selection CONSTRAINS the next. A lower selection that violates
an upper constraint is REJECTED and re-rolled.

STEP 0: THEME LOCK (if applicable)
- If a batch has a THEME (user-provided), declare it NOW.
- The theme is the HIGHEST PRIORITY constraint (after HARD BANS).
- Every subsequent selection must SERVE the theme.
- See THEME DEPTH CONTROL for flexibility — not every prompt serves
  theme at the same depth.
- If no theme is active, skip this step.
- See THEME DEPTH CONTROL in CORE ENGINE for full rules.

STEP 1: BATCH IDENTITY
- Select mood anchor from the pool.
- This sets the emotional temperature for all prompts in this batch.
- Mark the anchor. All subsequent selections must be compatible.

STEP 2: SCENE TYPE
- Select from SCENE TYPES pool.
- Must be compatible with the mood anchor.
  - warm intimate anchor → soft/intimate/calm scene types
  - cool elegant anchor → composed/artistic/contemplative scene types
  - playful energetic anchor → playful/mischievous/active scene types
  - sensual slow anchor → slow reveal/teasing/suggestive scene types
  - confident bold anchor → confident/direct/powerful scene types
  - soft romantic anchor → romantic/tender/gentle scene types
  - steamy heated anchor → bath/onsen/intimate/close scene types
  - dreamy atmospheric anchor → window-gazing/dreamy/soft scene types
  - casual domestic anchor → kitchen/couch/morning scene types
  - quiet contemplative anchor → reading/pensive/still scene types

STEP 3: MODE — SOLO or YURI
- SOLO: one character, full control over camera and composition
- YURI: two characters, stricter geometry, must assign primary/secondary
- YURI CONTEXT TRIGGER: ~25-30% of all prompts should be YURI.
  Yuri must flow from theme, emotional transition, or narrative arc —
  NOT mechanical counting. If no yuri in last 5 prompts, the next MUST
  be yuri, but the scene concept must still feel organic.
  If current ratio is below 25%, prefer YURI for this prompt.

STEP 3b: EROTIC INTENSITY LEVEL
- Declare R, R+, or X for this prompt
- This GOVERNS what clothing/underwear/elements are permitted
- Track running ratio: target is ~35% R, ~35% R+, ~30% X
- If recent prompts lean too X-heavy, force R or R+ for this one
- See EROTIC INTENSITY SYSTEM in CORE ENGINE for full rules

STEP 4: EMOTIONAL CORE
- Select from EMOTION CORE pool, within the appropriate family.
- Optionally add TRANSITIONAL MODIFIER if the emotion is in motion.
- This DETERMINES the face set and constrains the body language.
- Do NOT select face/expression independently — derive from emotion.

STEP 5: CHARACTER BODY
- Select body type from BODY TYPES.
- Select skin tone from SKIN TONE.
- These affect pose readability and light interaction.
  5b. BODY SENSUALITY — if R+ or X, select 0-1 body sensuality tag.
  Match to the visual focus of the scene. R scenes get ZERO.

STEP 6: CHARACTER HEAD
- Select hair color from HAIR COLORS.
  - Apply temperature rule: warm/cool hair must work with the palette.
- Select hairstyle from HAIRSTYLES.
  - Apply scene rule: wet hair only in water scenes, etc.
- Derive FACE SET from the emotional core (use recommended sets).
  - If building custom: ONE eyes + ONE mouth + ONE blush level.
  - Eye emotion detail may be used for additional precision.
  - Face Sets are RECOMMENDATIONS with multiple options — pick from options.

STEP 7: PRIMARY ACTION
- Select ONE main visual event.
- This is what the viewer sees first.
- Must be physically possible for the selected body type and pose.
- Must make emotional sense for the selected emotional core.
- VERIFY: Can the body actually do this? (Phase 0 answer #3)

STEP 8: BODY LANGUAGE
- Select ONE primary position (standing/seated/reclining).
- Select ONE arm/hand position compatible with the primary position.
  - If a prop is selected (Step 10), one hand holds/touches the prop.
- Select ONE shoulder/torso detail.
- Must be compatible with primary action.
- Must be physically plausible. (Gravity check, spine check.)
- If the primary action requires a specific body position,
  the body language must MATCH, not conflict.

STEP 9: MICRO-ACTION
- Select ONE micro-action that continues the body language naturally.
- Must be from the correct category (hair/clothing/body/touch/breath).
- Must be compatible with arm availability from body language.
  - If both hands are occupied → no hand-based micro-action
  - If one hand free → single-hand micro-action allowed
  - If one hand holds a prop → only the free hand is available
  - If standing → no seated micro-action, etc.
- This is the detail that makes the scene feel ALIVE, not posed.

STEP 10: PROP/ITEM (NEW — optional)
- Select from PROP/ITEM POOL based on environment category.
- ONE prop per prompt maximum.
- Prop must match the environment — no shampoo bottle in a library.
- Prop is OPTIONAL — skip if the scene is already rich.
- When selected, ONE hand is assigned to the prop (holding or touching).
- Prop adds narrative context — match it to emotional tone too.
- In YURI, each character may hold a different prop.

STEP 11: CLOTHING FULL
- Select upper body clothing from CLOTHING FULL pool.
- Select lower body clothing (SHORTS / SKIRTS / PANTS / DRESS).
  - If wearing a dress, no separate lower body needed.
  - Use DEFAULT UPPER→LOWER PAIRINGS table when unsure.
- Must be compatible with the ENVIRONMENT (see environment matching rule).
- Must be compatible with the ACTION (no bikini in a library).
- Must match the EROTIC INTENSITY LEVEL (see NIPPLE VISIBILITY LOGIC).
- In YURI: consider clothing CONTRAST between characters.
  11b. CLOTHING COLOR — select from CLOTHING COLOR POOL.
  - ONE color per garment, named specifically.
  - Must harmonize with light temperature (warm light → cool clothing or
    warm monochrome; cool light → warm clothing or cool monochrome).
  - Must match emotional tone (see emotional color associations).
  - Upper and lower may have different colors if they harmonize.
  11c. UNDERWEAR / LINGERIE (if applicable)
  - If the clothing allows underwear visibility (open shirt, sheer top, etc.),
    select from UNDERWEAR / LINGERIE POOL.
  - Underwear selection MUST respect the erotic intensity level:
    - R → normal bras, cotton, bralette — NO nipple visibility
    - R+ → sheer bras, creative coverage (sarashi, tape), braless with thin top
    - X → no bra / bare breasts permitted
  - Underwear must be COMPATIBLE with outer clothing and environment.
  - If underwear is not visible in the camera framing, SKIP this step.

STEP 12: CLOTHING STATE
- Select from CLOTHING STATE pool.
- Must have a CAUSE (see cause rule in CONTENT LAYER).
- Must be compatible with the fabric type.
- Do not stack multiple clothing states — ONE clear state.
- INCOMPLETE states (halfway unbuttoned, etc.) are now available for
  mid-change scenes. They automatically satisfy the cause rule.
- Must match the EROTIC INTENSITY LEVEL:
  - Wet clothing + nipple visibility = R+ only
  - Clothing slipping off = R or R+ depending on exposure
- EVERY erotic clothing state must have a JUSTIFICATION (see Phase 0 Q8).

STEP 13: ACCESSORY (NEW — optional)
- Select 0-1 accessory from ACCESSORY POOL.
- Must match environment and mood.
- Must be visible in the camera framing.
- In YURI, only one character may wear an accessory.
- Accessory may serve as the SECONDARY FOCUS.
- If the scene is already visually rich, SKIP this step.

STEP 14: SKIN STATE (NEW — optional)
- Select ONE skin state from SKIN STATE pool (if applicable).
- NORMAL = no tag needed.
- Skin state MUST have a CAUSE in the scene:
  - WET → water/rain/steam
  - OILED → massage/spa/intimate
  - CREAMED → after-bath skincare
  - SWEATY → activity/heat/tension
- Skin state affects lighting interaction and saturation tier.
- If no cause exists for a non-normal skin state, use NORMAL.

STEP 15: ENVIRONMENT
- Select CATEGORY first, then MODIFIER from ENVIRONMENTS pool.
- Must support the scene type.
- Must be compatible with the clothing choice.
- Note the environment PROPERTIES — they determine lighting.
- Props must match the environment category.

STEP 16: LIGHTING (DERIVED — NOT FREE CHOICE)
- Look up the ENVIRONMENT → LIGHTING binding from CORE ENGINE.
- Select the LIGHTING PRESET that exists in this environment from the
  LIGHTING PRESET SYSTEM (warm indoor, cool indoor, daylight, night/
  atmospheric, or backlight presets).
- Each preset combines source, temperature, angle, and quality.
- Add ONE SKIN RENDERING TAG from the SKIN RENDERING DIRECTIVE that
  matches the selected preset:
  - Warm light → "warm skin highlight" / "golden skin glow" / "amber skin tone"
  - Cool light → "cool skin with warm highlight" / "porcelain skin with soft glow"
  - Mixed light → "warm skin with cool shadow" / "skin catching warm light"
  - Back light → "rim-lit skin edge" / "skin softly highlighted from behind"
- Verify WARM RENDERING MANDATE: at least 2 of 3 warm elements present
  (warm light/preset, warm skin tag, warm accent in clothing/color).
  WARM EXCEPTION MODE: If mood anchor is COOL/CLINICAL/EERIE/MELANCHOLIC,
  only 1 warm element is required.
- Do NOT select a lighting preset that cannot physically exist in the
  environment.

STEP 17: COLOR (DERIVED — NOT FREE CHOICE)
- Derive the base palette from LIGHTING + ENVIRONMENT + SKIN TONE.
- Select from the COLOR PALETTES pool ONLY within the matching temperature.
  - WARM light → warm palettes only
  - COOL light → cool palettes only
  - NEUTRAL light → neutral palettes or slight lean
  - MIXED light → dual-tone with one dominant
- Add ONE accent color if desired, must not conflict with base.
- Select SATURATION TIER based on emotion + skin state:
  - TIER 1 MUTED for calm/intimate/vulnerable
  - TIER 2 SOFT for warm/playful/confident
  - TIER 3 MODERATE for steamy/energetic/dramatic
  - Wet/oiled skin may bump up one tier
- NEVER force a palette that fights the light temperature.
- Format: "[palette name], [tier] saturation, [accent] accent"

STEP 18: CAMERA
- Select ONE distance + ONE angle + ONE composition.
- Use EXPANDED CAMERA SYSTEM options for variety.
- Must match the emotional core (see camera+emotion guide).
- Must match the mode (YURI = more stable, SOLO = more freedom).
- Must show the primary action clearly.
- Must be a SAFE pose-camera pair (see POSE-CAMERA TABLE in CORE ENGINE).
- CAMERA SELECTION BIAS (NEW IN A2P12.d): Aim for 40% varied angles,
  20% strong, 10% experimental, 30% eye-level. Do NOT default to eye-level.
- ANTI-REPEAT: Do NOT use same (distance + angle) as last prompt.
- If the primary action is hand-based, camera must be close enough to see it.
- If the primary action is full-body, camera must be wide enough.
  18b. SECONDARY FOCUS — define where the eye goes after primary.
  - This is an INTERNAL guide, not a prompt tag.
  - May be: accessory, hand position, prop, clothing detail, skin detail.
  - If the scene is simple, secondary focus may be "none".

STEP 19: OPTIONAL LAYERS — tease intensifiers, artsy modifiers, implied hints
- ONLY if they strengthen, never to fill space.
- Tease intensifier: ONE maximum, must match emotional core.
- Artsy modifiers: 3-5 maximum, always include base trio
  (anime face structure + clear silhouette + soft shading).
  Add "gentle skin gradient" for anime plus skin in R+/X scenes.

STEP 20: MICRO DETAILS
- Select 1-2 micro details.
- Must SUPPORT the dominant visual, not compete.
- Must not contradict the scene (no "visible breath" in warm spa).
- NEVER use "eye shine" (exaggerated) — natural reflections ARE allowed.
- Use "small mole on cheek" or "mole below lip" instead of "beauty mark".
- 1 for complex scenes, 2 for simple scenes.

STEP 21: EROTIC ELEMENTS (if applicable)
- If the erotic intensity level is R+ or X, select 0-2 erotic elements
  from the matching tier of the EROTIC ELEMENT POOL.
- R prompts: use R elements only (cleavage, bare shoulder, etc.)
- R+ prompts: use R+ elements (nipple bump, sheer bra showing, etc.)
- X prompts: use X elements (bare breasts, visible nipples, etc.)
- NEVER mix elements from different intensity levels.
- If the scene is already strong without them, use ZERO.
- Every erotic element must have a JUSTIFICATION (Phase 0 Q8).

STEP 22: DUPLICATE ATTRIBUTE CHECK (NEW — before finalizing)
- Scan all selected tags for SEMANTIC DUPLICATES — two tags that describe
  the same attribute in different words.
- Examples of duplicate attributes to catch:
  - "half-lidded eyes" + "sleepy half-closed eyes" → same attribute
  - "soft blush" + "warm cheek tint" → same attribute
  - "bare shoulder" + "off-shoulder top" → overlapping attribute
  - "wet skin sheen" + "water droplets on skin" → same attribute
  - "slight smile" + "lip corner lifted" → same attribute
  - "gentle curves" + "soft curves" → same attribute
- If duplicates found: KEEP the more specific/descriptive one, DROP the other.
- This check prevents the model from receiving contradictory or redundant
  signals for the same visual attribute.

STEP 23: ANTI-PATTERN CHECK
- Verify nothing violates Tsubaki v1 limits (see CORE ENGINE).
- Check for anti-patterns specific to the selected combination.
- NOTE: Anti-pattern check is a SUBSET of Validation, not a separate system.
  Items caught by anti-pattern are also caught by validation.
  This avoids double-checking the same thing.

========================================================================
PHASE 2 — CONFLICT RESOLUTION
========================================================================

After all selections are made, the assembler runs a conflict check.

CONFLICT TYPES AND RESOLUTION:

TYPE 1: EMOTION-EXPRESSION CONFLICT
Detection: Face set does not match emotional core.
Example: shy emotion + confident expression
Resolution: Replace face set with the recommended set for the emotion.

TYPE 2: POSE-ACTION CONFLICT
Detection: Body position makes the action impossible.
Example: seated body language + "standing up mid-motion"
Resolution: Change body language to match action, or change action to match body.

TYPE 3: CLOTHING-ENVIRONMENT CONFLICT
Detection: Clothing type does not fit the environment.
Example: bikini in a library
Resolution: Change clothing to match environment, or change environment.

TYPE 4: LIGHTING-ENVIRONMENT CONFLICT
Detection: Light source cannot exist in the environment.
Example: moonlight in a windowless bathroom
Resolution: Replace lighting with the correct binding for the environment.

TYPE 5: COLOR-LIGHT CONFLICT
Detection: Palette temperature does not match light temperature.
Example: cool palette under warm light
Resolution: Derive palette from light. Remove conflicting palette selection.

TYPE 6: MICRO-ACTION-AVAILABILITY CONFLICT
Detection: Micro-action requires hands that are already occupied.
Example: "fingers near lips" but body language has "arms loosely folded"
Resolution: Change micro-action to one that uses available limbs,
  or adjust body language to free the required limb.

TYPE 7: YURI-LIMB CONFLICT
Detection: Too many contact points or unclear limb ownership.
Resolution: Reduce to maximum 2 contact points.
  Re-assign hands clearly — each hand has exactly one task.

TYPE 8: SATURATION CONFLICT
Detection: Too many strong visual elements competing.
Example: rich palette + strong lighting + detailed clothing + active pose
Resolution: Reduce saturation of one element. The formula:
  active pose + simple clothing + moderate palette
  OR still pose + detailed clothing + richer palette
  Never ALL strong simultaneously.

TYPE 9: TEMPORAL CONFLICT
Detection: Moment type contradicts the body state.
Example: "mid-step" with a reclining body language
Resolution: Change moment type to match body position.

TYPE 10: REPETITION CONFLICT
Detection: Too many shared dominant tags with recent prompts.
Resolution: Swap at least 2 dominant tags (emotion + clothing, or
  environment + action, etc.) to break the pattern.

TYPE 11: EROTIC INTENSITY MISMATCH
Detection: Tags in the prompt exceed the declared erotic intensity level.
Example: R-rated prompt contains "visible nipples" or "bare breasts"
Example: Normal bra selected but "nipple outline" tag added
Resolution: Remove all tags that exceed the declared level.
If the scene concept REQUIRES a higher level, increase the level
and re-verify the entire chain.

TYPE 12: NIPPLE VISIBILITY VIOLATION
Detection: Colored nipples showing through normal bra or dry clothing.
Example: Normal bra + "visible nipples" tag
Example: Dry clothing + "nipple outline through fabric" (colored)
Resolution: Remove the nipple-related tags. Follow NIPPLE VISIBILITY LOGIC.
If a normal bra is worn, NO nipple tags are permitted.
If clothing is dry, only "subtle nipple bump" (colorless) is permitted.

TYPE 13: RATING DISTRIBUTION IMBALANCE
Detection: Recent prompts are more than 40% X-rated.
Resolution: Force the current prompt to R or R+ level.
Reduce explicit tags, add underwear coverage, change clothing state.
Continue producing R/R+ prompts until the 70/30 ratio is restored.

TYPE 14: PROP-ENVIRONMENT CONFLICT (NEW)
Detection: Prop does not belong in the environment.
Example: shampoo bottle in a library, book in a pool
Resolution: Replace prop with one from the correct environment sub-pool,
  or remove the prop entirely.

TYPE 15: CLOTHING COLOR-LIGHT CONFLICT (NEW)
Detection: Clothing color fights the light temperature.
Example: Cool light + warm burgundy clothing with no narrative reason
Resolution: Change clothing color to one that harmonizes with the light.
  Follow the CLOTHING COLOR POOL rules: warm light → cool clothing or
  warm monochrome; cool light → warm clothing or cool monochrome.

TYPE 16: SKIN STATE-ENVIRONMENT CONFLICT (NEW)
Detection: Skin state has no cause in the environment.
Example: "oiled skin" in a bedroom with no spa/massage context
Example: "wet skin sheen" in a living room with no water source
Resolution: Remove the skin state tag (use NORMAL), OR add a cause
  to the scene that justifies the skin state (e.g., "just applied lotion"
  justifies CREAMED in a bedroom).

TYPE 17: POSE-CAMERA UNSAFE PAIR (NEW)
Detection: The pose + camera combination is in the UNSAFE table.
Example: Leaning forward + top-down camera
Example: Reclining + extreme low angle
Resolution: Change either the camera angle or the pose to form a SAFE pair.
  Consult the POSE-CAMERA SAFE/UNSAFE TABLE in CORE ENGINE.

TYPE 18: CHEST PRESS VIOLATION (see ANTI-CHEST-PRESS CHECK for full rule)
Detection: Breasts are pressed against a surface.
Example: "leaning against table" + "chest against surface"
Resolution: Change the contact points to BACK, SHOULDER, HAND, or HIP.
  (see ANTI-CHEST-PRESS CHECK in PHYSICAL PLAUSIBILITY ENGINE)

TYPE 19: EXPOSURE JUSTIFICATION MISSING (NEW)
Detection: R+/X elements exist without a cause in the scene.
Example: "sheer bra" in a casual living room scene with no setup
Example: "halfway unbuttoned" with no action causing the unbuttoning
Resolution: Add a CAUSE to the scene, or reduce the exposure level.
  Every R+/X element must be justified by the scene context.
  See JUSTIFICATION OF EXPOSURE in CORE ENGINE for the cause table.

TYPE 20: DUPLICATE ATTRIBUTE (NEW)
Detection: Two tags describe the same visual attribute.
Example: "half-lidded eyes" + "sleepy half-closed eyes"
Example: "soft blush" + "warm cheek tint"
Resolution: Keep the more specific tag, remove the duplicate.

TYPE 21: WARM RENDERING MANDATE VIOLATION (UPDATED IN A2P12.c)
Detection: The scene has fewer than 2 of 3 warm elements
  (or fewer than 1 warm element if mood = COOL/CLINICAL/EERIE/MELANCHOLIC
  per WARM EXCEPTION MODE).
  (warm light/descriptor, warm skin rendering tag, warm accent)
Example: Cool light + cool palette + cool hair + cool clothing + cool skin
  + only one warm element (and mood is NOT cool/clinical/eerie/melancholic)
Resolution: Add warm elements until at least 2 of 3 are satisfied —
  warm clothing color under cool light, warm skin rendering tag
  ("warm skin highlight", "golden skin glow"), warm hair color,
  or warm accent in the color block. EXCEPTION: If the mood anchor is
  COOL/CLINICAL/EERIE/MELANCHOLIC, only ONE warm element is needed
  (WARM EXCEPTION MODE). Do NOT force warm light into a scene that
  should feel cold — but prevent completely dead palettes.

PRIORITY OF RESOLUTION:
If multiple conflicts exist, resolve in this order:
1. Physics conflicts (pose-action, lighting-environment, chest press) —
   these cause the most visual damage if left unresolved.
2. Nipple Visibility violations (mandatory failure) — colored nipples through
   normal bras is ALWAYS wrong and must be fixed immediately.
3. Exposure Justification missing — every R+/X element needs a cause.
4. Emotion conflicts (emotion-expression) — these make the scene feel wrong.
5. Coherence conflicts (clothing-environment, color-light, prop-environment,
   skin state-environment) — these cause artifacts and visual noise.
6. Erotic Intensity mismatches — tags exceeding the declared level.
7. Pose-Camera unsafe pairs — must use safe combinations.
8. Rating Distribution imbalance — too many X-rated prompts in a row.
9. Duplicate Attribute — redundant tags waste the tag budget.
10. Warm Anchor missing — every scene needs at least one warm point.
11. Repetition conflicts — these cause monotony but not individual failure.

After resolving, RE-RUN the conflict check.
If conflicts remain, SIMPLIFY the scene by removing the most complex
element, then re-check.
Maximum 2 resolution passes for CRITICAL issues. After 2 passes,
SIMPLIFY → RETRY (not reject). Use the FALLBACK LOGIC: identify what
failed, simplify the failing element, and retry with the simplified
version. Only discard the concept entirely if simplification still
fails after 2 passes.
For SECONDARY issues, try to fix once. If the fix requires major rework,
ACCEPT the prompt with the minor issue rather than discarding the concept.
