A2P12 — CORE ENGINE

Purpose:
Build a controlled prompt generation system with a cognitive layer that understands
scene physics, emotional logic, and visual coherence before assembling output.
The system does not combine tags — it composes scenes.

Core principle:
The system THINKS before it BUILDS.
Every prompt is the result of a decision chain that respects physical reality,
emotional consistency, and visual readability.
Tag dumping is a failure mode, not an output mode.

========================================================================
COGNITIVE LAYER — THE THINKING ENGINE
========================================================================

This layer exists between the content pools and the assembler.
It does not generate text. It generates UNDERSTANDING of the scene before
any tag is placed into the prompt.

When the system receives a scene request, it must answer these questions
BEFORE selecting any pool values:

1. WHAT is happening in this scene? (one sentence, physical reality)
2. WHY is the character doing this? (motivation gives the pose meaning)
3. WHERE is the character? (environment determines light and color)
4. HOW does the body actually achieve this pose? (physical plausibility)
5. WHAT does the light do in this space? (light is not decoration — it is physics)
6. WHAT does the viewer see first? (visual hierarchy)
7. WHAT emotion drives the moment? (emotion shapes the body, not the other way)

If any question cannot be answered clearly, the scene concept is rejected
and must be rethought from scratch.

COGNITIVE OUTPUT (internal, not in prompt):
The answers to these 7 questions form a SCENE UNDERSTANDING BLOCK —
a mental model of the scene that persists through all subsequent decisions.

Example of a GOOD scene understanding block:
WHAT: A woman is sitting on the edge of her bed, putting on earrings
WHY: She is getting ready to go out, but the moment captures the pause between private and public
WHERE: Bedroom, evening, warm lamp light from the bedside table
HOW: Seated on mattress edge, one leg tucked under, torso slightly turned toward mirror
LIGHT: Warm lamp from left side, creating half-shadow on the right side of her face
FOCUS: The act of putting on the earring — the hand near the ear, the reflection
EMOTION: Quiet confidence — the calm before stepping into the world

Example of a BAD scene understanding block:
WHAT: A woman is looking sexy in a bedroom
WHY: Because she is hot
WHERE: A room
HOW: Posing
LIGHT: Good lighting
FOCUS: Her body
EMOTION: Attractive

The bad example fails because it has no SPECIFICITY — any image could satisfy it.
The good example describes ONE specific moment in time that the system can
then make decisions about with confidence.

A2P12 NOTE:
The cognitive layer is NOT a bottleneck — it should take a fraction of a second
of processing. It is a structured check, not a creative exercise. The creativity
happens within the constraints, not by bypassing them.

========================================================================
GLOBAL DECISION ORDER (REVISED)
========================================================================

The decision order is a cascade where each decision constrains the next.
A2P12 expands the cascade from 19 to 22 steps to accommodate erotic intensity
placement, prop logic, clothing bottom/top pairing, underwear visibility,
skin state, light angle, body sensuality, and structured quality modifiers.

1. BATCH IDENTITY — mood anchor + optional narrative mode
2. SCENE TYPE — what moment is this
3. MODE — SOLO or YURI
3b. EROTIC INTENSITY LEVEL (R / R+ / X)
4. EMOTIONAL CORE (+ optional counterpoint)
5. CHARACTER BODY — body type, skin tone
6. CHARACTER HEAD — hair color, hairstyle, face expression
   ^ expression derived from emotion, face set is RECOMMENDATION not lock
7. PRIMARY ACTION
8. BODY LANGUAGE
9. MICRO-ACTION (may include incomplete action)
9b. PROP/ITEM (if hands need purpose)
10. CLOTHING FULL + CLOTHING COLOR
10b. CLOTHING BOTTOM (paired with top)
10c. UNDERWEAR (if visible)
11. CLOTHING STATE
11b. SKIN STATE (if applicable)
12. ACCESSORY (optional, 0-1)
13. ENVIRONMENT (category + modifier)
14. LIGHTING + LIGHT ANGLE (derived)
15. COLOR (derived + clothing accent)
16. CAMERA
17. TOUCH/CONTACT
18. MOMENT TYPE
19. MICRO DETAILS (1-2 max)
19b. BODY SENSUALITY (R+/X, 0-1)
20. OPTIONAL TEASE INTENSIFIER
21. EROTIC ELEMENTS (0-2, justified)
22. ARTSY/QUALITY MODIFIERS (3-5)

NOTES ON NEW STEPS:

3b. EROTIC INTENSITY LEVEL:
Declared immediately after MODE so that all subsequent selections
(clothing, clothing state, micro-action, etc.) are constrained by the
governor. This prevents selecting an X-rated clothing state and then
having to downgrade to R.

4. EMOTIONAL CORE (+ optional counterpoint):
The core emotion still drives everything. A2P12 adds the PERMITTED option
of an emotional counterpoint — where the visual expression and the
emotional core are in deliberate tension. This is governed by the
EMOTIONAL COUNTERPOINT system (see Section 26). Not every prompt uses it.
~20-30% max across any batch.

6. CHARACTER HEAD — face set is RECOMMENDATION not lock:
A2P11.2 treated expression as a hard requirement. A2P12 recognizes that
the expression derived from the emotion is the DEFAULT natural mapping,
but permits deviation when justified (counterpoint, narrative arc, etc.).
The binding table is still the primary guide — deviation must be intentional.

9. MICRO-ACTION (may include incomplete action):
A2P12 permits micro-actions that represent the START of a movement, not
just completed movements. "Hand beginning to reach" rather than "hand
reaching." This creates stronger anticipation and narrative feel.

9b. PROP/ITEM (if hands need purpose):
New step. If the micro-action involves hands but lacks a clear target,
or if the scene benefits from an object (glass, book, phone, towel, brush),
a prop may be introduced. Props constrain what hand micro-actions are
valid — you cannot "hold a glass" and "fingers in hair" simultaneously.
Max one prop per scene unless the prop is the scene type (e.g., cooking).

10. CLOTHING FULL + CLOTHING COLOR:
Combined because color is inseparable from the garment choice for
visual coherence. The clothing color choice constrains the COLOR PALETTE
step (step 15) — it becomes the intentional accent or complement.

10b. CLOTHING BOTTOM (paired with top):
New step. In A2P11.2, only "CLOTHING FULL" existed. A2P12 separates top
and bottom to enable proper pairing logic. The bottom must be compatible
with the top in style category (casual/casual, formal/formal, etc.) and
in visual weight. CLOTHING FULL constrains CLOTHING BOTTOM.

10c. UNDERWEAR (if visible):
New step. When clothing state or clothing type makes underwear visible,
it must be selected here. This ties directly to the NIPPLE VISIBILITY
LOGIC and EROTIC INTENSITY LEVEL. If the scene is R-rated and underwear
is a normal bra, no further nipple logic applies.

11b. SKIN STATE (if applicable):
New step. Skin may be dry, damp, wet, glistening (sweat/oil), or
flushed. This constrains how light interacts with the body surface.
Wet skin has specular highlights. Oily skin has intensified reflections.
Flushed skin has localized warmth. This must be physically caused
(just came from water, exertion, heat, embarrassment).

12. ACCESSORY (optional, 0-1):
Moved from implicit to explicit. Accessories are a secondary focal point
and must not compete with the primary focus. They constrain what exists
in the scene — a headband means the hair is styled around it, a necklace
means the collarbone area has a decorative element, glasses change how
the face reads.

14. LIGHTING + LIGHT ANGLE (derived):
Expanded from just "LIGHTING." Light angle is HOW the light hits the
character — separate from direction. Front light, side light, contre-jour,
Rembrandt, top light. Each angle type has an emotion binding. Light angle
constrains what shadow patterns are valid (see Section 18 for full rules).

15. COLOR (derived + clothing accent):
Color is still derived from light + environment, but A2P12 formalizes
the clothing accent as an intentional color choice that must harmonize
with the derived palette. CLOTHING COLOR (from step 10) constrains this.

19b. BODY SENSUALITY (R+/X, 0-1):
New step. For R+ and X prompts, one optional body sensuality tag may be
added to emphasize a body feature in a non-gratuitous way. This is governed
by the WEIGHT CATEGORIES — if a NUCLEAR TAG is present, body sensuality
is redundant and must be skipped.

22. ARTSY/QUALITY MODIFIERS (3-5):
Formalized from the old "OPTIONAL LAYERS" step. These are the final polish
tags — composition, rendering quality, atmosphere, mood words. Exactly
3-5, not more, not fewer. Too few = the prompt feels flat. Too many =
dilution and prompt bloat. These must strengthen the scene, never pad it.

========================================================================
CASCADE RULE — DECISIONS CONSTRAIN DECISIONS
========================================================================

This is the single most important structural rule in the system.

Selections CASCADE — a higher decision constrains lower decisions.
If a lower-level selection contradicts a higher-level constraint,
the lower selection is REJECTED and re-rolled.

EXISTING BINDINGS (from A2P11.2):
- ENVIRONMENT → constrains LIGHTING (only light that exists in this space)
- LIGHTING → constrains COLOR (color follows the physics of the light source)
- CLOTHING FULL → constrains CLOTHING STATE (only states that the fabric can do)
- EMOTION → constrains EXPRESSION and BODY LANGUAGE (they are not independent)
- PRIMARY ACTION → constrains MICRO-ACTION (micro continues the action, not decorates)
- MODE + ACTION → constrains CAMERA (yuri needs wider/more stable framing)
- BODY TYPE → constrains certain poses (some poses read differently on different builds)

NEW BINDINGS (added in A2P12):
- PROP constrains available hand micro-actions (hands holding a glass cannot simultaneously fingers-through-hair)
- CLOTHING FULL constrains CLOTHING BOTTOM (style category must pair, visual weight must balance)
- CLOTHING COLOR constrains COLOR PALETTE (the clothing color becomes part of the palette derivation)
- LIGHT ANGLE constrains what shadow patterns are valid (side light creates half-shadow, front light does not)
- SKIN STATE constrains how light interacts with body (wet skin has specular highlights, dry skin does not)
- ACCESSORY constrains what secondary focal point exists (glasses change face reading, necklace occupies collarbone)

BINDING ENFORCEMENT:
When a lower step's selection is made, the system MUST check it against
ALL constraining bindings from higher steps. If a conflict is found:

1. First attempt: re-roll the lower step with the constraint active
2. Second attempt: adjust the lower step to a compatible alternative
3. Third attempt: flag to the cognitive layer for scene reconsideration
4. If the binding is irreconcilable: the higher step was wrong, re-roll UP

Example: If ENVIRONMENT = "bathroom" and LIGHTING = "moonlight" conflicts
(bathrooms typically don't have moonlight as the primary source unless
the scene specifies it), then LIGHTING must be re-rolled to something
the bathroom actually produces (mirror-reflected daylight, overhead warm, etc.).

The fundamental rule:
Light is physics. Color is the result of light hitting surfaces.
The system does not pick "a color palette" — it derives the palette
from the light source and the environment materials.

USAGE RULE:
1. Select environment first.
2. Look up the binding — this gives you the light source.
3. The color logic column tells you what palette the scene WILL have.
4. Do NOT add a separate COLOR PALETTE selection that contradicts this.
5. If you want a specific palette, you must choose an environment that produces it.
6. You may add ONE accent color that does not conflict with the base logic.

SPECIAL CASE — TIME OF DAY OVERRIDE:
If the environment supports multiple times of day (outdoor, balcony, terrace),
the system must choose the time of day BEFORE selecting light.
Time of day determines the light. Light determines the color.
This is non-negotiable.

SPECIAL CASE — CLOTHING COLOR ACCENT:
A2P12 permits the clothing color (selected at step 10) to act as an
intentional accent within the derived palette. This means:
- If the binding says "warm amber / cream" and the clothing is soft blue,
  the blue becomes a cool accent within the warm scene — this is PERMITTED
- If the clothing is warm-toned, it reinforces the palette — also PERMITTED
- The clothing color must NOT be a third strong color family in an already
  two-tone scene (see ANTI-PATTERNS — "more than two distinct color families")

========================================================================
SKIN TONE LOGIC
========================================================================

Skin tone is a defined character property that interacts with lighting
to produce the final skin rendering.

SKIN TONE POOL (SIMPLIFIED — defined here, used in CHARACTER BLOCK):
fair|medium|tan|dark

REASON FOR SIMPLIFICATION:
The original 24 skin tones caused Tsubaki to multiply skin color tags with
light temperature tags, producing orange/yellow/blue artifacts.
Four basic tones give the model clear direction without chromatic interference.
The lighting + environment system handles the nuance of skin rendering.

SKIN + LIGHT INTERACTION RULES:
- Fair skin under warm light: golden glow, visible blush, warm highlights
- Fair skin under cool light: porcelain, slight blue shadow, muted warmth
- Medium skin under warm light: warm richness, amber highlight, natural depth
- Medium skin under cool light: neutral elegance, subtle contrast, clean shadow
- Tan skin under warm light: sun-kissed warmth, amber-gold highlight, rich depth
- Tan skin under cool light: warm-cool contrast, clean shadow, elegant
- Dark skin under warm light: deep golden highlight, rich warmth, luminous
- Dark skin under cool light: cool depth, blue-silver highlight, striking contrast

The system MUST consider skin tone when selecting lighting and color.
A cool light on fair skin reads very differently from cool light on dark skin.
Both can be beautiful, but they produce different visual sentences.

USAGE:

EMOTIONAL COUNTERPOINT NOTE:
The bindings above are the DEFAULT natural mappings.
A2P12 permits optional counterpoint (~20-30% of prompts) where the visual
and emotion are in tension. See EMOTIONAL COUNTERPOINT section (Section 26).

========================================================================
PHYSICAL PLAUSIBILITY ENGINE
========================================================================

This block solves the "stupid poses" problem.

Before any action + body language + clothing state combination is accepted,
the system must verify:

GRAVITY CHECK:
- Is the center of gravity supported?
- If leaning, what is the character leaning ON?
- If one leg is raised, is the other leg stable?
- If arms are up, does the torso compensate?

SPINE CHECK:
- Can the spine actually bend this way?
- An "arch in the back" is subtle, not acrobatic — unless acrobatics is the scene type
- A "torso twist" rotates the shoulders relative to the hips — max ~45 degrees for natural pose
- "Leaning forward" means the hips go back, or the character is supported

LIMB CHECK:
- How many hands are visible and what is each doing?
- A hand cannot be in two places at once
- If both hands are occupied, there is no free hand for micro-action
- In YURI: count all four hands — each must have a clear task or rest position

CLOTHING PHYSICS CHECK:
- "Slipped to one side" — which side? What caused it? Gravity or motion?
- "Wet fabric clinging" — the fabric follows the body contour, it does not float
- "Open in front" — what holds it? Buttons undone? Belt? Hands?
- "Flowing" — requires air or motion, not just a tag

CONTACT CHECK:
- If the character is sitting, what surface?
- If leaning against a wall, is the wall in the environment?
- If feet are on the floor, is the floor visible or implied?
- In YURI: where do the bodies touch? Where do they NOT touch? Both must be clear.

BREATHING CHECK:
- Does the pose allow breathing?
- Extreme arches or compressions that look suffocating = reject
- "Parted lips" + "arched back" = breath visible, not frozen
- If the chest is compressed against a surface, can the lungs expand?
- Twisted torsos that pinch the diaphragm = reject

PROP CHECK (new in A2P12):
- If a prop is present, is it physically supported?
- A held glass must have a hand gripping it — not floating nearby
- A towel must be on a surface or in hands — not clipped to nothing
- A book must be open at a readable angle or closed and held
- Props interact with clothing — a bag strap crosses the body, glasses
  sit on the nose, a scarf drapes over shoulders

COMPLEXITY BUDGET CHECK (new in A2P12):
The total scene complexity must stay within a manageable budget.
Each element adds complexity:
- Dominant tags: 1 point each (scene type, emotion, action, clothing, environment, light)
- Supporting tags: 0.5 points each (micro-action, clothing state, color accent, camera)
- Nuclear tags: 3 points each (bare breasts, topless, nude)
- YURI mode: +2 points (second character adds exponential complexity)
- Props: +1 point each
- Accessories: +0.5 points each
- Complex clothing (multiple layers, sheer+open, etc.): +1 point
- Emotional counterpoint: +1 point
- Complex camera angle (not standard safe pair): +0.5 points

MAXIMUM COMPLEXITY BUDGET: 10 points
If the scene exceeds 10 points, it must be simplified.
Simplification priority: remove micro tags first, then supporting, then reduce dominant.
Never remove a nuclear tag's visual impact without also simplifying the scene around it.

If any check fails, the system must adjust the pose, not ignore the failure.

========================================================================
YURI COMPOSITION RULES
========================================================================

YURI scenes require stricter geometry than SOLO scenes because two bodies
create exponentially more ways to fail.

POSITION RULES:
- One character is PRIMARY (closer to camera), one is SECONDARY (further)
- The viewer's eye must land on the PRIMARY first
- The SECONDARY must not be occluded — at minimum, face and one hand visible

DEPTH RULES:
- Characters must be on slightly different depth planes — no flat overlap
- If facing each other, their noses must not merge — slight angle offset required
- If side by side, one shoulder slightly forward creates depth

HAND RULES:
- Each character has exactly two hands
- Every visible hand must have a clear purpose: touching, holding, resting, gesturing
- Hands between bodies must not create a "third limb" illusion
- Hands on the partner must show CONTACT POINT clearly

LIMB SEPARATION:
- Arms must not merge visually with the partner's arms
- Use contrast: different skin angle to light, clothing color difference,
  or clear negative space between limbs
- Legs: if seated together, knees point in readable directions, not a tangle

HEAD ANGLE:
- Two faces must not overlap from the camera's perspective
- If close together, one face is slightly turned — profile + three-quarter works
- Forehead-to-forehead: both faces visible, noses offset vertically or horizontally

CLOTHING CONTRAST:
- If both characters wear similar clothing, the scene reads as one mass
- Prefer different clothing or different color for each character
- OR: same outfit type but different clothing state (one buttoned, one open)

EMOTIONAL COUNTERPOINT IN YURI:
Emotional counterpoint is NOT permitted in YURI scenes.
YURI composition is already complex — adding intentional visual/emotional
tension between two characters creates confusion about focus and dynamic.
Both characters' expressions should align with or naturally complement
the scene's emotional core.

========================================================================
WEIGHT CATEGORIES
========================================================================

Not all tags carry equal visual weight. The system must understand
which tags DOMINATE the image and which are SUPPORTING.

DOMINANT TAGS (determine the entire reading of the image):
- scene type
- emotion core
- primary action
- clothing full
- environment
- lighting

SUPPORTING TAGS (refine the dominant tags but cannot override them):
- micro-action
- clothing state
- color accent
- camera detail
- tease intensifier

MICRO TAGS (barely visible but add texture):
- skin glow
- lip shine
- hair strand
- beauty mark
- breath detail

NUCLEAR TAGS (visually override everything — count as +3 visual weight):
bare breasts, topless, nude, exposed breasts
These are so visually dominant that adding them to a complex scene
will make everything else invisible. Use ONLY in simple scenes.

NUCLEAR TAG RULES:
- A nuclear tag in a complex scene (many supporting tags, detailed environment,
  multiple accessories) causes the image to collapse — the nuclear element
  dominates everything and all other carefully chosen tags become invisible.
- Nuclear tags REQUIRE simple composition: minimal environment, simple pose,
  few accessories, one clear focal point.
- If a scene already has 3+ supporting tags and you add a nuclear tag,
  the scene is over-loaded. Either simplify the scene or downgrade the element.
- Nuclear tags count as +3 visual weight for complexity scoring.
  If total visual weight exceeds 10, the scene is too complex.
- In YURI, nuclear tags are EXTREMELY risky — two nude bodies multiply
  complexity exponentially. Only use in the simplest possible compositions.

RULES:
- Dominant tags must all agree with each other. One conflict = scene failure.
- Supporting tags may add nuance but must not contradict a dominant tag.
- Micro tags may be added freely unless they clutter an already complex scene.
- Nuclear tags override everything — they require scene simplification.
- If a scene feels weak, strengthen a DOMINANT tag before adding micro tags.
- If a scene feels cluttered, remove MICRO tags first, then SUPPORTING, never DOMINANT.

========================================================================
ANTI-PATTERNS — TSUBAKI v1.1
========================================================================

These are patterns that consistently produce bad output with Tsubaki v1.1
and must be actively suppressed.

VISUAL ANTI-PATTERNS:
- Multiple strong colored light sources in one scene → color artifacts, glowing edges
- High saturation palette + warm light → oversaturation, skin turns orange
- Very dark environment + bright accent color → halo artifacts, light bleeding
- Cool light + warm palette without transitional tone → muddy midtones
- More than two distinct color families → chromatic chaos

POSE ANTI-PATTERNS:
- Complex hand positions (fingers crossed, intricate grips) → mutated hands
- Extreme foreshortening toward camera → limb proportion collapse
- More than two distinct hand gestures in one character → hand merge / extra fingers
- Torso twisted beyond natural range + arms raised → anatomy collapse
- Sitting pose with both knees up + hands behind → limb confusion
- "chest press", "pressed against glass", "breasts against surface" →
  flat unnatural chest rendering. If leaning, use back/shoulder/arm ONLY.
  This is BANNED at the anti-pattern level.

FACE ANTI-PATTERNS:
- Multiple emotion tags on one face → blank or unreadable expression
- "Looking up" + "looking to the side" simultaneously → cross-eyed or vacant
- Heavy eye detail + heavy mouth detail → face reads as two separate regions
- "Blush" + "pale" + "sweat" simultaneously → skin artifact, splotchy rendering

CLOTHING ANTI-PATTERNS:
- More than two clothing layers described → model flattens or merges them
- "Sheer" + "wet" + "open" on the same garment → overexposure, artifact
- Very detailed fabric description + complex pose → fabric ignores pose
- More than one clothing interaction (unbuttoning + slipping + flowing) → clothing chaos

YURI ANTI-PATTERNS:
- Both characters doing complex poses simultaneously → anatomy collapse
- More than two points of body contact → limb merge
- Identical poses mirrored → mannequin effect, uncanny
- Both characters making intense eye contact with camera → who is the focus?
- One character behind the other with arms around → hidden limb syndrome

STYLE ANTI-PATTERNS:
- "Realistic skin" anywhere → drifts toward photorealism, loses anime identity
- "Manhwa eyes" or "long lash" descriptions → style drift into Korean webtoon
- "Oil painting" or "watercolor" modifiers → fights the anime rendering base
- Too many quality boosters stacked → diminishing returns, prompt bloat
- "flat peach skin" / over-smoothed skin → Tsubaki sometimes drifts toward
  featureless anime skin with no shading variation, making the body look like
  a flat peach-colored surface. This is NOT style drift toward realism — it's
  over-smoothing within anime. Fix: add "subtle skin shading variation" to style block.
- "brushing" in any hand/hair context → Tsubaki SPAWNS a literal hairbrush.
  Use "fingers in hair" or "touching hair strands" instead.

========================================================================
REPETITION RULES — SIMPLIFIED
========================================================================

A2P12 simplifies the 10-dimension tracking from A2P11.2 to 6 key dimensions.
This reduces overhead while maintaining effective variety.

TRACKED DIMENSIONS (6 key):
1. Scene type — do not repeat within 3 prompts
2. Emotion core — do not repeat within 2 prompts
3. Clothing category — do not repeat within 3 prompts
4. Environment category — do not repeat within 4 prompts
5. Lighting type — do not repeat within 3 prompts
6. Camera framing category — do not repeat within 2 prompts

Note: "clothing category" replaces "clothing full" — tracking at the category
level (dress, top+bottom, swimwear, lingerie, etc.) rather than exact garment
prevents cycling while allowing variety within a category.

SOFT TRACKING (should differ, not mandatory):
- hair color, hairstyle, skin tone, body type
- micro-action type, color accent direction
- clothing state, clothing color
- prop/item, accessory, skin state

Soft tracking dimensions should differ from recent prompts but are not
hard-blocked. If a soft dimension repeats, it is acceptable as long as
the 6 key dimensions are all different and cross-dimension tracking passes.

CROSS-DIMENSION TRACKING:
- Same emotion + same camera + same clothing state = feels identical
  even if other dimensions differ
- If two recent prompts share 3+ dominant tags, the next prompt MUST change
  at least 2 dominant tags regardless of individual tracking

WHY SIMPLIFICATION:
The 10-dimension system from A2P11.2 was theoretically comprehensive but
practically difficult to enforce in real-time. Hair color, body type, and
clothing state at the exact-garment level created artificial constraints
that sometimes forced poor selections just to satisfy the tracker.
The 6-key system focuses on the dimensions that most affect visual distinctiveness.

WHAT WAS REMOVED AND WHY:
- Primary action category tracking: actions vary naturally with scene type;
  tracking them separately caused forced action selection that sometimes
  conflicted with the scene concept
- Hair color hard-tracking: moved to soft tracking because hair color
  alone does not make two prompts feel identical — it's the combination
  that matters
- Body type hard-tracking: moved to soft tracking for the same reason;
  two different body types in the same scene/emotion/environment read
  as variations, not repetition
- Clothing state hard-tracking: moved to soft tracking; clothing state
  naturally varies with action and clothing choice, so it rarely repeats
  without other dimensions also repeating

ENFORCEMENT:
After each prompt is assembled, the system checks:
1. Does this prompt's scene type match any of the last 3 prompts? → FAIL if yes
2. Does this prompt's emotion core match the last 2 prompts? → FAIL if yes
3. Does this prompt's clothing category match any of the last 3 prompts? → FAIL if yes
4. Does this prompt's environment category match any of the last 4 prompts? → FAIL if yes
5. Does this prompt's lighting type match any of the last 3 prompts? → FAIL if yes
6. Does this prompt's camera framing match the last 2 prompts? → FAIL if yes
7. Does this prompt share 3+ dominant tags with any single recent prompt? → FAIL if yes

========================================================================
VARIATION SYSTEM (REVISED)
========================================================================

Variation must be enforced across ALL of these, not just some:

STRUCTURAL VARIATION (must change):
- scene type
- emotional temperature (warm / cool / tense / calm)
- action dynamics (still / slow / active / turning)
- interaction mode (self-contained / toward viewer / toward partner)

VISUAL VARIATION (must change):
- face shape and expression family
- hair color and style
- body type
- clothing category
- environment category
- lighting direction and quality

COMPOSITIONAL VARIATION (must change):
- camera distance and angle
- body orientation to camera
- clothing state behavior
- depth and layering

EMOTIONAL VARIATION (must change):
- emotional intensity level
- tension direction (inviting / retreating / holding / releasing)
- vulnerability level (exposed / guarded / balanced)

A2P12 NOTE:
The variation system works in concert with the simplified repetition tracker.
The 6 key tracked dimensions correspond to the most impactful visual variation
axes. Soft-tracked dimensions provide additional texture when they differ.
Cross-dimension tracking catches composite repetition that individual
dimension tracking misses.

VARIATION WITHIN NARRATIVE BATCHES:
If a batch uses NARRATIVE MODE (see Section 27), variation is relaxed
SLIGHTLY — the narrative may justify repeating a lighting type or environment
as the "story" continues. However, the 6 key dimensions must still show
net variation across the full batch. No two consecutive narrative prompts
should share more than 2 key dimensions.

========================================================================
BATCH DIVERSITY RULES (REVISED)
========================================================================

Each batch must have a MOOD ANCHOR — a dominant emotional temperature
that flavors the entire batch.

BATCH MOOD ANCHOR POOL:
warm intimate / cool elegant / playful energetic / quiet contemplative /
sensual slow / confident bold / soft romantic / steamy heated /
dreamy atmospheric / casual domestic

RULES:
- A batch may contain 3–7 prompts
- All prompts in a batch share the mood anchor at their foundation
- But each prompt within the batch must still vary on all tracked dimensions
- The next batch MUST use a different mood anchor
- Adjacent batches must differ in at least 4 dominant dimensions
- No two adjacent batches may share the same lighting type as primary

BATCH NARRATIVE MODE (new — optional):
- Prompts within a batch MAY form a sequential mini-story (3-5 prompts)
- Not mandatory — use when it adds life
- Each narrative prompt still varies on all tracked dimensions
- Mood anchor still applies, emotion can evolve across narrative
- If last batch was narrative, current should probably NOT be
- The narrative must have a clear arc: beginning → escalation → resolution
  or beginning → tension → release, etc. Not just "same scene, different angle."
- The last prompt in a narrative batch may transition toward the next
  batch's mood anchor — this is the ONE exception to "next batch must differ"
- Narrative batches count as +1 complexity for the system — the assembler
  must track not just individual prompt variation but story progression

========================================================================
MODE LOGIC (REVISED)
========================================================================

SOLO:
- Focus: one character's body language, expression, presence
- Camera may be more intimate and more experimental
- Clothing interaction is with self only
- Emotion is projected toward the viewer or inward
- Body language must tell the entire story alone

YURI:
- Focus: interaction, proximity, emotional exchange
- Camera must be more stable — wider framing, simpler angles
- Clothing interaction may be between partners
- Emotion is shared or contrasted between two characters
- Body language must be readable for BOTH characters simultaneously
- ALWAYS assign: primary character (closer to camera) + secondary character
- ALWAYS define: contact points, gaze direction, emotional dynamic
- Simple geometry is MANDATORY — complex compositions fail

========================================================================
MOTION LOGIC (REVISED)
========================================================================

Every scene must contain a visible MOMENT — a point in time that implies
what came before and what comes after.

STATIC FAILURE: A pose that could exist forever with no tension is not a scene.
It is a mannequin display.

MOMENT TYPES:
- Mid-action: caught during movement (turning, standing up, reaching)
- Held breath: still but with visible tension (about to move, just stopped)
- Transition: between two states (clothing shifting, weight transferring)
- Aftermath: just after something happened (hair settling, breath releasing)
- Anticipation: about to do something (hand raised, lean beginning)

Each scene must be classifiable into one of these moment types.
If it cannot be classified, it is too static and must be revised.

A2P12 NOTE — INCOMPLETE ACTIONS:
A2P12 permits micro-actions that are INCOMPLETE — the beginning of a movement
rather than the completion. "Hand beginning to reach toward the glass" rather
than "hand holding the glass." This creates stronger narrative feel and
anticipation. The key is that the INCOMPLETE action must be physically readable
— the viewer must understand what is about to happen, even though it hasn't
happened yet. This is different from ambiguity. Ambiguity = unclear. Incomplete
= clear intent, not yet realized.

========================================================================
ENVIRONMENT LOGIC (REVISED)
========================================================================

Environment is not scenery. It is a PHYSICAL SPACE that the character occupies.

RULES:
- The character must INTERACT with the environment (sit on, lean on, stand near)
- If the environment is not important to the scene, it should be minimal
- Never describe environment details that are not lit or not in frame
- Environment materials affect the light (white walls reflect, wood absorbs, water reflects)
- A scene with a complex environment needs simpler posing
- A scene with complex posing needs a simpler environment

ENVIRONMENT + PROP INTERACTION:
Props introduced at step 9b must be ENVIRONMENTALLY PLAUSIBLE.
A wine glass in a bedroom is odd but possible. A wine glass at the beach is strange.
A towel in a bathroom is natural. A towel in an office is specific but needs cause.
If a prop does not fit the environment, either change the prop or change the
environment. Do not force it.

========================================================================
LIGHTING LOGIC (REVISED)
========================================================================

Lighting is PHYSICS, not decoration.

RULES:
- One light source concept per scene (secondary fill is allowed but must be subtle)
- The light source must EXIST in the environment (window, lamp, sun, moon, candle)
- Light has DIRECTION — it comes from somewhere and creates shadow opposite
- Light has TEMPERATURE — warm sources produce warm highlights and cool shadows
- Light has QUALITY — direct is hard, diffused is soft, reflected is gentle
- Light has ANGLE — how the light hits the character (see LIGHT ANGLE below)
- Skin reflects light differently based on skin tone (see Skin Tone Logic)
- Colored light tints everything — do not add a separate "color palette" that fights the light

COLOR ARTIFACT PREVENTION:
- If the light is warm, the palette is warm. Accent cool tones are acceptable
  ONLY as shadow tones, never as equal-weight color
- If the light is cool, the palette is cool. Warm accents only in skin and hair
- Do not mix two strong colored lights — this causes edge artifacts in Tsubaki
- Keep saturation controlled: the model adds saturation on its own,
  your prompt should stay moderate
- Avoid "neon" anything unless the scene specifically calls for it
  and the environment supports it
- Avoid "glowing" effects on skin — Tsubaki interprets this as light bloom artifacts

LIGHT ANGLE:
Light has ANGLE — HOW it hits the character. This is separate from direction.
Direction tells you where the light comes FROM. Angle tells you how it
interacts with the character's form.

ANGLE TYPES:

FRONT LIGHT:
Light hits the character from the front. Flat, even illumination with minimal
shadows. Safe choice. Best for confident, playful, casual moods where the
character should be fully visible and approachable.
Shadow behavior: soft shadows behind the character, minimal modeling shadows on face.

SIDE LIGHT:
Light hits the character from one side (typically 45-90 degrees). Creates
dramatic half-shadow on the opposite side. Best dimensionality and depth.
Best for intimate, romantic, mysterious moods where you want the body to
have form and volume.
Shadow behavior: one side of face and body in shadow, strong modeling.

BACK LIGHT / CONTRE-JOUR:
Light comes from behind the character. Creates silhouette effect with rim
light outlining the form. Best for vulnerable, mysterious, ethereal moods.
The face may be partially or fully in shadow.
Shadow behavior: face in shadow, body outline defined by rim light, dramatic.

REMBRANDT:
Named after the painter's characteristic lighting. Light from above and to
one side, creating a triangle of light on the cheek opposite the source.
Cinematic and dramatic. Best for dramatic, tense, powerful moods.
Shadow behavior: triangle of light on cheek, deep shadows, highly modeled.

TOP LIGHT:
Light from directly above (overhead lamp, skylight, noon sun). Creates
dramatic shadows under the eyes, nose, and chin. Best for mysterious,
overhead lamp scenes, nocturnal moods.
Shadow behavior: shadows under facial features, downward shadow on body.

ANGLE → EMOTION BINDING:

Intimate/warm → soft side light
The side light wraps around the body, creating depth and closeness.
The half-shadow suggests privacy — not everything is revealed.

Vulnerable/thoughtful → contre-jour
The silhouette effect makes the character look exposed yet protected
by the light outline. The face in shadow suggests introspection.

Confident/playful → front light + fill
Even illumination shows the character fully — nothing hidden, nothing
to hide. The openness of the light matches the openness of the pose.

Dramatic/tense → Rembrandt or strong side
The triangle of light or dramatic split creates a cinematic quality
that reads as serious, intentional, powerful.

EXPERIMENTAL WARNING:
Light angle is a powerful tool but can cause artifacts in Tsubaki if pushed
too hard. If contre-jour creates a completely black face with no features,
fall back to side light with a fill. If Rembrandt creates harsh shadows
that lose facial detail, fall back to soft side light. The angle should
ENHANCE the scene, not destroy readability.

========================================================================
COLOR LOGIC (REVISED)
========================================================================

Color is DERIVED, not selected.

DERIVATION RULE:
1. Environment determines available light sources
2. Light source determines color temperature
3. Color temperature determines the base palette
4. Skin tone + hair color add natural warmth or cool contrast
5. Clothing color is the ONE place you may introduce intentional color choice
6. Accent color (if any) must harmonize with the derived palette

PERMITTED ACCENT LOGIC:
- Warm scene: ONE cool accent (e.g., blue accessory, cool shadow tone)
- Cool scene: ONE warm accent (e.g., warm hair, amber reflection)
- Neutral scene: ONE color accent of any temperature

SATURATION CONTROL (3-LEVEL SYSTEM):
A2P12 replaces flat "desaturated" with 3 levels tied to emotion.

LEVEL 1 — MUTED (base default):
For calm, intimate, contemplative scenes.
Tag: "muted" — NOT "desaturated" (muted preserves warmth)
This is the safest choice. Tsubaki adds saturation on its own, so starting
at muted gives the model room to breathe. Use when in any doubt at all.

LEVEL 2 — SOFT (new default for most scenes):
For warm, playful, relaxed, casual, gentle scenes.
Tag: "soft" or "soft saturation" — alive but not vivid
This is the default for scenes that should feel warm and inviting without
being intense. It sits between muted and moderate. Most prompts should
land here unless the emotion specifically calls for lower or higher.

LEVEL 3 — MODERATE:
For steamy, energetic, confident, bold scenes.
Tag: "moderate saturation" — highest allowed
This is ONLY for scenes where the emotional intensity demands visual richness.
Steamy heated mood, confident bold mood, energetic playful mood. Use sparingly.

STILL BANNED: "vivid", "intense", "saturated", "rich", "colorful", "vibrant", "desaturated"

WHY REPLACE "DESATURATED":
"Desaturated" sometimes caused Tsubaki to remove ALL warmth from the image,
producing cold, grey, lifeless results. "Muted" preserves warmth while
controlling saturation — it says "keep the warm tones, just dial them down."
The 3-level system gives the assembler a more nuanced tool than a binary
desaturated/not-desaturated choice.

SATURATION LEVEL SELECTION GUIDE:
- Calm + indoor + evening → LEVEL 1 (muted)
- Intimate + warm light + relaxed → LEVEL 1 (muted) or LEVEL 2 (soft)
- Playful + casual + daytime → LEVEL 2 (soft)
- Warm + gentle + soft lighting → LEVEL 2 (soft)
- Steamy + close camera + warm light → LEVEL 2 (soft) or LEVEL 3 (moderate)
- Confident + bold + direct light → LEVEL 3 (moderate)
- Energetic + bright light + active → LEVEL 3 (moderate)
- When in doubt → LEVEL 1 (muted) or LEVEL 2 (soft), never LEVEL 3

WARM ANCHOR RULE:
Every prompt must have at least ONE warm element, even in cool scenes.
Cool light + warm skin highlight. Cool palette + warm hair/clothing accent.
Never allow completely cold palette without warm anchor.
This prevents the "pale/washed out" problem.

Examples:
- Cool blue light scene → the character's skin retains natural warmth,
  or a warm-toned clothing piece provides the anchor
- Grey overcast scene → the character's hair color or a wooden surface
  in the environment provides warmth
- Night/moonlight scene → a warm lamp in the background, or the character's
  skin catching the moonlight with its natural warmth

If the entire palette reads as cold with no warm element whatsoever,
the system MUST add one. This is non-negotiable.

========================================================================
STYLE LOGIC (REVISED)
========================================================================

The system must maintain clean anime presentation throughout.

LOCK POINTS (never override):
- anime face structure: large eyes, small nose, defined but soft jawline
- smooth cel-shading style skin — not realistic pores, not oil painting
- clean lineart presence — not sketchy, not painterly
- hair rendered as shaped volumes with highlight, not individual strands
- eyes are the emotional center — they must be expressive and clear

DRIFT PREVENTION:
- If the model drifts toward manhwa: add "anime face structure, small nose"
- If the model drifts toward realism: add "smooth anime shading, cel-shaded skin"
- If the model drifts toward painterly: add "clean lineart, defined edges"
- If skin becomes flat/peach-toned (Anime Plus drift):
  add "subtle skin shading variation" to style block
  This maintains anime style WITH proper shading — NOT realism
  The key distinction: "subtle skin shading variation" tells the model to add
  light/shadow variation to skin while keeping the anime rendering base.
  It does NOT mean "add realistic skin texture." The skin stays smooth and
  cel-shaded, but it has variation in value (light/dark) across the surface.
- These corrections should be in the STYLE BLOCK, not scattered

STYLE TAG BUDGET:
The style block should contain 3-5 style tags maximum. Overloading the
style block dilutes each tag's effectiveness and creates conflicting
directions. Recommended structure:
1. Base style confirmation (1 tag): "anime style" or "cel-shaded"
2. Skin rendering (1 tag): "smooth anime shading" or + drift correction
3. Line quality (1 tag): "clean lineart" or "defined edges"
4. Optional atmosphere (0-1 tags): "soft focus background" etc.
5. Optional quality (0-1 tags): "detailed eyes" etc.

========================================================================
VALIDATION LOGIC (REVISED)
========================================================================

Before a prompt is finalized, the system runs a FULL validation chain.
A2P12 uses the updated 22-step cascade as the reference.

LEVEL 1 — COHERENCE:
- Does the scene have one clear focus?
- Do all dominant tags agree with each other?
- Does the emotion match the expression and body language?
- Does the clothing make sense in the environment?
- If emotional counterpoint is used, is it readable as intentional tension?

LEVEL 2 — PHYSICS:
- Is the pose physically possible?
- Does the lighting exist in this environment?
- Does the clothing state have a physical cause?
- Is the center of gravity supported?
- If a prop is present, is it physically supported and placed?
- Does the skin state have a cause (water, heat, exertion)?

LEVEL 3 — COLOR:
- Is the palette derived from the lighting?
- Are there conflicting color temperatures?
- Is saturation at the correct 3-level setting for the emotion?
- Is the warm anchor present?
- Are there any anti-pattern violations?

LEVEL 4 — STYLE:
- Is the anime identity stable?
- Are there any drift triggers?
- Is the face structure protected?
- Is skin shading variation present (to prevent flat peach drift)?

LEVEL 5 — VARIATION:
- Does the scene differ from recent prompts on the 6 key tracked dimensions?
- Is there composite repetition (3+ dominant tags shared)?
- Is the batch mood anchor respected?
- If in a narrative batch, does the story progress while maintaining variation?

LEVEL 6 — MODEL SAFETY:
- Are there any Tsubaki v1.1 anti-pattern violations?
- Are hand positions simple enough?
- Is the Yuri composition geometrically clear?
- Are there too many competing visual elements?
- Does the visual weight stay within bounds (nuclear tag check)?
- Is the pose-camera combination safe (see SAFE/UNSAFE table)?
- Are nipple visibility rules followed per the EROTIC INTENSITY LEVEL?
- Is every R+/X element justified (see JUSTIFICATION OF NUDITY)?

FAILURE RESOLUTION (step by step):
If validation fails at any level:

LEVEL 1 failure → rethink the scene concept from emotion
LEVEL 2 failure → simplify the pose, reduce body language complexity
LEVEL 3 failure → remove color palette, derive from light + environment only
LEVEL 4 failure → add style lock tags, remove drift triggers
LEVEL 5 failure → swap dominant tags to break repetition pattern
LEVEL 6 failure → simplify the entire scene — reduce element count

After fixing, re-run validation from the failed level up.
Do not skip levels.

OUTPUT RULE
========================================================================

The final output must be a sequence of prompts that feel intentional, varied,
physically believable, emotionally coherent, and visually strong.

Every prompt must pass all six validation levels.

The system does not output until it has THOUGHT about the scene,
UNDERSTOOD the physical and emotional logic, and VERIFIED the result.

Tag dumping is a critical failure.
Physical impossibility is a critical failure.
Color contradiction is a critical failure.
Style drift is a critical failure.
Composite repetition is a critical failure.
Unjustified nudity is a critical failure.
Nuclear tag in complex scene is a critical failure.

========================================================================
EROTIC INTENSITY SYSTEM
========================================================================

Every prompt must declare an EROTIC INTENSITY LEVEL before assembly.
This level determines what body/clothing/element combinations are permitted.
It is NOT a separate tag — it is a GOVERNOR that constrains the entire prompt.

The intensity level is declared at step 3b of the cascade, immediately after
MODE. This ensures all subsequent selections (clothing, clothing state,
underwear, skin state, micro-action, erotic elements) are constrained.

LEVELS:

R — SUGGESTIVE:
Character is fully clothed or in normal underwear. No nipple visibility.
Erotic charge comes from pose, expression, clothing state, and atmosphere.
The IMPLICATION is erotic; the visual is clothed.

PERMITTED: cleavage, thigh exposure, suggestive pose, sheer fabric (without
nipple visibility), clothing slipping off one shoulder, unbuttoned shirt,
braless with only the faintest nipple bump through fabric (NOT colored),
teasing expression, strategic camera angle.

NOT PERMITTED: visible nipples (colored), bare breasts, sheer bra showing
nipple color, explicit sexual poses.

R+ — EROTIC:
Character shows partial or strategic exposure. Nipple visibility is
CONDITIONAL on clothing type and state (see NIPPLE VISIBILITY LOGIC below).
The visual is explicitly erotic but not fully explicit.

PERMITTED: nipple outline through thin clothing (small bump, colorless),
nipple outline through wet clothing (colored, visible),
sheer bra showing nipple color (INTENTIONAL selection),
strategic coverage (sarashi, tape, pasties),
bare shoulders/collarbone with partial breast exposure from angle,
visible bra through translucent top,
partial breast exposure from clothing state (one side slipped, etc.).

NOT PERMITTED: fully bare breasts with visible nipples, explicit sexual acts.

X — EXPLICIT:
Character is partially or fully topless with direct nipple visibility.
This is the HIGHEST intensity and must be used SPARINGLY.

PERMITTED: bare breasts, visible nipples (direct, no covering),
topless with arms crossing for partial cover,
very explicit poses.

NOT PERMITTED: sexual acts beyond the scope of this system.

DISTRIBUTION TARGET (CRITICAL):
R:   ~35% of all prompts
R+:  ~35% of all prompts
X:   ~30% of all prompts

This means approximately 70% R/R+ and 30% X.
If more than 40% of recent prompts are X-rated, the next prompts MUST
be R or R+ until the balance is restored.
Track this across the batch — not per-prompt, but as a running ratio.

INTENSITY AND NUCLEAR TAGS:
X-rated scenes that include nuclear tags (bare breasts, topless, nude)
are the HIGHEST visual weight combinations. They require the simplest
possible composition. See WEIGHT CATEGORIES — NUCLEAR TAGS.

========================================================================
NIPPLE VISIBILITY LOGIC (CRITICAL — READ CAREFULLY)
========================================================================

This block solves the problem of colored nipples showing through bras
and clothing when they should not, which inflates the X-rating and
produces unrealistic results.

FUNDAMENTAL RULE:
Nipple visibility is CONDITIONAL on what the character is wearing
and the STATE of that clothing. It is NEVER automatic.

RULE 1 — NORMAL BRA (non-sheer, non-wet):
A normal bra covers the nipple completely. NO nipple visibility through it.
- Lace bra (opaque cups): NO visibility
- Sports bra: NO visibility
- Push-up bra: NO visibility
- Bralette: NO visibility
- ANY bra with solid/padded cups: NO visibility
The model should NOT render nipples showing through a normal bra.
Do NOT add any nipple-related tags when a normal bra is worn.

RULE 2 — SHEER BRA (intentional R+ selection):
If the scene INTENTIONALLY selects a sheer or semi-sheer bra,
nipple color MAY be visible through the fabric.
- Sheer lace bra: nipple color visible through lace pattern
- Mesh bra: nipple visible through mesh
- Semi-transparent bra: nipple outline with faint color
This MUST be an INTENTIONAL selection in the underwear pool,
not a default or accidental outcome.
Tag: "sheer bra" or "lace bra, visible through fabric"

RULE 3 — DRY CLOTHING WITHOUT BRA (braless):
Through dry clothing, only a small BUMP is visible — NOT colored.
- Thin top, no bra: subtle nipple bump through fabric (colorless, barely visible)
- Thick clothing, no bra: no visibility at all
- Fitted top, no bra: small protrusion visible, but NO color
This is R territory, NOT X. The bump is a physical shape, not a visual detail.
Tag: "subtle nipple bump" or "nipple outline through thin fabric"
Do NOT use "visible nipples" for this — that implies colored visibility.

RULE 4 — WET CLOTHING:
Wet fabric becomes translucent. Nipple color MAY be visible.
- Wet white top: nipple color visible through wet fabric
- Wet thin fabric: nipple outline and color showing
- Wet swimwear: may show nipple outline
This is R+ territory. The wetness is the CAUSE — water must be in the scene.
Tag: "wet clothing, nipple outline visible" or "wet fabric clinging, visible through"

RULE 5 — BARE BREASTS (X-rated):
Direct nipple visibility with no covering.
This is ONLY for X-rated prompts.
Tag: "bare breasts" or "exposed breasts, visible nipples"

RULE 6 — CREATIVE COVERAGE (R+):
Nipple is covered but the breast is partially visible.
- Sarashi: breast partially wrapped, nipple hidden under fabric
- Black tape / cross tape: nipple covered, breast visible around tape
- Pasties: nipple covered, surrounding breast visible
- Ribbon tie: strategic cover, breast mostly visible, nipple hidden
This is R+ territory — erotic but not explicit.
Tag: "sarashi", "nipple tape", "cross tape", "pasties"

SUMMARY TABLE:
CLOTHING STATE               | NIPPLE VISIBILITY  | RATING
Normal bra                   | NONE               | R
Sheer/semi-sheer bra         | Color through lace | R+
Dry clothing, no bra         | Small bump only    | R
Wet clothing                 | Color visible      | R+
Bare breasts                 | Direct visibility  | X
Creative coverage (tape etc) | Hidden, breast vis | R+

VIOLATION CHECK:
Before finalizing any prompt, verify:
- If a normal bra is worn → NO nipple tags in the prompt
- If clothing is dry → NO "visible nipples" tag (only "subtle bump" if thin)
- If wet → nipple visibility is acceptable IF it matches the erotic level
- If X-rated → bare breasts tags are acceptable
- If R-rated → absolutely NO visible nipples (colored or otherwise)

This check is MANDATORY and must pass before the prompt is output.

========================================================================
JUSTIFICATION OF NUDITY — NEW
========================================================================

Every R+/X element must have a JUSTIFIABLE CAUSE.
The element does not appear randomly — something in the scene EXPLAINS
why the character is in this state of undress or exposure.

JUSTIFICATION TABLE:

Element                          | Valid Cause(s)
Wet clothing sheer               | WATER (rain, shower, pool, onsen)
Towel slipping                   | MOVEMENT (reaching, turning, standing)
Shirt unbuttoned                 | HEAT (warm room, exertion, after bath)
No bra under thin top            | MORNING CASUAL (waking, lazy day)
Sarashi unwrapped                | ACTIVITY (martial arts, exercise, bath prep)
Clothing sliding off shoulder    | MOVEMENT or LOOSE FIT
Bra visible through top          | INTENTIONAL (chose sheer/thin top)
Bare breasts                     | BATH or PRIVATE (shower, changing, alone)
Topless with cover               | INTIMATE SETTING (bedroom, after intimacy)
Strategic clothing dishevelment  | JUST WOKE UP / JUST ARRIVED
Cleavage emphasis                | CLOTHING DESIGN (low-cut, unbuttoned)

RULES:
1. The justification is a THINKING step, not a tag. It does not appear in
   the output prompt. It validates WHY the element exists in the scene.
2. If no cause exists in the scene for an R+/X element, the element must be
   REMOVED or DOWNGRADED to a lower intensity level.
3. The cause must be physically present in the scene — water visible, heat
   implied, movement in progress, private setting established.
4. "Because it looks good" is NOT a valid justification.
5. Justification must be checked at LEVEL 6 of validation (MODEL SAFETY).

EXAMPLES OF VALID JUSTIFICATIONS:
- "Wet shirt clinging, nipple outline visible" → VALID because water is
  in the scene (shower, pool, rain). The wetness is the cause.
- "Unbuttoned shirt, cleavage visible" → VALID because the scene is
  after a bath or in a warm room. Heat or post-bath is the cause.
- "Sarashi unwrapping, partial breast visible" → VALID because the
  character is in the middle of physical activity or transitioning.

EXAMPLES OF INVALID JUSTIFICATIONS:
- "Walking in a park, topless" → INVALID. No cause for being topless
  in a public setting. REMOVE or DOWNGRADE.
- "Office scene, no bra, visible nipples through shirt" → INVALID.
  An office setting does not justify going braless in thin clothing
  unless the narrative specifically explains it (e.g., she just got
  splashed, she's changing, etc.).

CONFLICT RESOLUTION:
If the desired R+/X element cannot be justified in the current environment,
the system has three options:
1. Change the environment to one where justification exists
2. Downgrade the element to a lower intensity that fits
3. Remove the element entirely

Option 1 is preferred when the scene concept is strong. Option 2 or 3
when the environment is essential to the scene's mood or narrative.

========================================================================
EMOTIONAL COUNTERPOINT — NEW
========================================================================

Most memorable images have emotion and visual in tension.
Emotional counterpoint is the DELIBERATE creation of this tension — where
the character's expression or body language does not match the stated
emotional core, creating a more complex, intriguing image.

DEFINITION:
Emotional counterpoint = the visible expression/body and the emotional core
are in deliberate, readable tension. Not confusion — TENSION.

PERMITTED FREQUENCY:
~20-30% of prompts maximum across any batch.
If last 3 prompts used counterpoint, the next MUST NOT.
This prevents counterpoint from becoming the default and losing its impact.

NOT PERMITTED:
- In YURI scenes (already complex enough with two characters)
- When the scene is already complex (many elements, detailed environment)
- When the viewer cannot READ the tension (it just looks confused)

EXAMPLES OF VALID COUNTERPOINT:

Vulnerable expression + confident pose:
The character's face shows uncertainty, but her body language is open and
commanding. This creates a "brave but scared" reading — powerful.

Shy gaze + open clothing:
The character looks away or downward, but her clothing is revealing.
This creates a "doesn't want to be seen but is" tension — intimate.

Sleepy softness + bright light:
The character's expression is heavy-lidded and drowsy, but the scene is
brightly lit. This creates a "just woken up" morning feeling — gentle.

Confident smile + something slipping:
The character is smiling boldly, but a clothing element is sliding out
of place. This creates a "composure cracking" moment — playful.

Quiet sadness + warm environment:
The character's expression is distant or melancholic, but the setting
is warm and comfortable. This creates a "safe space to feel" mood — deep.

RULES FOR IMPLEMENTATION:
1. The emotional core is still the PRIMARY driver — counterpoint is the
   secondary layer. The emotion determines the SCENE, the counterpoint
   determines the EXPRESSION.
2. The tension must be READABLE within 2 seconds of viewing. If the viewer
   needs to analyze it, the counterpoint has failed and looks like a mistake.
3. One axis of counterpoint per prompt maximum. Do not stack multiple
   tensions (expression vs body vs environment all in conflict = chaos).
4. The counterpoint must be TRACKED — if overused, it becomes the new
   default and loses its power. The system must monitor frequency.
5. After a counterpoint prompt, the next 2 prompts should use standard
   emotion→body alignment to "reset" the visual language.

COUNTERPOINT TRACKING:
Maintain a rolling window of the last 5 prompts:
- Count how many used counterpoint
- If count >= 2, next prompt MUST use standard alignment
- If count >= 3 consecutive, this is a failure — re-roll the latest
- Across any batch of 7+ prompts, counterpoint should appear 1-3 times max

========================================================================
BATCH NARRATIVE MODE — NEW
========================================================================

Optional: prompts within a batch MAY form a sequential mini-story.

STRUCTURE:
- A narrative arc spans 3-5 prompts within a batch
- Not mandatory — use when it adds life to the batch
- Each prompt in the narrative still varies on all 6 key tracked dimensions
- The mood anchor still applies to the overall narrative
- Emotion CAN evolve across the narrative arc (e.g., shy → confident)

NARRATIVE ARC TYPES:

escalation arc:
Calm beginning → building tension → peak moment → soft landing
Example: reading quietly → looking up → standing → reaching out

transition arc:
One state → in-between → new state
Example: fully dressed → mid-change → new outfit → adjusting

revelation arc:
Hidden → hinted → partial reveal → full presence
Example: back to camera → turning → three-quarter → facing viewer

time passage arc:
Morning → afternoon → evening → night
Each time of day changes light, color, and mood naturally

RULES:
1. Each narrative prompt must be independently valid — no prompt should
   be "incomplete" without the others. Each must work as a standalone image.
2. Variation across narrative prompts is relaxed SLIGHTLY — repeating an
   environment or lighting type is acceptable if the narrative justifies it.
   But no two consecutive narrative prompts may share more than 2 key dimensions.
3. The mood anchor for the narrative batch is the OVERALL mood, not per-prompt.
   Individual prompts may shift within that umbrella.
4. The LAST prompt in a narrative may transition toward the next batch's mood.
   This is the one exception to "adjacent batches must differ in mood anchor."
5. If the last batch was narrative, the current batch should probably NOT be.
   Two narrative batches in a row feels like a serial, not a varied collection.
6. Narrative mode adds +1 complexity to the system. The assembler must track
   story progression in addition to individual prompt variation.

WHEN TO USE:
- When the mood anchor naturally suggests progression (sensual slow, steamy heated)
- When the batch size is 5+ (enough room for an arc)
- When the previous 2+ batches were non-narrative (variety)
- When the character and setting support a mini-story naturally

WHEN NOT TO USE:
- When the batch size is 3 or fewer (not enough room)
- When the previous batch was narrative (avoid repetition)
- When the mood anchor is dreamy/atmospheric (this benefits from standalone moments)
- When the system is already at high complexity (yuri, X-rated, etc.)

POSE-CAMERA SAFE/UNSAFE TABLE — NEW
========================================================================

This table provides quick-reference combinations that are known to work
well with Tsubaki v1.1 (SAFE) and combinations that consistently produce
problems (UNSAFE). The system should consult this table during validation
at LEVEL 6 (MODEL SAFETY).

UNSAFE COMBINATIONS (avoid these):

Forward lean + top-down camera:
→ Chest flattens and disappears. The angle compresses the torso and the
  model loses the chest volume entirely. If forward lean is needed, use
  eye-level or slight low angle instead.

Sitting on edge + bottom-up camera:
→ Creates an unnatural "looking up at crotch" angle that Tsubaki
  interprets as an extreme perspective, distorting the seat and the body.
  Use eye-level or slight top-down for seated poses.

Arms overhead + face close-up:
→ Arms get cropped or merge with the head. The frame is too tight for
  the arm span. If arms are overhead, pull camera back to at least
  medium shot to include the full gesture.

Lying down + top-down + hands behind head:
→ Hands hidden behind the head from this angle, and the model often
  generates extra hands or deforms the arms trying to resolve the pose.
  If lying down with top-down, keep hands visible (at sides, on stomach).

Complex twist + side profile:
→ Proportions collapse. The torso twist combined with a side view causes
  the model to lose track of the body's depth, producing a flat or
  distorted result. Simplify the twist or change the camera angle.

Standing + extreme worm's-eye:
→ Distorted proportions — legs too long, torso compressed. The extreme
  angle is beyond Tsubaki's reliable range. If low angle is desired,
  use "slight low angle" rather than worm's-eye.

SAFE COMBINATIONS (reliable):

Standing + eye level / slight low angle:
→ Classic, stable, reads well. The slight low angle adds presence without
  distortion. Works for confident, casual, warm moods.

Seated + eye level / slight top-down:
→ Natural, grounded, intimate. Eye level for conversation feeling.
  Slight top-down for viewer-observing feeling. Both safe and reliable.

Reclining + side view / slight top-down:
→ Good body display, natural proportions. The side angle shows the
  body's curve without distortion. Slight top-down adds intimacy.

Leaning + three-quarter view:
→ Dynamic but stable. The lean creates energy, the three-quarter view
  maintains readable proportions. Works for confident, playful moods.

Standing + over-shoulder:
→ Dramatic and reliable. Shows the back of the character with the face
  turned, creating depth and presence. Works for mysterious, confident moods.

EROTIC PAIRS (pose + camera combinations for R+/X scenes):

Side view + curve emphasis + medium shot:
→ Shows the body's silhouette and curves from the side. Medium shot
  includes enough context without over-complexity. Best for body sensuality.

Over-shoulder + back arch + medium-close:
→ Viewer sees the character from behind with head turned, back arched.
  Creates intimacy and reveal. Medium-close keeps focus on the figure.

Leaning forward + slight low angle + body framing:
→ The lean creates cleavage or body emphasis. Slight low angle enhances.
  Body framing (doorway, window) adds depth without complexity.

Sitting crossed legs + slight top-down + suggestive:
→ Natural seated pose with crossed legs creating thigh emphasis.
  Slight top-down gives the viewer an observant perspective.

Standing three-quarter + waist-up + confident:
→ Classic confident framing. Three-quarter shows body language.
  Waist-up focuses on expression and upper body. Clean and powerful.

Reclining + eye level + intimate relaxed:
→ Lying back at eye level creates a "viewer is beside" feeling.
  Intimate without being aggressive. Works for relaxed, sensual moods.

Back view turning head + medium + classic reveal:
→ Character faces away from camera, turns head to look back.
  Medium shot shows the full back and the face turn. Classic and striking.

USAGE RULES:
1. During camera selection (step 16), check the pose against this table.
2. If the combination is UNSAFE, select a different camera angle.
3. If the pose is fixed (required by the scene concept), adjust the camera
   to find a SAFE pairing.
4. For erotic scenes, prefer the EROTIC PAIRS — these are specifically
   tested for R+/X content rendering.
5. If no safe pairing exists for a complex pose, SIMPLIFY the pose.
6. This table is a GUIDE, not an exhaustive list. Novel combinations that
   pass physical plausibility are acceptable, but default to safe when unsure.

COMBINATION COMPLEXITY RULE:
The more elements in a pose-camera combination, the higher the risk.
Simple pose + standard angle = safe. Complex pose + unusual angle = risky.
A2P12 recommends: for every complexity point added to the pose,
reduce camera complexity by one step.

Example: A complex reclining twist (high pose complexity) should be
paired with the simplest possible camera angle (eye level, straight-on).
A simple standing pose (low pose complexity) can handle a more dynamic
camera angle (over-shoulder, slight Dutch).

NARRATIVE SEQUENCE CONSIDERATION:
Within a narrative batch, the pose-camera combinations should show
variety not just between prompts but in the TYPES of angles used.
If prompt 1 is eye-level, prompt 2 could be slight top-down, prompt 3
over-shoulder, etc. This creates visual variety within the story arc.
Do not use the same safe pair twice in a narrative sequence.

CAMERA TRANSITION BETWEEN NARRATIVE PROMPTS:
Abrupt camera angle changes between sequential narrative prompts feel
jarring. Prefer gradual transitions:
- eye level → slight top-down → more top-down (zooming out gently)
- three-quarter → over-shoulder → profile (rotating around the subject)
- close-up → medium → full (pulling back for context)

These transitions are guidelines, not rules — but following them creates
a more cohesive narrative flow.

================================================================================
A2P12 — ASSEMBLER
================================================================================

The Assembler transforms pool selections into a structured prompt.
It follows 6 phases: Pre-processing, Cascade, Conflict Resolution,
Assembly, Negative Construction, and Validation.


================================================================================
PHASE 0: COGNITIVE PRE-PROCESSING
================================================================================

Before ANY pool selection, answer these questions in order:

0.1 WHAT IS THE SCENE?
    Write a one-sentence scene description.
    Example: "A woman wakes up in a luxury hotel room, stretching in
             the warm morning light filtering through sheer curtains."

0.2 WHAT IS THE EMOTIONAL CORE?
    Identify the primary emotion family.
    Example: "Warm — relaxed intimacy with morning haze transitional."

0.3 WHAT IS THE RATING?
    Declare: R (casual) / R+ (suggestive) / X (explicit)
    This locks available pools and tags.

0.4 IS THIS YURI?
    Yes / No. If yes, emotions must be compatible.
    MAX 2 contact points in yuri scenes.

0.5 WHAT LEVEL OF INTIMACY IS TARGETED?
    Check the session's running tally:
    - If last 3 were casual → this one CAN be intimate
    - If last 3 were intimate → this one SHOULD be casual
    - Target: 70% casual / 30% intimate

0.6 IS EMOTIONAL COUNTERPOINT AVAILABLE?
    (New in A2P12) Check if last 2 prompts used same emotion family.
    If yes, counterpoint is available but optional.
    Track in repetition log.

0.7 SESSION CONTEXT?
    Check:
    - Which emotions used recently? (avoid repetition)
    - Which environments used recently? (variety)
    - Which camera angles used recently? (variety)
    - Running tag counts? (avoid tag spam)
    - Any patterns forming? (break them intentionally)

RULE: Never skip Phase 0. It prevents formulaic output.

PHASE 2: CONFLICT RESOLUTION
================================================================================

After cascade selection, run ALL conflict checks.
Each conflict type has a detection pattern and resolution.

================================================================================
TYPE 1: RATING-MATERIAL CONFLICT
================================================================================
Detection: Erotic element or action selected with R rating.
Resolution: Remove erotic element/action, or upgrade to R+.

================================================================================
TYPE 2: EMOTION-ENVIRONMENT CONFLICT
================================================================================
Detection: Playful emotion with dark/dramatic environment, or
            Tense emotion with bright cheerful environment.
Resolution: Change emotion OR environment to match.
            Exception: Emotional counterpoint (must be logged).

================================================================================
TYPE 3: LIGHTING-EMOTION CONFLICT
================================================================================
Detection: Cool dramatic lighting with warm playful emotion (no counterpoint).
Resolution: Adjust lighting temperature or log as counterpoint.

================================================================================
TYPE 4: CAMERA-POSE MISMATCH
================================================================================
Detection: Camera framing incompatible with pose.
            (e.g., full body shot with reclining pose, or
             extreme close-up with standing pose)
Resolution: Adjust camera to safe combination from safety table.

================================================================================
TYPE 5: CLOTHING-ENVIRONMENT CONFLICT
================================================================================
Detection: Formal/elegant clothing in casual home environment,
            or sleepwear in outdoor/public environment.
Resolution: Change clothing to match environment category.

================================================================================
TYPE 6: YURI EMOTION OPPOSITION
================================================================================
Detection: Character A uses Warm family, Character B uses Cool family.
Resolution: Change one character's emotion to compatible family.
            Warm+Playful, Cool+Vulnerable are safe.
            Warm+Cool and Playful+Vulnerable are CONFLICTS.

================================================================================
TYPE 7: OVERCOMPLEX HANDS
================================================================================
Detection: More than one detailed hand action on same character.
Resolution: Simplify to one hand action. Keep the other hand neutral.

================================================================================
TYPE 8: NIPPLE VISIBILITY VIOLATION
================================================================================
Detection: Nipple visible through opaque clothing, or
            explicit breast detail in R-rated scene.
Resolution: Follow Nipple Visibility Logic strictly.
            Opaque fabric = no visibility. Sheer = may show (R+).
            X-rated = can show with justification.

================================================================================
TYPE 9: SATURATION OVERFLOW
================================================================================
Detection: Multiple bright/saturated elements with MODERATE saturation level.
Resolution: Remove one bright element or downgrade to SOFT saturation.

================================================================================
TYPE 10: REPETITION STRIKE
================================================================================
Detection: Same emotion, environment, or camera angle used 3+ times in a row.
Resolution: Force change to a different option this prompt.

================================================================================
TYPE 11: YURI CONTACT OVERFLOW
================================================================================
Detection: More than 2 contact points between yuri characters.
Resolution: Remove contacts until 2 or fewer remain.

================================================================================
TYPE 12: SKIN TONE MISMATCH
================================================================================
Detection: Skin described as "peach" or "flat" — conflicts with Anime Plus.
Resolution: Use proper skin tone from Pool 7 with undertone descriptor.

================================================================================
TYPE 13: WATER ELEMENT WITHOUT WATER ENVIRONMENT
================================================================================
Detection: Wet skin, water droplets, or steam tags without water environment.
Resolution: Remove water elements or change environment to water category.

================================================================================
TYPE 14: PROP-HAND CONFLICT (NEW)
================================================================================
Detection: Prop selected but both hands are occupied by body language.
Resolution: Remove prop. OR free one hand by simplifying body language.
            A hand holding a prop cannot also be doing an arm action.

================================================================================
TYPE 15: CHEST PRESS ANTI-PATTERN (NEW)
================================================================================
Detection: Any tag implying breasts pressed against surface
            ("pressed against glass", "breasts against surface", "chest press").
Resolution: Change to back/shoulder/arm contact only.
            NO breasts against any surface — this is a hard ban.

================================================================================
TYPE 16: SHOE-FRAMING CONFLICT (NEW)
================================================================================
Detection: Shoes added to a standing prompt.
Resolution: Remove shoes. Tsubaki forces full-body rendering when shoes
            are present, which conflicts with intended framing.

================================================================================
TYPE 17: BRUSHING ARTIFACT (NEW)
================================================================================
Detection: "brushing" in any hand/hair context.
Resolution: Replace with "fingers in hair" or "touching hair strands".
            Tsubaki will render a literal hairbrush object if "brushing" is used.

================================================================================
TYPE 18: OVER-SATURATION CONFLICT (NEW)
================================================================================
Detection: Scene uses "moderate" saturation level AND has multiple bright
            colored elements (bright clothing + bright environment + bright prop).
Resolution: Downgrade saturation to "soft" OR remove one bright element.
            Maximum impact is MODERATE — never push to vivid.

================================================================================
TYPE 19: COUNTERPOINT OVERUSE (NEW)
================================================================================
Detection: Last 3 prompts all used emotional counterpoint.
Resolution: This prompt MUST NOT use counterpoint.
            Emotion and visuals must align naturally.
            Counterpoint is a spice, not a default.

================================================================================
CONFLICT RESOLUTION PROCESS
================================================================================

1. Run all 19 conflict checks against assembled selections.
2. For each detected conflict, apply the specified resolution.
3. Re-check modified selections for new conflicts.
4. If conflicts cascade, simplify the prompt.
5. Log all resolutions for session tracking.

POST-CONFLICT CHECKLIST:

[ ] All detected conflicts resolved
[ ] No new conflicts introduced by resolutions
[ ] Selections are internally consistent
[ ] Proceed to Phase 3

STABILITY BLOCK — REMOVED
================================================================================

In A2P12, there is NO separate stability block at the end of the positive prompt.
Stability is now handled by:

1. Quality block ("masterpiece, best quality") provides base quality
2. Style block ("anime face structure, clean lineart") provides style stability
3. Negative prompt catches failures: "bad anatomy, wrong proportions, etc."

DO NOT ADD any stability tags to the positive prompt.
All stability-related tags are now in the negative prompt (Phase 4).

RATIONALE:
- Positive prompt should describe the DESIRED image, not prevent failures
- Prevention is the negative prompt's job
- Removing stability block frees up to 3-4 tag slots for meaningful content
- Quality + style + negative covers all stability needs

1. PROP / ITEM POOL (Pool 26)

   - Must be compatible with light source

   - Intimate scenes may have underwear only or absent

   - Max one per prompt
   - Skip in water environments and complex scenes

   - Used as micro detail slot (counts toward 2-4 total)

   - Cannot be used 3+ prompts in a row (Conflict Type 19)

8. INCOMPLETE ACTION TECHNIQUE

   - Must be physically plausible and used sparingly
   - Works best with medium/wide shots

   - Strict environment binding rules
   - 6 trace types with specific environment requirements

10. HAND / FINGER DETAIL POOL (within Pool 25)

    - CRITICAL: No "brushing" — Tsubaki spawns hairbrush
