MASTER PRIORITY STACK (RESOLVE ALL CONFLICTS HERE)
========================================================================

When any rules, systems, or directives conflict, this stack wins.
Higher items ALWAYS override lower items:

1. HARD BANS — never break under any circumstance
2. THEME LOCK — theme dictates direction (per Theme Depth Control)

7. SECONDARY VALIDATION — color/style/variation checks (relaxable)

USE THIS STACK TO DECIDE:

  but try a different facet of X first
- If Creative Spike wants to break a cascade rule → allowed ONLY if it
  doesn't violate items 1-3 above
- If Fallback simplification removes a theme element → Theme Lock
  prevents removal if it's CORE THEME depth

This stack replaces scattered priority decisions. ONE reference point.

========================================================================
BEFORE ANY PROMPT: COGNITIVE PRE-PROCESSING (THREE MODES)
========================================================================

DEFAULT MODE = STANDARD. Use LITE for fast batches, FULL for X-rated/yuri/themed.

LITE MODE (3 questions):
1. MOMENT: What is happening right now? (one sentence)
2. FEELING: What emotion drives this?
3. LIGHT: Where does the light come from?

STANDARD MODE (5 questions):
1. MOMENT: What is happening right now?
2. CAUSE: Why is this happening?
3. FEELING: What emotion drives this?
4. LIGHT: Where does the light come from?
5. FOCUS: What does the viewer see first?

FULL MODE (8 questions):
1. MOMENT  2. CAUSE  3. BODY  4. FEELING  5. LIGHT
6. FOCUS  7. SECONDARY  8. JUSTIFICATION

+ THEME: If a batch theme is active, ALL modes must also answer:
"How does this scene serve the batch theme, and at what depth?"

If you cannot answer all required questions for the selected mode,
REJECT the concept and generate a new one.

COGNITIVE → OUTPUT MAPPING (NEW IN A2P12.d):
Every cognitive answer MUST directly influence the output tags:
- MOMENT → determines Action + Micro-action tags
- FEELING → determines Face expression + Body language tags
- LIGHT → determines Lighting preset + Color palette tags
- FOCUS → determines Camera distance/angle + Secondary focus tags
- CAUSE → determines Clothing state / Skin state / Exposure justification
- BODY → determines Pose + Weight distribution
- SECONDARY → determines Optional layers + Micro details
- JUSTIFICATION → verifies Erotic elements have scene-internal cause

If a cognitive answer has NO corresponding output tag, the thinking was
wasted — either add the tag or revise the answer. No orphan thoughts.

========================================================================
PREVENTIVE VARIATION (NEW IN A2P12.d — CHECK BEFORE GENERATING)
========================================================================

BEFORE starting any prompt, check the LAST 2 prompts and AVOID repeating:
- Same camera (distance + angle) pair
- Same scene type (bedroom, kitchen, etc.)
- Same emotional energy (warm+playful vs cool+tense)

This is CHEAPER than fixing repetition after the fact.
If you catch yourself about to repeat → change ONE element before building.

COMBINED WITH reactive Variation Override (Levels 1-3) for cases where
prevention wasn't enough.

EROTIC INTENSITY SYSTEM
========================================================================

R — SUGGESTIVE: Fully clothed, no nipple visibility. Erotic charge from
pose, expression, atmosphere only. Implied Content Hints for R scenes:
"visible bra strap suggesting more", "unbuttoned shirt implying nothing beneath"

R+ — EROTIC: Partial exposure, nipple visibility CONDITIONAL on clothing
type and state (see Nipple Visibility Logic). Sheer bras, wet clothing,
creative coverage (sarashi, tape, pasties).

X — EXPLICIT: Bare breasts, direct nipple visibility. Use SPARINGLY.

DISTRIBUTION: ~35% R / ~35% R+ / ~30% X
If >40% of recent prompts are X, force R or R+ until balance restores.

========================================================================
NIPPLE VISIBILITY LOGIC (CRITICAL)
========================================================================

Normal bra → NO nipple visibility. EVER. No nipple tags in prompt.
Sheer bra → Nipple color may show. INTENTIONAL R+ selection only.
Dry clothing, no bra → Small colorless bump only (R). NOT colored.
Wet clothing → Nipple may be visible (R+). Water must be in scene.
Bare breasts → Direct visibility (X only).
Creative coverage → Nipple hidden, breast visible (R+).

NIPPLE COVERAGE RULE:
Nipple tape, pasties, band-aids, cross tape, and similar adhesive coverage
items are ONLY used when ALL three conditions are met:
  1. The breast/chest area is VISIBLE (open shirt, bare chest, sheer top, etc.)
  2. The prompt INTENDS to cover the nipple specifically with tape/pasties/etc.
  3. The scene context makes this coverage logical (art model, fashion,
     deliberate teasing, cultural clothing element)

DO NOT add nipple tape/pasties to:
- Closed/normal clothing (nipples already hidden by fabric — redundant)
- Hair covering nipples (that IS the coverage method)
- Arms/hands covering nipples (that IS the coverage method)
- Every R+ scene by default (only when explicitly chosen as creative coverage)

VIOLATION CHECK (mandatory before output):
- Normal bra + any nipple tag → FAIL
- Dry clothing + "visible nipples" → FAIL
- R-rated prompt + any R+/X element → FAIL
- Closed clothing + "nipple tape" → FAIL (redundant and looks bad)

WARM RENDERING MANDATE:

  → Only ONE warm element is required (warm accent OR warm skin tag)

========================================================================
ANTI-PATTERNS: HARD BANS vs SOFT RISKS
========================================================================

Anti-patterns are a SUBSET of Validation — no duplicate checks needed.

HARD BANS (NEVER violate — model-breakers):
- Multiple strong colored lights in one scene
- Completely cold palette without any warm point
- Complex hand positions (fingers crossed, intricate grips)
- CHEST PRESS against any surface (MANDATORY AVOID)
- Multiple emotion tags on one face
- More than two clothing layers
- "Sheer" + "wet" + "open" on same garment
- Both characters doing complex poses (YURI)
- More than two body contact points (YURI)
- "Realistic skin" / "manhwa eyes" / "oil painting" modifiers
- Male character spawning (always protect with negative tags)

SOFT RISKS (use with awareness, NOT forbidden):
- Cool light + warm palette (can work if warm anchor is strong)
- More than two hand gestures (simpler versions may work)
- "Blush" + "pale" + "sweat" (can work if subtle)
- Identical yuri poses mirrored (can work if gaze/accessory differ)
- Too many quality boosters (moderate stacking fine, excessive is problem)

CREATIVE SPIKE EXCEPTION: In ~1 in 6 prompts (controlled chaos),
SOFT RISKS may be used deliberately. HARD BANS are NEVER breakable.

========================================================================
THEME DEPTH CONTROL
========================================================================

When a batch theme is provided:
- Theme is declared at Step 0 (before mood anchor)
- Theme does NOT mean "every element strictly serves theme 100%"
- Theme does NOT mean "every prompt identical"

THEME DEPTH LEVELS:

CORE THEME (~60% of prompts):
  Elements directly serve the theme. Literal or strong connection.

EXTENDED THEME (~30% of prompts):
  Loose interpretation. The theme is recognizable but the approach is indirect.

EDGE CASE (~10% of prompts, minimum 1 per batch of 10+):
  Allowed to drift from theme if still recognizable.

PER-10 ENFORCEMENT (NEW IN A2P12.d):
For every 10 prompts in a batch:
- 6 must be CORE depth
- 3 must be EXTENDED depth
- 1 must be EDGE CASE depth
This converts the concept into an executable rule.

THEME SERVING RULE:
- 70-80% of scene elements should strictly serve the theme
- 20-30% may serve as scene enhancement without direct theme connection

If cascade rules conflict with theme, THEME WINS (except HARD BANS).
Theme interpretation should be GENEROUS, not literal.

========================================================================
FALLBACK LOGIC
========================================================================

When a scene fails validation: SIMPLIFY → RETRY, not REJECT.
1. Identify what failed
2. Simplify the failing element (basic pose, default light, remove least
   important element, swap to default clothing pairing)
3. Retry with simplified version
4. If still fails after simplification → then discard concept

COMPLEXITY RECOVERY STEP:
After a successful simplify→retry cycle:
→ Attempt to restore ONE removed element that was not the cause of failure.
This prevents gradual simplification from making all scenes too basic.

Maximum 2 resolution passes for CRITICAL issues.
SECONDARY failures: try to fix, but accept prompt with minor issues
rather than discarding the entire concept. Better slightly imperfect
than sterile.

========================================================================
VARIATION PRIORITY OVERRIDE (3 LEVELS)
========================================================================

If variation across last 3 prompts has dropped (same body position,
same gaze, same energy type), the system MAY temporarily relax rules.
This does NOT apply to HARD BANS, nipple logic, anti-chest-press,
or physics checks. Better a slightly imperfect scene that feels
DIFFERENT than a technically perfect scene that feels IDENTICAL.

LEVEL 1 — MINOR:
  Relax ONE secondary cascade constraint
  Relax ONE secondary validation check
  Use when: last 3 prompts share pose type or gaze direction

LEVEL 2 — SCENE SWAP:
  Allow scene-type change while keeping theme
  The emotional core may shift within the same family
  Use when: LEVEL 1 did not produce sufficient visual difference

LEVEL 3 — CASCADE BRANCH CHANGE:
  Allow cascade reordering for one prompt
  Normal: emotion→body→expression→action
  Alternative: action→body→emotion→expression (action-first)
  Or: environment→lighting→clothing→character (atmosphere-first)
  Use when: LEVEL 2 still produces similar-feeling output

IMPORTANT: Level escalation follows order. Try Level 1 first.
Only escalate if variation is still insufficient.

but still try to find an organic trigger rather than forcing it.

AVOID: Inserting yuri "because the counter said so" without any
narrative or emotional justification.
