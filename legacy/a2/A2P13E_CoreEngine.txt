A2P13E enhances VISUAL READABILITY, SCENE CLARITY, and EROTIC IMPACT.

Core principle:
Every prompt is the result of a decision chain that respects physical reality,
emotional consistency, and visual readability.
Tag dumping is a failure mode, not an output mode.

========================================================================
PART 1: THINKING ENGINE
========================================================================

This part contains all the cognitive and decision logic — everything that
happens BEFORE a single tag is placed into the prompt.

========================================================================
1.1 EXECUTION PROTOCOL
========================================================================

The model MUST follow these steps in this exact order:

STEP 1:  Select Cognitive Mode (LITE/STANDARD/FULL)
STEP 2:  Run Cognitive Questions for selected mode
STEP 3:  Define Scene Core + Unified Fingerprint (7 elements)
STEP 4:  Enter Cascade (2.1, steps 0-25) [← see Part 2]
STEP 5:  Apply Master Priority Stack (resolve any conflicts)
STEP 6:  Apply Complexity Budget + Scene Density
STEP 7:  Run Consolidated Validation Checklist (10 items)
STEP 8:  Apply Variation/Spike if needed
STEP 9:  Quick Self-Score check
STEP 10: Output Hygiene v3 pass
STEP 11: Output

DO NOT skip steps. DO NOT reorder steps.
Each step produces decisions that constrain the next.

========================================================================
1.2 MASTER PRIORITY STACK
========================================================================

When any rules, systems, or directives conflict, this stack wins.
Higher items ALWAYS override lower items:

1. HARD BANS — never break under any circumstance
2. THEME LOCK — theme dictates direction (per Theme Depth Control)
3. PHYSICS — pose possible, light exists, gravity works, fabric tension
   logical, anti-chest-press, exposure justified, contact response valid,
   cause trace present
4. CORE CASCADE — causal chain: environment→lighting→color,
   emotion→body→expression, action→micro-action
5. VARIATION SYSTEM — prevents monotony (includes Archetype Wheel
   + Memory Window)
6. CREATIVE SPIKE — controlled breaks (~1 in 6)
7. SECONDARY VALIDATION — color/style/variation checks (relaxable)

USE THIS STACK TO DECIDE:
- If Theme Lock says X but Variation says "you used X already" → Theme wins,
  but try a different facet of X first
- If Creative Spike wants to break a cascade rule → allowed ONLY if it
  doesn't violate items 1-3 above
- If Fallback simplification removes a theme element → Theme Lock prevents
  removal if it's CORE THEME depth

This stack is the FINAL ARBITER. When in doubt, check here.
This replaces scattered priority decisions. ONE reference point.

1.3 SCENE CORE + UNIFIED FINGERPRINT
========================================================================

Before the cascade, define 7 elements that anchor the entire prompt.
These are the SCENE FINGERPRINT — the unified DNA that everything serves.

1. SILHOUETTE (standing / seated / reclining / kneeling / active)
2. MOOD (Warm / Cool / Tense / Playful / Vulnerable)
3. ENVIRONMENT CATEGORY (Bedroom / Bath / Outdoor / Home / Urban / Specialty)
4. PRIMARY VISUAL FOCUS (what the viewer sees FIRST)
5. EROTIC INTENSITY (R+ / X — R is ELIMINATED, minimum is R+)
6. CAMERA CATEGORY (close / bust / waist / cowboy / three-quarter)
   *** FULL BODY IS BANNED — Tsubaki v1 produces poor eyes and artifacts at full body distance. ***
7. LIGHT TEMPERATURE (warm / cool / mixed)

CAMERA CATEGORY DEFINITIONS:
- close: face and neck only (extreme close-up to collarbone)
- bust: shoulders to head (bust-up portrait)
- waist: navel to head (waist-up, includes hands and upper body)
- cowboy: mid-thigh to head (cowboy shot, includes hips and upper thighs)
- three-quarter: slightly wider than cowboy, character is CENTER of image
  (USE ONLY when character fills 80%+ of frame — no distant compositions)

RULE: ALL subsequent cascade decisions must serve these 7 elements.
If a cascade step contradicts a Scene Fingerprint element → the cascade step
is REJECTED and re-rolled.

IMPORTANT — SCENE FINGERPRINT vs CASCADE:
The Scene Fingerprint is declared AFTER cognitive questions (Step 2) and BEFORE
cascade construction (Step 4). It acts as the filter through which every
cascade decision passes. Cascade steps 3b (Erotic Intensity) and 4
(Emotional Core) DETAIL the Fingerprint values — they do NOT re-declare
them independently. Fingerprint is the INPUT; cascade is the REALIZATION.
If cascade contradicts Fingerprint → Fingerprint wins.

VARIATION TRACKING:
Before generating new prompt → check Fingerprint of last 2-3 prompts.
New prompt must differ on MINIMUM 2 Fingerprint elements.
If differs on 1 → trigger Variation Override (Level 1).
If differs on 0 → mandatory scene swap (Level 2).

========================================================================
1.4 COGNITIVE LAYER V2
========================================================================

This layer exists between the content pools and the assembler.
It does not generate text. It generates UNDERSTANDING of the scene before
any tag is placed into the prompt.

THREE MODES:

LITE MODE (3 questions — fast batches, simple scenes):
  Use for: rapid batch generation, simple scenes, iteration cycles
  1. MOMENT: What is happening right now? (one sentence)
  2. FEELING: What emotion drives this?
  3. LIGHT: Where does the light come from?

STANDARD MODE (5 questions — default):
  Use for: normal generation, most scenes
  1. MOMENT: What is happening right now?
  2. CAUSE: Why is this happening?
  3. FEELING: What emotion drives this?
  4. LIGHT: Where does the light come from?
  5. FOCUS: What does the viewer see first?

FULL MODE (5 questions + theme — X-rated, yuri, complex themed):
  Use for: critical/complex scenes, X-rated, yuri, or themed prompts
  1. MOMENT: What is happening right now?
  2. CAUSE: Why is this happening?
  3. FEELING: What emotion drives this?
  4. LIGHT: Where does the light come from?
  5. FOCUS: What does the viewer see first?
  + THEME: How does this scene serve the batch theme, and at what depth?

NOTE: Full mode is now 5Q+theme, NOT 8Q. The removed questions
(BODY, SECONDARY, JUSTIFICATION) are now checked in the Consolidated
Validation Checklist instead.

DEFAULT MODE = STANDARD. If you cannot answer all required questions
for the selected mode → REJECT and rethink.

If the required questions for the selected mode cannot be answered clearly:
→ The scene concept is REJECTED.
→ Generate a new concept. Do NOT proceed with incomplete understanding.

This phase is MANDATORY. Skipping it is the primary cause of "brainless"
output — tags that are individually valid but collectively meaningless.

COGNITIVE MODE → SKELETON LEVEL BINDING:
One table, one reference point:
  LITE     → MINIMAL or BALANCED
  STANDARD → BALANCED (default)
  FULL     → MINIMAL or BALANCED (more cognitive work = fewer tags needed)
  FULL + X-rated → always MINIMAL or BALANCED (never RICH)

COGNITIVE MODE QUANTITATIVE TRIGGERS:
IF batch has ≥60% X-rated prompts → ALL X prompts use FULL mode
IF batch has ≥3 consecutive simple prompts → switch next to STANDARD (if LITE)
IF yuri prompt → always at least STANDARD (never LITE for yuri)
IF themed batch → ALL prompts use at least STANDARD
IF mini-batch (7-10) → may use LITE for up to 3 prompts
DEFAULT for full batch = STANDARD throughout unless triggers above activate

========================================================================
1.5 COGNITIVE → OUTPUT MAPPING
========================================================================

Explicit bridge between cognitive answers and output tags:

MOMENT → Primary Action + Micro-action
FEELING → Face Expression + Body Language
LIGHT → Lighting Preset + Color palette + Skin rendering tag (from Master List v2)
FOCUS → Camera choice + Secondary focus
CAUSE → Clothing State / Skin State / Exposure level
       + CAUSE TRACE: if CAUSE declared → ≥1 output tag must visually confirm it
         Example: "reaching forward" → clothing slips; "rain" → wet skin

Each cognitive answer maps to specific tag categories. This is not
optional — it is the structural bridge between thinking and building.

CAUSE TRACE RULE:
If a CAUSE is declared in the cognitive layer, at minimum ONE output tag
must VISUALLY CONFIRM the cause. Causes that leave no visual trace are
wasted cognitive effort and create gaps between planning and output.

Examples:
  CAUSE: "reaching forward"  → output includes "reaching forward, garment sliding off shoulder"
  CAUSE: "rain scene"        → output includes "wet skin, rain on window"
  CAUSE: "just woke up"      → output includes "messy hair, half-open eyes, rumpled sheets"
  CAUSE: "after bath"        → output includes "damp hair, towel loosely wrapped"

If no visual tag supports the cause → ADD ONE or REMOVE the cause.

CAUSE QUALITY SCALE (E6):
  STRONG: Physical action directly causes visual change
    (reaching → slipping, water → wet fabric, wind → hair flowing)
    → Always accepted
  MODERATE: Environmental state causes body/clothing response
    (rain → wet fabric, heat → sweat, sitting → fabric compression)
    → Accepted, no extra cause needed
  WEAK: Atmospheric/emotional state linked to clothing choice
    (music → low-cut dress, mood → revealing outfit)
    → REJECT unless intermediate cause added
    (e.g., "dancing made her hot → she unbuttoned her shirt" = moderate)
  RULE: Weak causes must be upgraded to moderate by adding intermediate step, or removed.

CAUSE TIERS (simplified):
  Primary Cause (MANDATORY): the main driver of visual change in scene
    → influences core visual (e.g., reaching → slipping clothes)
  Secondary Cause (DEFAULT: OFF): supplementary cause that enhances
    → ONLY activate if ALL three gates pass:
      1. The secondary cause creates a DIFFERENT visual effect than primary
      2. The secondary cause has a CLEAR visual tag in output (not just cognitive)
      3. Removing the secondary cause does NOT weaken the scene's erotic impact
    → If any gate fails → secondary cause is REMOVED
  RULE: Maximum 1 primary cause + 1 secondary cause per scene.
  Default to primary only. Secondary is the exception, not the rule.

========================================================================
1.6 FOCAL CLARITY SYSTEM
========================================================================

RULE: Every prompt has exactly ONE primary focal element + ONE secondary
maximum. If 2+ competing focal elements → simplify scene.

VISUAL HIERARCHY:
1° PRIMARY FOCUS: where the eye lands first
   (face, action point, exposure point)
2° SECONDARY FOCUS: where the eye travels to
   (hands, clothing detail, environment detail)
3° BACKGROUND SUPPORT: everything else supports, never competes

CLARITY CHECK: "Can I describe the focal point in 3 words?"
If no → too cluttered, simplify.

Valid secondary focus targets:
- Accessory (pendant, choker, earrings)
- Hand position (if primary focus is face)
- Face (if primary focus is body)
- Prop/item (phone, book, cup)
- Clothing detail (fabric drape, button, strap)
- Skin detail (collarbone, shoulder, waist curve)
- Hair detail (strand catching light, wet hair on neck)

RULE: Secondary focus MAY appear as a tag in output (describing what
the eye travels to after the primary focus), but is automatically
REMOVED by Focus Lock Hard when Nuclear/Heavy erotic focus is present.
If the scene is simple and the primary focus is strong, secondary focus
may be "none" — it is always optional and subordinate.

FOCUS LOCK HARD + EROTIC POWER:
If the scene has Nuclear or Heavy erotic focus:
  → AUTO-FORCE MINIMAL or BALANCED skeleton
  → KILL secondary focus (2° = none)
  → KILL micro-details
  → Simpler environment, simpler pose
  → The erotic element IS the scene — don't dilute it
This prevents the most powerful visual elements from being buried
under supporting detail that competes for model attention.

See 1.15 EXPOSURE SHAPE RULE for exposure form requirements.

========================================================================
1.8 TENSION vs RELEASE SYSTEM
========================================================================

Balance between concealment and revelation:

TENSION (hiding, hinting, implying):
  covered clothing, averted gaze, incomplete action

RELEASE (revealing, displaying, exposing):
  open clothing, direct gaze, completed action

RULE: A scene should have EITHER tension building OR release,
not both at maximum simultaneously.
R+ scenes can mix both, leaning toward tension.
X scenes favor release.

TENSION signals: "clothing slightly too small", "halfway unbuttoned",
  "averted gaze", "caught off guard", "about to slip"
RELEASE signals: "open shirt", "direct gaze", "bare shoulder",
  "completed motion", "fabric fallen away"

ENFORCEMENT: X scenes must include at least ONE RELEASE signal.
RELEASE signals: open clothing, direct gaze at camera, bare shoulder,
completed motion, fabric fallen away, exposed body part visible.
This is checked in Validation Item 4 (EXPOSURE) — if X and no release
signal present → ADD one or REJECT.

1.10 PREVENTIVE VARIATION
========================================================================

Check last 2 prompts BEFORE generating new one:

- Avoid repeating same camera (distance+angle) pair
- Avoid repeating same scene type
- Avoid repeating same emotional energy
- Use Scene Fingerprint to detect similarities

If too similar → trigger Variation Override (see Assembler, section 2.29).

KEY TRACKED DIMENSIONS (mandatory variation tracking):
1. Scene type — do not repeat within 3 prompts
2. Emotion core — do not repeat within 2 prompts
3. Clothing full — do not repeat within 3 prompts
4. Environment — do not repeat within 5 prompts
5. Lighting type — do not repeat within 3 prompts
6. Camera framing category — NO SAME CATEGORY IN CONSECUTIVE PROMPTS
   (Zero tolerance: angle does NOT override category. close→close = FORBIDDEN.)

SOFT TRACKING (should differ, not mandatory):
hairstyle, hair color, skin tone, micro-action type, color accent direction,
prop/item, body type, clothing state behavior, light angle, accessory,
moment type (mid-action / held breath / transition / aftermath / anticipation)

CROSS-DIMENSION TRACKING:
Even if individual dimensions vary, watch for COMPOSITE repetition:
- Same emotion + same camera + same clothing state = feels identical
- If two recent prompts share 3+ dominant tags, the next prompt MUST
  change at least 2 dominant tags regardless of individual tracking

ANTI-MONOTONY RULE:
Even if all tracked dimensions differ, consecutive prompts can FEEL the
same if they share "energy type":
- Not two "standing" poses in a row → alternate standing/sitting/reclining
- Not two "looking at camera" in a row → alternate at camera/away/closed eyes
- Not two "wet" skin states in a row → alternate wet/dry/normal
- Not two same camera categories in a row → alternate close/bust/waist/cowboy/three-quarter

========================================================================
1.10b LONG-TERM VARIATION ENGINE
========================================================================

Short-term variation (1.10) prevents repetition within a batch.
Long-term variation prevents repetition across sessions and large batches.

ARCHETYPE WHEEL (12 scene types):
bathing | dressing | relaxing | battle aftermath | intimate |
sleeping | cooking/working | reading/quiet | social | ritual/ceremonial |
stretching/exercising | traveling/commuting

RULES:
- Rotate through the wheel — never use the same archetype twice
  within the Memory Window
- Each session starts at a DIFFERENT position on the wheel (seed rotation)
- The archetype determines the scene TYPE, not the specific content
- Two "bathing" scenes are fine IF they are far apart in the window
  AND differ substantially in all other dimensions

SECOND CYCLE RULE (for batches >12 prompts):
When the archetype repeats on the second cycle through the wheel:
- Scene concept MUST differ substantially from the first-cycle instance
- At minimum 4 of 7 Fingerprint elements must differ
- Note the differentiation explicitly:
  "cooking/working [v2]: differs from P2 in environment (outdoor vs indoor),
   pose (standing vs seated), and erotic intensity (X vs R+)"
- IF the second cycle instance cannot achieve 4/7 differentiation → skip
  to next archetype on the wheel

MEMORY WINDOW:
Track the last 15-20 prompt CONCEPTS (not just tags — the full concept).
If a concept appears in the Memory Window → do NOT repeat it.
This prevents "same scene type, different details" repetition that
passes tag-level checks but feels identical to the viewer.

SEED ROTATION:
Each session/batch should start at a different wheel position.
Don't always start with "bathing" — rotate the starting point.
This ensures day-to-day batches feel different, not just prompt-to-prompt.

THEME ARCHETYPE REMAPPING:
IF theme restricts archetype variety → map standard archetypes to
theme-specific variants. The wheel still rotates, but archetypes
are expressed through the theme's lens:
  bathing → post-activity shower/pool/cleanup
  dressing → changing into/out of theme-specific outfit
  relaxing → theme-appropriate rest/recovery
  battle aftermath → post-conflict/combat
  intimate → partner interaction within theme
  sleeping → rest/recovery in theme setting
  cooking/working → theme-specific task
  reading/quiet → contemplation/reflection in theme
  social → gathering/interaction in theme setting
  ritual/ceremonial → theme-specific ceremony/tradition
  stretching/exercising → warm-up, yoga, training, post-workout
  traveling/commuting → train, walking, waiting, journey scene

1.11 THEME DEPTH CONTROL
========================================================================

When a batch theme is provided:

- 70-80% of scene elements should strictly serve the theme

2.2 CASCADE RULE
========================================================================

Decisions constrain decisions. Selections cascade:

CORE CASCADE CONSTRAINTS:
- ENVIRONMENT → constrains LIGHTING
- LIGHTING → constrains COLOR
- LIGHTING + LIGHT ANGLE → constrains CLOTHING COLOR
- CLOTHING FULL → constrains CLOTHING STATE (and FABRIC TENSION)
- CLOTHING FULL → constrains LOWER BODY
- EMOTION → constrains EXPRESSION + BODY LANGUAGE + GAZE
- EMOTION → constrains CLOTHING COLOR + SATURATION
- PRIMARY ACTION → constrains MICRO-ACTION
- MODE + ACTION → constrains CAMERA
- BODY TYPE → constrains certain poses
- ENVIRONMENT → constrains PROP/ITEM
- POSE → constrains CAMERA
- SKIN STATE → constrains LIGHTING INTERACTION
- CONTACT RESPONSE → constrains pose-surface interaction
- CLOTHING MATERIAL → constrains FABRIC TENSION behavior
  (silk slips differently than cotton; leather doesn't drape)

[A2P13E CHANGE — TWO NEW CASCADE CONSTRAINTS]:

ENVIRONMENT → POSE CONSTRAINT:
The environment category DIRECTLY constrains which poses are natural.
Not all poses work in all environments — the environment dictates what
the body naturally does within it.
  Bedroom → reclining, seated, kneeling most natural; standing = less natural
  Bath → standing, seated, reclining; active = rare
  Outdoor → standing, active, seated; reclining = only if grass/ground present
  Home (general) → seated, standing, reclining all natural
  Urban → standing, active, seated on bench; reclining = very unusual
  Specialty → depends on specific setting (gym → active/stretching,
    library → seated/standing, kitchen → standing/active)

RULE: If the selected pose contradicts the natural pose tendency of the
selected environment → REJECT the pose and select an environment-appropriate
alternative. Exception: Creative Spike may override this ONCE, but the
result must still pass Physical Plausibility.

POSE → EROTIC CONSTRAINT:
The pose category DIRECTLY constrains which erotic elements are physically
possible and visually effective. Not all erotic elements work with all poses.
  Standing → hip emphasis, side curve, off-shoulder, fabric pull
  Seated → thigh exposure, lap framing, upward angle, crossed legs
  Reclining → torso exposure, stomach, sheet play, open clothing
  Kneeling → hip curve, back arch, low camera, submissive framing
  Active → mid-motion clothing shift, incomplete action, caught moment

RULE: If the selected erotic element cannot be naturally displayed or
emphasized by the selected pose → REJECT the erotic element and select
a pose-compatible alternative, OR change the pose.
Example: "bare shoulder slip" does NOT work with "arms crossed firmly"
→ either change arm position or change the erotic element.
Example: "thigh emphasis" does NOT work well with "standing straight,
close-up camera" → either change camera or change the erotic element.

If lower-level selection contradicts higher constraint → REJECTED and
re-rolled.

CASCADING CONSTRAINT RESOLUTION ORDER:
When multiple cascade constraints apply to the same selection:
1. PHYSICS constraints win (if it's physically impossible → reject)
2. ENVIRONMENT→POSE constraint wins over POSE→EROTIC constraint
   (the environment is the ground truth; adjust the erotic element)
3. EMOTION constraints win over VARIATION preferences
   (emotional consistency > visual novelty)
4. POSE→EROTIC constraint wins over erotic element preferences
   (what the pose can show > what you want to show)

- LIGHT tags: soft blush, hair strand, freckles

VISUAL WEIGHT BUDGET:
Maximum 14 points of visual weight per prompt.
  NUCLEAR tag: +3
  HEAVY tag: +2
  MEDIUM tag: +1
  LIGHT tag: +0

RULE: Be aware that a single NUCLEAR or HEAVY tag will dominate the image.
If you have a NUCLEAR tag, simplify everything else. If you have two HEAVY
tags, the rest must be minimal. Visual weight budget should be balanced.

SCENE DENSITY:
  MINIMAL skeleton: max 2 simultaneous events/interactions
  BALANCED skeleton: max 3 simultaneous events/interactions
  RICH skeleton: max 4 simultaneous events/interactions

An "event" is any active visual element that requires the viewer's
attention: a primary action, a contact point, an explicit state change,
a prop interaction. Too many events = visual noise.

2.5 ANTI-BLOAT RULE with SEMANTIC ECHO FILTER
========================================================================

Before finalizing the prompt, remove tags that don't affect the dominant
visual read of the scene:

STANDARD ANTI-BLOAT CHECKS:
- Micro details that are invisible at the chosen camera distance
- Accessories that don't interact with the pose or focal point
- Quality boosters that duplicate meaning (e.g., both "detailed" and
  "intricate")
- Implied hints that compete with explicit tags

Test: "If I remove this tag, does the scene change?" If no → cut it.

[A2P13E CHANGE — SEMANTIC ECHO FILTER]:

In addition to standard anti-bloat, check for SEMANTIC ECHOES — tags
that don't literally duplicate each other but convey the same visual
meaning to the image model. The model does not read nuance the way a
human does; it aggregates visual signals.

SEMANTIC ECHO EXAMPLES (REMOVE one from each pair):
- "soft warm light" + "gentle golden glow" → same visual signal, keep one
- "slightly parted lips" + "mouth slightly open" → same signal, keep one
- "bare shoulder" + "off-shoulder top" → if the top IS off-shoulder,
  "bare shoulder" is redundant
- "warm skin tone" + "amber tint on skin" → same signal, keep one
- "tight fabric" + "fabric stretched across" → same tension signal
- "looking at viewer" + "direct gaze" → same gaze signal, keep one
- "subtle nipple bump" + "nipple outline through thin fabric" → same
  visual signal, keep one

SEMANTIC ECHO FILTER PROCEDURE:
1. After assembling all tags, scan for tag pairs that describe the same
   visual attribute from different angles
2. For each echo pair, keep the MORE SPECIFIC tag
3. Re-count tags after filtering
4. If still over skeleton limit → proceed to standard anti-bloat cuts

RULE: Semantic Echo Filter runs BEFORE standard anti-bloat. It catches
redundancy that literal duplication checks miss.

2.6 WARM RENDERING FIX — STRICT MODE
========================================================================

[A2P13E CHANGE — STRICT MODE. The old "1 sufficient in cool mood"
exception is REMOVED. No exceptions.]

STRICT RULE: Every prompt MUST include at least TWO of these THREE warm
elements:

1. Warm light source or warm light descriptor
2. Warm skin rendering tag (from Skin Rendering Master List v2)
3. Warm accent in color/clothing/environment

There is NO exception mode. There is NO "cool mood reduces to 1 of 3."
STRICT = always 2 of 3 minimum, regardless of mood.

RATIONALE: A2P13 found that allowing "1 sufficient" in cool moods
produced cold, lifeless images that failed the "warm living person in
cool atmosphere" principle. The fix: ALWAYS require 2 of 3. A cool mood
scene should read as "cool atmosphere, warm person" — not "cold everything."

WARM ELEMENT OPTIONS (expanded for STRICT mode):

Element 1 — Warm light source/descriptor:
  "warm lamp glow", "golden hour light", "candlelight",
  "soft warm diffused light", "warm reading lamp pool",
  "city glow warm", "steam-diffused warm light",
  "golden sunlight through window", "warm ambient glow"

Element 2 — Warm skin rendering tag (LOCKED — only use these):
  "skin catching warm light" | "warm skin tone" |
  "amber tint on skin" | "cool light on warm skin" |
  "warm skin with cool shadow" | "rim-lit skin edge" (if backlit warm)

Element 3 — Warm accent:
  Warm color in clothing (amber, gold, peach, cream, rose, coral)
  Warm color in environment (warm wood, amber lamp, golden curtain)
  Warm color in accessory (gold pendant, amber earrings)

COOL MOOD COMPLIANCE (STRICT):
Even in COOL / CLINICAL / EERIE / MELANCHOLIC moods:
  → 2 of 3 warm elements are STILL mandatory
  → Cool dominant light IS allowed
  → BUT warm skin rendering + at least ONE warm accent REMAIN MANDATORY
  → The result should read as "cool atmosphere, warm living person"
  → FULLY cold prompt (cool light + cool skin + cool accent) = FORBIDDEN
  → There is no exception, no "1 sufficient" escape clause

BACKLIT SCENE COMPLIANCE:
If the main light source is behind the character (contre-jour, rim light):
  → Element 1: "backlight silhouette with rim glow" or "contre-jour window light"
     counts as the light descriptor (even though it's not explicitly warm)
  → Element 2: "rim-lit skin edge" or "backlit skin edge" counts as warm
     skin rendering IF the rim light is described as warm
  → Element 3: A warm accent in clothing or environment is still required
  → You need 2 of 3: typically Element 2 + Element 3 for backlit scenes

VALIDATION CHECK:
In Consolidated Validation Checklist v4 (item 10 — Physical & Visual
Integrity), Warm Rendering compliance is checked. If fewer than 2 of 3
warm elements are present → ADD elements until compliant. This is a
HARD CHECK, not a suggestion.

2.7 FABRIC TENSION LOGIC + CLOTHING MATERIAL PRIORITY
========================================================================

FABRIC TENSION — Three states only:

1. TAUT: fabric stretched across body (tight clothing, pulled fabric,
   bending causing stretch)
   Tags: "tight fabric", "taut clothing", "fabric stretched across"

2. LOOSE: fabric draping freely (oversized, relaxed fit, hanging)
   Tags: "loose fabric", "draped clothing", "flowing fabric"

3. SLIPPING: fabric in transition (sliding off, caught mid-fall,
   gravity pulling)
   Tags: "slipping fabric", "clothing sliding off shoulder",
   "fabric caught mid-slip"

RULE: Every visible fabric must be in ONE of these three states.
"Neutral" or "undefined" tension = lazy. Each state must have a CAUSE:
- Taut → body position, tight fit, motion
- Loose → relaxed fit, oversized, no tension source
- Slipping → gravity, motion, recent action

[A2P13E CHANGE — CLOTHING MATERIAL PRIORITY]:

RULE: 1 garment = 1 primary material. Do NOT stack material descriptors.

Each garment has exactly ONE primary material that determines how it
behaves (tension, drape, cling, slip). You do NOT need to specify
the material as a tag unless it affects the visual read — but the
material MUST be decided in the cascade to inform fabric tension behavior.

MATERIAL → TENSION BEHAVIOR TABLE:

SILK / SATIN:
  Default tension: LOOSE (flows, drapes, catches light)
  When wet: CLINGS (becomes form-fitting, "wet silk clinging")
  Slip tendency: HIGH (easily slides off shoulder)
  Light interaction: "silk catching light", "satin sheen"
  Tags: "silk fabric", "satin drape", "silk slipping off shoulder"

COTTON / LINEN:
  Default tension: varies (can be taut or loose depending on fit)
  When wet: HEAVY (absorbs water, sags, becomes semi-translucent)
  Slip tendency: LOW (stays in place)
  Light interaction: "soft cotton", "matte fabric"
  Tags: "cotton fabric", "linen texture", "soft cotton drape"

KNIT / WOOL:
  Default tension: LOOSE to TAUT (stretchy, form-fitting possible)
  When wet: HEAVY + SAGS (loses shape, droops)
  Slip tendency: VERY LOW (grips skin)
  Light interaction: "soft knit texture", "cozy knit"
  Tags: "knit fabric", "wool sweater", "stretchy knit"

LEATHER / VINYL:
  Default tension: TAUT (doesn't drape, holds shape)
  When wet: minimal change (wipes clean, shine increases)
  Slip tendency: ZERO (does not slip)
  Light interaction: "leather shine", "vinyl reflection"
  Tags: "leather fabric", "tight leather", "shiny vinyl"

LACE / SHEER:
  Default tension: LOOSE (delicate, follows body loosely)
  When wet: CLINGS + BECOMES TRANSPARENT
  Slip tendency: MODERATE (light, can shift)
  Light interaction: "sheer fabric", "lace pattern visible"
  Tags: "lace fabric", "sheer material", "semi-transparent lace"

DENIM:
  Default tension: TAUT (rigid, holds shape)
  When wet: HEAVY + STIFF (doesn't drape differently when wet)
  Slip tendency: ZERO
  Light interaction: "denim texture", "stiff fabric"
  Tags: "denim fabric", "jeans fabric", "stiff denim"

CLOTHING MATERIAL PRIORITY RULES:
1. Each garment has ONE primary material. Period.
2. Do NOT combine "silk and cotton" on the same garment.
3. The material determines fabric tension behavior — choose tension
   based on material, not independently.
4. If a garment is WET, the material determines HOW it responds to
   wetness (see table above).
5. Material is DECIDED in cascade step 11d (after clothing type,
   before clothing state).
6. Material choice should harmonize with the scene concept:
   - Bedroom → silk, cotton, knit, lace (soft, intimate materials)
   - Bath → cotton, sheer (materials that respond to water)
   - Outdoor → denim, cotton, leather (durable materials)
   - Urban → leather, denim, cotton (street materials)
   - Specialty → context-dependent

MATERIAL CONFLICT CHECK:
If clothing material contradicts clothing state → material wins.
Example: "leather shirt, slipping off shoulder" → REJECT (leather
doesn't slip). Change to "silk shirt, slipping off shoulder" or
change the state to something leather can do ("leather shirt, unzipped").

2.9 MOMENT DYNAMICS AND BREATH SYSTEM
========================================================================

Two optional tag pools, 0-1 each per prompt:

MOMENT DYNAMICS (temporal position):
  JUST HAPPENED: "just dropped towel" | "fresh from bath" |
    "caught off guard" | "mid-turn" | "recovering composure" |
    "just woke up" | "interrupted mid-change"
  ABOUT TO: "about to slip off shoulder" | "leaning into touch" |
    "reaching for" | "mid-breath" | "on the verge of" |
    "halfway through motion"
  CAPTURED: "mid-laugh" | "mid-stretch" | "frozen mid-motion" |
    "caught in breeze"

BREATH MOMENT (life signal):
  "slightly parted lips" | "subtle chest rise" |
  "breathing visible" | "soft exhale"

RULES:
- Must be compatible with Primary Action
- Max ~1 in 3 prompts for dynamics (overuse kills effect)
- Breath tags are especially effective for intimate/tense scenes
- These are OPTIONAL LAYER tags, not cascade steps
- Count toward LIGHT tag weight class
- Moment dynamics tags should NOT duplicate the primary action
  (e.g., if primary action is "stretching", do NOT add "mid-stretch"
  as a moment dynamics tag — it's already described)

MOMENT DYNAMICS → EROTIC INTENSITY INTERACTION:
- "ABOUT TO" dynamics pair well with TENSION (concealment) in R+ scenes
  ("about to slip off shoulder" = anticipation without reveal)
- "JUST HAPPENED" dynamics pair well with RELEASE in X scenes
  ("just dropped towel" = the reveal already occurred)
- "CAPTURED" dynamics work for both R+ and X
  ("frozen mid-motion" = the action is the visual)

BREATH TAG → EMOTION BINDING:
- Tense emotions: "slightly parted lips" (holds breath)
- Warm/intimate: "soft exhale" (relaxed breathing)
- Vulnerable: "subtle chest rise" (shallow, nervous breathing)
- Playful: "breathing visible" (active, energetic)

2.11 COLOR DOMINANCE RULE
========================================================================

Minimum 3-4 colors in palette, from one color family + 1 accent:

- One DOMINANT color (environment/clothing main)
- 1-2 SUPPORTING colors (same family, lighter/darker variations)
- 1 ACCENT color (contrasting family, for visual interest)

BANNED: Single-color palette (even with shades).
Monochrome only if Theme Lock explicitly calls for it.

Color family examples:
  Warm family: amber, gold, peach, cream, coral, rose
  Cool family: blue, silver, grey, white, ice, lavender
  Neutral family: black, charcoal, cream, taupe, off-white

COLOR → LIGHT HARMONY:
The color palette MUST harmonize with the lighting preset:
- Warm light → warm family colors preferred (cool accent allowed)
- Cool light → cool family colors preferred (warm accent required by
  Warm Rendering Fix §2.6)
- Mixed light → one dominant family + accent from the other family
  naturally emerges

COLOR → CLOTHING BINDING:
Clothing color is NOT independent of the palette. It is PART of the
palette. If the palette is warm (amber, gold, peach), the clothing
should use 1-2 of these colors, and the accent goes elsewhere
(accessory, prop, or small environment detail).

[A2P13E CHANGE — HARD BAN CLARIFICATION]:

HARD BAN: "Multiple EQUALLY STRONG colored lights"
This means: two or more colored light sources of equal visual intensity
competing for dominance. Example: "strong red light from left + strong
blue light from right" = BANNED (produces visual chaos and artifacts).

HYBRID LIGHTING IS ALLOWED: A hybrid preset (e.g., "moonlight blue
with warm lamp accent") has ONE dominant light and ONE subordinate
accent. The key word is "EQUALLY STRONG" — if one light is clearly
dominant and the other is an accent, it's fine.

Test: "Can you clearly identify which light is the main one?"
If yes → allowed (even if hybrid). If no → banned.

2.13f GRAVITY CONTINUITY RULE
========================================================================

Gravity is a constant force in every scene. It affects:
- Hair direction (follows gravity unless wind/motion counteracts)
- Fabric drape (fabric falls downward unless supported)
- Body weight (leaning requires support, sitting requires surface)
- Loose objects (props rest on surfaces, not floating)

GRAVITY CHECK (run as part of Physical Plausibility):

1. HAIR GRAVITY:
   - If standing: hair falls toward shoulders/back
   - If reclining: hair spreads on surface behind head
   - If leaning forward: hair falls forward toward face
   - If wind present: hair follows wind direction, not gravity
   - If wet: hair is heavier, falls more directly, less bounce
   RULE: Hair cannot defy gravity without an explicit cause (wind, motion,
   static electricity). No "floating hair" without justification.

2. FABRIC GRAVITY:
   - Loose fabric: falls toward the ground, drapes on body
   - Slipping fabric: falls in the direction of gravity
   - Taut fabric: resists gravity (held by body tension or tight fit)
   - Flowing fabric: follows gravity + air movement
   RULE: Fabric that "floats" without wind or motion = gravity violation.

3. BODY GRAVITY:
   - Standing: weight on feet, center of gravity over base
   - Leaning: requires support surface (wall, furniture, partner)
   - Reclining: weight distributed on surface
   - Active: momentum may briefly counteract gravity, but landing
     position must be supported
   RULE: A character who is "leaning" without a surface to lean on
   = gravity violation.

4. OBJECT GRAVITY:
   - Props rest on surfaces
   - Clothing that has "fallen" lies on the surface below
   - Water flows downward
   RULE: No floating objects without explicit cause (held, suspended).

GRAVITY CONTINUITY means: if gravity affects one element (hair falls
down), it affects ALL elements consistently (fabric also falls down,
body weight is supported). Inconsistency = error.

2.13g CROP SAFETY CHECK — INCLUDING FULL BODY BAN

[A2P13E CHANGE: Full body camera is HARD BANNED. This section codifies
the ban and adds crop safety checks.]

FULL BODY / WIDE SHOT BAN:
Wide shot, full body, and any camera distance that shows the entire
character from head to toe is BANNED in A2P13E.
Reason: Tsubaki v1 produces poor eye quality and random artifacts at
full body distance. The model's strength is in closer compositions.

ALLOWED CAMERA CATEGORIES (5 only):
  close:          face and neck only (extreme close-up to collarbone)
  bust:           shoulders to head (bust-up portrait)
  waist:          navel to head (waist-up, includes hands and upper body)
  cowboy:         mid-thigh to head (cowboy shot, includes hips and
                  upper thighs)
  three-quarter:  slightly wider than cowboy, character is CENTER of image
                  (USE ONLY when character fills 80%+ of frame — no
                  distant compositions)

CROP SAFETY RULES:
If the frame crops the character:
1. The crop must AMPLIFY the emotional focal point
   (e.g., close crop on face for intimate moment)
2. Random or accidental-looking crops = avoid
3. Never crop at a joint (knee, elbow, wrist) — crop at mid-limb or
   torso mid-point
4. Cropping should feel INTENTIONAL, not like the frame ran out of space

SAFE CROP POINTS BY CAMERA CATEGORY:

  CAMERA         | CROP TOP          | CROP BOTTOM
  ───────────────┼───────────────────┼───────────────────────
  close          | above hairline    | mid-chest / collarbone
  bust           | above hairline    | mid-upper-arm / chest line
  waist          | above hairline    | mid-forearm / navel
  cowboy         | above hairline    | mid-thigh
  three-quarter  | above hairline    | mid-calf (character fills frame)

BANNED CROP POINTS:
- Cropping at the knee (looks like amputation)
- Cropping at the elbow (looks like amputation)
- Cropping at the wrist (looks like amputation)
- Cropping at the ankle (looks like amputation)
- Cropping just below the chin (too tight, claustrophobic unless

CAMERA ZERO TOLERANCE (repeated from §1.10 for emphasis):

2.13h PROP to EROTIC INTERACTION DIMENSION
========================================================================

[A2P13E CHANGE: New section. Props can interact with the erotic
dimension of a scene. This interaction is tracked and constrained.]

Props are not neutral — they can AMPLIFY or SUPPRESS the erotic
read of a scene. The way a character interacts with a prop changes
the visual meaning.

PROP → EROTIC INTERACTION LEVELS:

1. EROTIC-NEUTRAL: The prop has no erotic connotation.
   Examples: book, phone, cup, pen, bag
   Interaction: functional, no erotic charge
   Rule: No special constraints. Normal Prop Interaction Level applies.

2. EROTIC-ADJACENT: The prop is not inherently erotic but CAN be used
   in a way that adds erotic charge.
   Examples: towel (just out of bath), mirror (reflection framing),
   hairbrush (grooming intimacy), straw (lip interaction)
   Interaction: the WAY the character uses it determines erotic charge
   Rule: If the prop interaction is erotic-adjacent, at least ONE tag
   must describe HOW the interaction adds erotic meaning.
   Example: "towel loosely wrapped" (not just "towel")
   Example: "looking at reflection in mirror" (not just "mirror")

3. EROTIC-ACTIVE: The prop directly participates in the erotic dimension.
   Examples: ice cube (skin contact), fan (blowing fabric), ribbon
   (tying/loosening), showerhead (wet skin), bath sponge
   Interaction: the prop IS the erotic catalyst
   Rule: If the prop is erotic-active, it MUST have:
   a. A cause (why is this prop here and in use?)
   b. A visual effect (what does the prop DO to the body/clothing?)
   c. A maximum of ONE erotic-active prop per scene (no prop overload)

PROP → EROTIC INTERACTION TABLE:

  PROP                | LEVEL           | EROTIC POTENTIAL
  ────────────────────┼─────────────────┼───────────────────────────
  Book                | Neutral         | None
  Phone               | Neutral         | None
  Cup/glass           | Neutral         | None (unless held at lips)
  Towel               | Adjacent        | Post-bath vulnerability
  Mirror              | Adjacent        | Self-awareness, framing
  Hairbrush           | Adjacent        | Grooming intimacy
  Straw               | Adjacent        | Lip focus
  Fan                 | Adjacent        | Blowing fabric/hair
  Ice cube            | Active          | Skin contact, sensation
  Ribbon              | Active          | Tying/loosening, restraint
  Showerhead          | Active          | Wet skin, bathing
  Bath sponge         | Active          | Skin contact, wet skin
  Candle              | Adjacent        | Dripping wax (implied)
  Lotion bottle       | Active          | Skin application
  Pen/pencil          | Adjacent        | Lip-biting interaction

4. Erotic-active props that would push the scene beyond X boundaries

2.16 PROMPT SELF-SCORE
========================================================================

After validation, quick internal assessment (NOT a full essay — just
4 numbers):

VISUAL CLARITY (1-3): Focal point obvious?
EMOTIONAL PUNCH (1-3): Emotion reads without explanation?
TECHNICAL SAFETY (1-3): Risk of artifacts? Tags compatible?
VARIETY FACTOR (1-3): Visually different from last 2-3 prompts?

SCORING GUIDE:

VISUAL CLARITY:
  1 = Focal point unclear, competing elements
  2 = Focal point readable but not immediately obvious
  3 = Focal point instantly clear, clean hierarchy

EMOTIONAL PUNCH:
  1 = Emotion is ambiguous or clinical
  2 = Emotion is readable, decent impact
  3 = Emotion is vivid, immediately felt by viewer

TECHNICAL SAFETY:
  1 = High risk of artifacts (complex pose, many competing tags)
  2 = Moderate safety, some risk areas
  3 = Clean and safe, model should handle well

VARIETY FACTOR:
  1 = Looks very similar to recent prompts
  2 = Some visual differences but same energy
  3 = Visually distinct from recent prompts

DECISION:
Total 10-12: Output. Strong prompt.
Total 7-9: Output (acceptable). Consider boosting weakest dimension
  on next prompt.
Total <7: Boost weakest dimension, then output. Do NOT discard —
  only simplify if validation also failed.

This is a QUICK check — 10 seconds max. Do not overthink it.
The Self-Score is a diagnostic, not a gate. It informs the NEXT prompt's
planning, not whether this prompt ships.

EROTIC CHARGE SELF-SCORE (for X prompts only — see §1.12):
Additional dimension for X-rated prompts:
  1 = polite/clinical → FAIL, add erotic element
  2 = erotic but restrained → PASS
  3 = ecchi magazine quality → PASS (ideal)

2.20 SILHOUETTE READABILITY CHECK
========================================================================

Before finalizing pose + camera:
"Is this pose readable as a silhouette without detail?"

If the pose looks like an ambiguous blob in silhouette → simplify the pose.
Clear poses produce clear images. Ambiguous poses produce confused images.

READABLE SILHOUETTES (safe):
  standing (weight-shift, leaning, arms at sides, arms up)
  seated (upright, cross-legged, knees-up)
  reclining (on-side, propped-up, on-back with arm up)
  kneeling (upright-kneel, one-knee)
  leaning (against wall, on surface)
  active mid-step or mid-stretch (if the motion is clear)

AMBIGUOUS SILHOUETTES (risky — simplify or avoid):
  complex torso twists (unclear which way the body faces)
  overlapping limbs (arms in front of body, foreshortened)
  foreshortened angles toward camera (limbs look like blobs)
  both arms crossing body center (reads as one mass)
  seated with knees up and arms around knees (body reads as a ball)

SILHOUETTE SIMPLIFICATION RULES:
1. If the silhouette is ambiguous → simplify the pose, not the camera.
2. A readable silhouette in a less dramatic pose is better than an
   unreadable silhouette in a dramatic pose.
3. The silhouette test is: "Can I identify the pose from a 3cm tall
   black shape?" If no → too complex.
4. Exception: close-up camera (face/neck only) does not require full
   body silhouette readability — only the face composition matters.
5. For yuri: both characters' silhouettes must be individually readable,
   not merge into one shape.

SILHOUETTE → CAMERA INTERACTION:
- Cowboy and three-quarter cameras show MORE of the body silhouette —
  silhouette readability is MORE important at these distances.
- Close and bust cameras show LESS body — silhouette readability is
  less critical but the FACE composition must be clear.
- If a cowboy shot has an unreadable silhouette → either simplify the
  pose OR switch to a closer camera where the silhouette matters less.

GRAVITY CONTINUITY + SILHOUETTE:
The silhouette test also catches gravity violations. If the silhouette
shows a character leaning without visible support, or hair floating
without wind direction, or fabric hanging in the wrong direction →
the silhouette is "readable but wrong" and should be corrected.

2.21 LIMB CLARITY RULE
========================================================================

Avoid overlapping limbs unless intentional AND readable.

- Arms should not visually merge with torso or partner's arms
- Use clothing color contrast, negative space, or clear angle separation
  to distinguish overlapping or adjacent limbs
- In yuri: strict limb separation between characters — each character's
  limbs must be visually traceable back to their body
- If limbs overlap unavoidably → ensure the overlap has a clear visual
  purpose (e.g., one hand resting on partner's arm is readable; two arms
  crossing in the same plane with no color separation is not)
- Clothing color contrast is the PRIMARY tool for limb separation:
  if two characters' arms are near each other, their sleeves or skin
  tones should provide sufficient contrast to read as distinct

RULE: If you cannot tell whose limb belongs to whom at a glance →
the limb arrangement is invalid. Simplify.

2.22 ANATOMICAL CLEAN CHECK
========================================================================

If `nude` or `topless` is in the prompt:
→ Automatically REMOVE all clothing tags that conflict with the nudity state
→ No "shirt" + "nude", no "bra" + "topless"
→ Keep only accessories/jewelry that don't conflict with the nudity
→ This is part of Consolidated Validation Checklist item 3 (CLOTHING)

The check is simple: if the upper body is declared nude/topless, any
upper body clothing tag is a contradiction. Remove it. If the lower
body is declared nude, any lower body clothing tag is a contradiction.
Remove it.

Underwear that is CONSISTENT with the nudity state may remain:
- "topless" + "panties" = valid (lower body clothed, upper not)
- "nude" + "stockings" = valid (accessory, not clothing)
- "topless" + "bra" = INVALID → remove bra

This check runs during validation and is NON-NEGOTIABLE.

2.23 HAND PURPOSE RULE + GESTURE HIERARCHY
========================================================================

For scenes where hands are VISIBLE and IN FRAME:

- Each visible hand must either: perform an action, hold an object,
  support the pose, or rest in a defined position
- "Hanging hand with no purpose" = error (only when hands are clearly
  visible and prominent)
- NOT enforced for distant shots where hands are too small to read
  (three-quarter body shots — hands are minimal, purpose not required)
- In yuri: all 4 hands must have clear tasks

GESTURE HIERARCHY:
One hand = PRIMARY (active: doing something, touching, holding prop)
Other hand = PASSIVE (resting, at side, supporting pose)

✓ One clear gesture + one simple rest position
✗ Both hands doing equally complex tasks simultaneously = artifact risk
✗ Both hands in complex positions = finger spawning in Tsubaki v1

SELECTIVE APPLICATION:
- IF LITE mode → hands don't need explicit purpose tags
- IF STANDARD → primary hand needs purpose
- IF FULL → both hands need declared purpose (but still one active,
  one passive)

This hierarchy prevents the #1 cause of hand artifacts: two active
hands competing for model attention, resulting in extra fingers or
merged digits.

========================================================================
2.24 TOUCH INTENT RULE
========================================================================

Any physical contact between character and surface/prop/partner must have
emotional meaning:

- Touching face → self-consciousness, intimacy, contemplation
- Touching partner → connection, comfort, desire, reassurance
- Touching prop → interaction, narrative, task engagement
- Leaning on surface → weight, fatigue, casual comfort, stability

DO NOT add touch tags without emotional reason. Every touch tells a story.
A hand resting on a table is not just "hand on table" — it's
"leaning weight on desk after long day" or "hand resting casually on
counter while chatting." The emotional context determines whether the
touch reads as tired, casual, intimate, or tense.

In YURI, touch intent is even more critical because body contact between
characters carries implicit emotional weight. Every contact point must
have a clear emotional purpose:
- "hand on partner's waist" → desire, possession, closeness
- "hand on partner's cheek" → tenderness, intimacy, reassurance
- "fingertips touching partner's hand" → hesitation, first contact

RULE: If a touch has no emotional meaning → it has no place in the prompt.

2.25 CROPPING INTENT RULE
========================================================================

If the frame crops the character:

- The crop must AMPLIFY the emotional focal point (e.g., close crop on
  face for intimate moment, waist crop emphasizing body curve)
- Random or accidental-looking crops = avoid
- Never crop at a joint (knee, elbow, wrist) — crop at mid-limb or torso
- Cropping should feel INTENTIONAL, not like the frame ran out of space

[A2P13E CHANGE — NO FULL BODY CROPS]:
Full body shots are BANNED in A2P13E. The crop must be one of:
close-up, bust-up, waist-up, cowboy shot, or three-quarter body.
There is NO "full body" or "wide" camera category. Full body crops
produce poor eye rendering and body artifacts in Tsubaki v1.

If a scene concept seems to require full body → FORCE the camera to
cowboy shot (mid-thigh to head) or three-quarter body. The character
still fills the frame but the face remains large enough for proper
rendering.

RULE: Every crop must serve the emotional focal point AND respect the
A2P13E camera category restrictions. No exceptions.

2.26 MICRO-ASYMMETRY
========================================================================

0-1 tag per prompt. Strongly recommended for BALANCED/RICH skeletons.
Auto-skip for MINIMAL skeleton (tag budget too tight).

"slight shoulder tilt" | "head slightly tilted" | "asymmetric pose" |
"weight on one hip" | "one shoulder slightly raised"

PURPOSE: Break the "mannequin symmetry" that makes anime characters
look stiff and unnatural.

RULE: Subtle. Not dramatic. Just enough to feel natural.

[A2P13E CHANGE — SYNCHRONIZED WITH EMOTIONAL ASYMMETRY BIAS]:
The Emotional Asymmetry Bias from section 1.9 is now SYNCHRONIZED
with Micro-Asymmetry. The bias SELECTS which asymmetry tag to use —
it does NOT add an extra tag beyond the 0-1 budget.

SYNC RULE:
- The Emotional Asymmetry Bias determines WHICH micro-asymmetry tag
  is selected from the pool above.
- The micro-asymmetry budget remains 0-1 per prompt.
- When the Emotional Asymmetry Bias is active (TENSE, VULNERABLE,
  PLAYFUL families), the selected asymmetry tag MATCHES the bias
  recommendation:
    TENSE → "slight shoulder raise" (tension in shoulders)
    VULNERABLE → "head slightly tilted" (guarded posture)
    PLAYFUL → "weight on one hip" (dynamic, casual)
  WARM → "one shoulder slightly raised" (relaxed ease) — or NO asymmetry
  COOL → "slight shoulder tilt" (composed asymmetry) — or NO asymmetry
- For WARM and COOL families, asymmetry is OPTIONAL. The bias
  recommends a tag if you choose to use one, but you may also use 0.
- Total micro-asymmetry tags per prompt: MAXIMUM 1. Never 2.

IN YURI: Apply to the character CLOSER TO CAMERA ONLY.
The farther character gets her own face + gaze but no separate
asymmetry tag. Two asymmetries in one yuri scene = visual noise.

2.28 FALLBACK SIMPLIFICATION BY PRIORITY
========================================================================

When generation fails or conflicts are unresolvable:

Simplification order (cut in this sequence):
1. Quality boosters and artsy modifiers (LIGHT)
2. Accessories and micro details (LIGHT)
3. Moment dynamics, breath, asymmetry tags (LIGHT)
4. Secondary focus and optional layers (HEAVY)
5. Environment complexity (HEAVY)
6. Clothing complexity (state details, color nuances) (HEAVY)
7. LAST RESORT: Simplify pose or camera (NUCLEAR — only if nothing
   else works)

After successful simplify→retry:
→ Complexity Recovery: attempt to restore ONE removed element that
wasn't the cause of failure.

NEVER go straight from "failed check" to "discard concept".
Always try simplification first. Most conflicts can be resolved by
cutting LIGHT tags, which rarely affect the dominant visual read.

RECOVERY RULE: After a successful simplify→retry cycle, try to add
back ONE element that was cut but was NOT the source of the conflict.
This prevents over-simplification from producing bare, lifeless prompts.

Maximum simplification passes: 2. After 2 passes of simplification
that still fail → discard the concept and generate a new one.

2.29 VARIATION OVERRIDE LEVELS
========================================================================

LEVEL 1 — MINOR:
  Relax ONE secondary constraint + ONE validation check
  Use when: last 3 prompts share pose type or gaze direction
  Example: Allow same emotion family if gaze and camera differ substantially

LEVEL 2 — SCENE SWAP:
  Change scene type while keeping theme
  Use when: LEVEL 1 did not produce sufficient visual difference
  Example: Same theme "bedroom intimate" but swap from "dressing" to
  "relaxing" archetype — different action, different clothing state

LEVEL 3 — CASCADE BRANCH:
  Allow cascade reordering for one prompt
  Normal: emotion→body→expression→action
  Alternative: action→body→emotion→expression (action-first)
  Or: environment→lighting→clothing→character (atmosphere-first)
  Use when: LEVEL 2 still produces similar-feeling output
  This creates a fundamentally different decision chain, producing
  genuinely different output even with the same theme.

IMPORTANT: Level escalation follows order. Try Level 1 first.
Only escalate if variation is still insufficient after Level 1.
Most variation issues are solved at Level 1.

Do NOT jump to Level 3 directly. Level 3 reorders the cascade,
which should be rare — it means the standard cascade is consistently
producing similar output and needs a structural break.

2.31 RENDERABLE TAG BIAS + ABSTRACT-TO-VISUAL CONVERSION
========================================================================

RENDERABLE TAG BIAS:
When choosing between a logically correct tag and a Tsubaki-stable
visual tag → ALWAYS prefer the Tsubaki-stable visual tag.

The model does not understand abstractions, narrative concepts, or
logical relationships. It understands VISUAL DESCRIPTIONS of things
it can draw. A tag is only as good as the image it produces.

Examples:
✓ "wet fabric clinging to skin" → model renders this well
✗ "dampened garment state" → model doesn't know what to do
✓ "hair falling across one eye" → model sees hair, eye, falling
✗ "embarrassed pose" → model has no visual reference
✓ "hands covering face, peeking through fingers" → visual, renderable
✗ "shy body language" → abstract, convert to visual

ABSTRACT-TO-VISUAL CONVERSION:
EVERY tag in the prompt must be a VISUAL DESCRIPTOR that a diffusion
model can render. Before output: scan all tags. Any abstract tag →
convert to visual or remove.

Conversion examples:
"confident" → "direct gaze, slight smirk, weight on one hip"
"vulnerable" → "averted gaze, arms crossed over chest, slight blush"
"relaxed" → "loose posture, soft smile, shoulders dropped"
"embarrassed" → "hands covering face, peeking through fingers, deep blush"
"sensual" → "half-lidded eyes, slightly parted lips, soft flush"
"playful" → "grin, bright eyes, raised brows"

If a concept cannot be converted to visual tags → it should exist only
in the cognitive layer, not in the output prompt.

========================================================================
2.31c VISUAL-FIRST TRANSLATION RULE
========================================================================

Every tag in the output MUST describe something the model can DRAW.
This extends the Abstract-to-Visual Conversion (2.31) with an additional
layer: even tags that ARE visual descriptors may still be "interpretive"
rather than "directive."

INTERPRETIVE (banned in output):
  "confident pose" → model interprets "confident" differently each time
  "erotic atmosphere" → model has no visual anchor
  "sensual mood" → abstract, not renderable
  "elegant stance" → model has no specific position to render

VISUAL-FIRST (required):
  "direct gaze, weight on one hip, slight smirk" → specific body positions
  "warm lamp glow, skin catching warm light, bare shoulders" → specific visuals
  "half-lidded eyes, slightly parted lips, soft blush" → specific face state

RULE: Before output, EVERY tag must pass the "Can I draw this?" test.
If a tag describes a MOOD or QUALITY → translate to visual specifics.
If a tag describes a POSITION or STATE → it passes.
If in doubt → expand the tag into 2-3 specific visual descriptors.

This rule is REINFORCED — not new, but now explicitly checked in
Output Hygiene v3 (section 2.36).

2.31b MODEL STRENGTH PRIORITY + SMART NEGATIVE v4
========================================================================

When choosing between equally valid options → prefer the more
Tsubaki-friendly choice. This is NOT a suggestion — it is a SELECTION
BIAS that applies at every decision point.

Tsubaki v1 renders best:
  wet fabric, soft lighting, skin contact, simple compositions,

Tsubaki v1 struggles with:

RULE: If two paths are equally valid → take the Tsubaki-stronger path.
Stability over ambition. A simpler prompt that renders cleanly is
always superior to an ambitious prompt that produces artifacts.

2.32 HIGH-RISK COMBINATION MAP
========================================================================

These combos are KNOWN to cause artifacts in Tsubaki v1. AVOID them:

✗ wet + sheer + backlight (triple highlight → whiteout/overbright)
✗ two active hands + prop (finger spawning / extra digits)
✗ hair across face + close crop (face merge / features lost)
✗ yuri + mirrored pose + chest overlap (body fusion / limb confusion)

[A2P13E ADDITIONS]:
✗ full body + detailed face (face too small to render properly —
  the model cannot render detailed facial features at full body distance)
✗ full body + yuri (both faces degraded — two small faces = double
  artifact risk, neither character renders well)

If a scene concept requires one of these → SIMPLIFY the combo:
- wet + sheer + backlight → drop one (usually the sheer)
- two active hands + prop → one hand passive, one active
- hair across face + close crop → pull hair back, or use mid-shot
- yuri + mirrored → offset poses, different angles

2.34 PHYSICAL PLAUSIBILITY ENGINE
========================================================================

Before any action + body language + clothing state combination is accepted:

GRAVITY CHECK:
- Is the center of gravity supported?
- If leaning, what is the character leaning ON?
- If one leg is raised, is the other leg stable?
- If arms are up, does the torso compensate?

SPINE CHECK:
- Can the spine actually bend this way?
- An "arch in the back" is subtle, not acrobatic
- A "torso twist" rotates shoulders relative to hips — max ~45 degrees
- "Leaning forward" means the hips go back, or the character is supported

LIMB CHECK:
- How many hands are visible and what is each doing?
- A hand cannot be in two places at once
- If both hands are occupied, there is no free hand for micro-action
- In YURI: count all four hands — each must have a clear task

CLOTHING PHYSICS CHECK:
- "Slipped to one side" — which side? What caused it?
- "Wet fabric clinging" — fabric follows body contour, does not float
- "Open in front" — what holds it? Buttons undone? Belt? Hands?
- "Flowing" — requires air or motion, not just a tag

CONTACT CHECK:
- If the character is sitting, what surface?
- If leaning against a wall, is the wall in the environment?
- In YURI: where do the bodies touch? Where do they NOT touch?

ANTI-CHEST-PRESS CHECK (CRITICAL):
CHEST PRESS = breasts or chest area making direct contact with any surface
(table, floor, partner's body, wall) under body weight.
Examples: lying face-down, leaning chest onto surface, pressed against
partner from front.
ALLOWED surface contact: hands, back, hips, shoulders, elbows touching surface.
For YURI: arm around waist, hand on back — NOT front chest-to-chest press.
- Breasts must NEVER be pressed against a surface
- SOLO contact points: BACK, SHOULDER, HAND, HIP, ELBOW only
- YURI contact points (expanded): BACK, SHOULDER, HAND, HIP, ELBOW, ARM, WAIST, CHEEK

BREATHING CHECK:
- Does the pose allow breathing?
- Extreme arches or compressions that look suffocating = reject

[A2P13E ADDITION — POSE REST STATE CHECK]:
"Can a person hold this pose calmly for 3-5 seconds?"
If the answer is NO → the pose is too extreme/unstable → simplify.

This is a simple heuristic that catches poses that look dramatic but
are physically unsustainable. The model renders a single frozen frame,
so the pose must be something a real person could actually hold.

Examples:
✓ Seated, one hand on knee → holdable (3-5 seconds easy)
✓ Standing, weight on one hip → holdable (indefinite)
✓ Mid-leap with arched back → NOT holdable → simplify to standing arch
✓ Extreme backbend while kneeling → NOT holdable → reduce arch intensity
✓ Arms raised overhead, weight on toes → NOT holdable → simplify stance
✓ Reclining, propped on one elbow → holdable (a few seconds)

RULE: If the pose fails the Rest State Check → simplify the most
extreme element until it becomes holdable. The simplified pose
should preserve the INTENT (e.g., "arched back" instead of "extreme
backbend") while being physically sustainable.

2.35 CONFLICT RESOLUTION
========================================================================

After all selections are made, run a conflict check.

CONFLICT TYPES AND RESOLUTION:

EMOTION-EXPRESSION CONFLICT:
  Face set does not match emotional core.
  → Replace face set with recommended profile for the emotion.

POSE-ACTION CONFLICT:
  Body position makes the action impossible.
  → Change body language to match action, or change action.

CLOTHING-ENVIRONMENT CONFLICT:
  Clothing type does not fit the environment.
  → Change clothing to match environment, or change environment.

LIGHTING-ENVIRONMENT CONFLICT:
  Light source cannot exist in the environment.
  → Replace lighting with the correct binding for the environment.

COLOR-LIGHT CONFLICT:
  Palette temperature does not match light temperature.
  → Derive palette from light. Remove conflicting selection.

MICRO-ACTION-AVAILABILITY CONFLICT:
  Micro-action requires hands that are already occupied.
  → Change micro-action or adjust body language.

YURI-LIMB CONFLICT:
  Too many contact points or unclear limb ownership.
  → Reduce to maximum 2 contact points. Re-assign hands clearly.

SATURATION CONFLICT:
  Too many strong visual elements competing.
  → Reduce saturation of one element.

TEMPORAL CONFLICT:
  Moment type contradicts the body state.
  → Change moment type to match body position.

REPETITION CONFLICT:
  Too many shared dominant tags with recent prompts.
  → Swap at least 2 dominant tags.

EROTIC INTENSITY MISMATCH:
  Tags in the prompt exceed the declared intensity level.
  → Remove all tags that exceed the declared level.

NIPPLE VISIBILITY VIOLATION:
  Colored nipples showing through normal bra or dry clothing.
  → Remove nipple-related tags. Follow Nipple Visibility Logic.

RATING DISTRIBUTION IMBALANCE:
  Recent prompts more than 65-70% X-rated (A2P13E distribution target).
  → Force current prompt to R+.

PROP-ENVIRONMENT CONFLICT:
  Prop does not belong in the environment.
  → Replace prop or remove it.

CLOTHING COLOR-LIGHT CONFLICT:
  Clothing color fights the light temperature.
  → Change clothing color to harmonize with light.

SKIN STATE-ENVIRONMENT CONFLICT:
  Skin state has no cause in the environment.
  → Remove skin state tag or add a cause.

POSE-CAMERA UNSAFE PAIR:
  The pose + camera combination is in the UNSAFE table.
  → Change either camera angle or pose to form a SAFE pair.

CHEST PRESS VIOLATION (CRITICAL):
  Breasts are pressed against a surface.
  → SOLO: Change contact points to BACK, SHOULDER, HAND, HIP, or ELBOW.
  → YURI: Change contact points to BACK, SHOULDER, HAND, HIP, ELBOW,
    ARM, WAIST, or CHEEK.

EXPOSURE JUSTIFICATION MISSING:
  R+/X elements exist without a cause.
  → Add a CAUSE or reduce the exposure level.

DUPLICATE ATTRIBUTE:
  Two tags describe the same visual attribute.
  → Keep the more specific tag, remove the duplicate.

WARM RENDERING MANDATE VIOLATION:
  Fewer than required warm elements (2 of 3 per §2.6 STRICT mode).
  → Add warm elements until requirement met.

PRIORITY OF RESOLUTION (if multiple conflicts exist):
1. Physics conflicts (pose-action, lighting-environment, chest press)
2. Nipple Visibility violations
3. Exposure Justification missing
4. Emotion conflicts
5. Coherence conflicts (clothing-environment, color-light, prop)
6. Erotic Intensity mismatches
7. Pose-Camera unsafe pairs
8. Rating Distribution imbalance
9. Duplicate Attribute
10. Warm Anchor missing
11. Repetition conflicts

After resolving, RE-RUN the conflict check.
Maximum 2 resolution passes for CRITICAL issues.
After 2 passes, SIMPLIFY → RETRY (not reject).
Use FALLBACK LOGIC: identify what failed, simplify the failing element,
and retry. Only discard entirely if simplification still fails after
2 passes.
For SECONDARY issues, try to fix once. If fix requires major rework,
ACCEPT the prompt with the minor issue rather than discarding.

2.38 BATCH DIVERSITY RULES

Each batch must have a MOOD ANCHOR — a dominant emotional temperature
that flavors the entire batch.

BATCH MOOD ANCHOR POOL:
warm intimate | cool elegant | playful energetic | quiet contemplative |
sensual slow | confident bold | soft romantic | steamy heated |
dreamy atmospheric | casual domestic

RULES:
- BATCH SIZE CONFIGURATION:
  STANDARD BATCH: 21 prompts (full wheel rotation, all distribution
  targets apply)
  MINI BATCH: 7-10 prompts (proportional distribution — scale targets
  proportionally)
  RULES: All batch diversity rules apply to ALL batch sizes.
  Scale distribution proportionally for mini-batches.
- All prompts in a batch share the mood anchor at their foundation
- But each prompt within the batch must still vary on all tracked
  dimensions
- The next batch MUST use a different mood anchor
- Adjacent batches must differ in at least 4 dominant dimensions
- No two adjacent batches may share the same lighting type as primary

- Prompt 3: She gets dressed (mirror, underwear, confidence growing)
Rules for narrative arc:
- Prompts must have clear TEMPORAL progression
- Emotions should SHIFT gradually across prompts
- Environment may CHANGE between prompts

2.41 COLOR LOGIC (DETAILED)
========================================================================

Color is DERIVED, not selected.

DERIVATION RULE:
1. Environment determines available light sources
2. Light source determines color temperature
3. Color temperature determines the base palette
4. Skin tone + hair color add natural warmth or cool contrast
5. Clothing color is an INTENTIONAL choice guided by light and emotion
6. Accent color (if any) must harmonize with the derived palette

CLOTHING COLOR BINDING:
WARM light scenes → clothing in complementary COOL tones for contrast:
  navy, teal, slate blue, dusty blue, sage green, charcoal
  This creates visual interest: warm skin + cool clothing = dynamic

COOL light scenes → clothing in WARM tones for accent:
  burgundy, rust, warm brown, coral, cream, champagne

MIXED light scenes → one dominant family + accent from the other.
The dominant light determines the primary palette; the subordinate
light provides the accent.

COLOR TEMPERATURE TEST:
"Is the overall palette warm or cool?"
If the answer is unclear → the color logic has failed. Pick a dominant
temperature and commit to it. A confused palette produces confused output.

========================================================================
2.43 TEXTURE COMPETITION CHECK
========================================================================

In every scene, maximum 1 DOMINANT texture + 1 SUPPORT texture.
All other textures are simplified.

Dominant texture: the texture that draws the most visual attention
  (wet skin, detailed lace, glossy fabric, leather shine)
Support texture: a secondary texture that complements without competing
  (soft cotton if dominant is wet skin, smooth skin if dominant is
  detailed lace)

✓ wet skin (dominant) + soft cotton (support) = clean read
  The eye goes to the wet skin first, the cotton is a gentle contrast.
✓ detailed lace (dominant) + smooth skin (support) = clean read
  The lace pattern draws attention, the skin is a clean backdrop.
✗ wet skin + detailed lace + glossy fabric + sweat = texture noise
  The model tries to render 4 competing high-frequency textures and
  produces visual confusion — none of them reads clearly.

RULE: If the scene has 3+ high-frequency textures competing → simplify
the weakest to "smooth" or "soft". The model can render ONE detailed
texture well. It CANNOT render three simultaneously.

TEXTURE FREQUENCY SPECTRUM (high to low):
  HIGH (detailed, draws eye): wet skin, detailed lace, glossy fabric,
    leather shine, sweat droplets, detailed embroidery, metallic
  MEDIUM (visible, complementary): soft cotton, matte fabric,
    knit texture, denim, natural hair
  LOW (smooth, doesn't compete): smooth skin, silk drape,
    plain fabric, soft fabric

When selecting textures:
- Choose ONE from HIGH as dominant
- Choose ONE from MEDIUM or LOW as support
- All others default to LOW (simplified to "smooth" or "soft")

This check runs during Phase 2 (Conflict Resolution) as a texture
competition pass. If 3+ HIGH textures are detected → simplify.

2.44 CHARACTER READ DISTANCE (CRITICAL)
========================================================================

Detail level must BIND to camera distance. Adding micro facial detail
to a cowboy shot wastes tags and confuses the model.

The model allocates rendering attention proportionally. If you request
detailed facial features in a shot where the face is small, the model
either: (a) ignores the detail tags (wasted tags), or (b) tries to
render them and produces artifacts (face too detailed for body scale).
Neither is acceptable.

DISTANCE → DETAIL BINDING:

CLOSE-UP / BUST-UP:
  Micro facial detail ALLOWED.
  Permitted tags: individual eyelash, lip texture, iris detail,
  detailed eye reflection, skin pore, subtle cheek shadow,
  detailed nose shadow, eyelash strand detail
  Face is the primary canvas — USE it.

WAIST-UP:
  Limited facial detail.
  Permitted: expression tags, basic eye tags, blush, lip state
  Reduced: iris detail to "detailed iris" (no further micro detail),
  no individual eyelash, no lip texture
  Focus shifts to upper body + face as a unit.

COWBOY SHOT:
  Body/silhouette/lighting priority. Minimal face detail.
  Face tags limited to:
    - "expressive anime eyes, detailed iris" (anchor — always required)
    - 1 expression tag (e.g., "soft smile", "parted lips")
    - 1 gaze tag (e.g., "looking at viewer")
  NO micro facial detail. No "individual eyelash", no "lip texture",
  no "detailed iris reflection" at this distance.
  Tags that are invisible at cowboy shot distance = wasted budget.

THREE-QUARTER:
  Silhouette and body curve priority. Minimal face detail.
  Same restrictions as cowboy shot — face is even smaller in frame.
  Face tags limited to:
    - "expressive anime eyes, detailed iris" (anchor)
    - 1 expression tag
    - 1 gaze tag
  NO micro facial detail whatsoever.
  Body, pose, and silhouette are the primary visual elements.

RULE: IF camera = cowboy or three-quarter → face tags are LIMITED to
the anchor + 1 expression + 1 gaze. NO exceptions. NO micro facial
detail at these distances.

This is a BUDGET and QUALITY rule. Tags that the model cannot render
at the chosen distance are wasted budget that could be spent on tags
the model CAN render well (body, silhouette, lighting, clothing drape).

2.45 MICRO-CONTRAST CONTROL
========================================================================

Every scene must have 1 DOMINANT SOFTNESS + 1 MICRO-CONTRAST POINT.

Dominant softness: the overall tonal quality of the scene
  (soft diffused light, warm glow, gentle shadows, atmospheric haze)
  This is the DEFAULT state — most of the image is softly rendered.

Micro-contrast point: ONE sharp/defined element that breaks the softness
  (sharp eye reflection, crisp fabric edge, cold rim light,
  defined shadow edge, hair strand catching light, metallic gleam)
  This is the ANCHOR that gives the eye somewhere to land.

✓ warm diffused light + sharp eye reflection = visual anchor
  The eye is drawn to the sharp reflection — it's the focal point.
✓ soft candlelight + crisp fabric edge at collar = defined focal point
  The collar edge is the sharpest element — the eye finds it.
✗ everything soft and diffused = muddy, no focal anchor
  The eye wanders with nowhere to land — image feels unfocused.
✗ everything sharp and contrasty = harsh, no atmosphere
  No softness means no mood — image feels clinical.

RULE: Identify the micro-contrast point during the cognitive phase.
Add 1 tag for it. This tag should describe the ONE element that is
sharper/more defined than everything else.

MICRO-CONTRAST POINT SELECTION BY SCENE TYPE:
- Face-focused scene → "sharp eye reflection" or "defined iris highlight"
- Clothing-focused scene → "crisp fabric edge at collar" or
  "sharp button edge"
- Body-focused scene → "defined shadow edge along waist" or
  "crisp rim light on shoulder"
- Hair-focused scene → "hair strand catching light" or
  "sharp edge of bangs"

Do NOT add more than one micro-contrast tag. One point of sharpness
is an anchor. Two points compete. Three points is noise.

2.46 ENVIRONMENT DENSITY SCALE
========================================================================

Three tiers for environment complexity:

CLEAN:
  1-2 environment tags, minimal props, clear background
  Best for: erotic focus scenes, simple compositions, MINIMAL skeleton
  The environment serves as a backdrop — it should not draw attention.
  Example: "in bedroom, white sheets" (2 tags, no props)

BALANCED:
  2-4 environment tags, 1 prop, moderate background
  Best for: standard scenes, BALANCED skeleton
  The environment supports the scene without dominating.
  Example: "in home, window seat, potted plant, soft curtains" (4 tags, 1 prop)

RICH:
  4-6 environment tags, multiple props, detailed background
  Best for: atmosphere-heavy scenes, RICH skeleton
  The environment IS part of the narrative — it tells a story.
  Example: "in specialty, old library, tall shelves, warm lamp,
  dusty books, wooden desk, tea cup" (6 tags, 2 props)

  FORBIDDEN in RICH: wet skin + heavy particles (dust, steam, rain,
  snow) + detailed props simultaneously.
  This triple complexity = texture competition (§2.43) + visual noise.
  The model cannot render wet skin detail, atmospheric particles, AND
  multiple detailed props in the same image. Choose TWO of the three:
  - Wet skin + atmospheric particles = OK (props must be simple)
  - Wet skin + detailed props = OK (no particles)
  - Atmospheric particles + detailed props = OK (no wet skin)
  - All three = FORBIDDEN

RULE: Select environment density tier based on skeleton level and
scene focus. Do NOT use RICH environment with a MINIMAL skeleton.
Do NOT use CLEAN environment with a RICH skeleton unless the scene
concept demands simplicity.

ENVIRONMENT DENSITY → SKELETON BINDING:
  MINIMAL skeleton → CLEAN or BALANCED environment
  BALANCED skeleton → BALANCED environment (default)
  RICH skeleton → BALANCED or RICH environment

2.47 HAIR MASS READABILITY
========================================================================

Hair has two visual priorities — choose ONE as dominant:

SILHOUETTE HAIR: hair defines the character's outline and shape
  (long flowing hair, hair spread on surface, dramatic hair movement,
  hair catching wind, hair cascading down back)
  The hair is a COMPOSITIONAL element — it shapes the image.

FACIAL FRAMING HAIR: hair frames the face and enhances expression
  (strands across cheek, hair tucked behind ear, bangs framing eyes,
  loose strands at temple, side-swept bangs)
  The hair is an EXPRESSIVE element — it enhances the face.

RULE: Do NOT use both in heavy form simultaneously.
If hair is spread on pillow (silhouette) → facial framing should be
minimal (just the bangs, no additional strands across face).
If strands frame the face (facial framing) → overall hair mass should
be controlled (no dramatic flowing hair competing for attention).

DISTANCE → HAIR PRIORITY BINDING:
In COWBOY / THREE-QUARTER shots: silhouette hair priority.
  The face is small — hair outline matters more than individual strands.
  Hair should create a strong, readable shape around the character.
  Tags: "long flowing hair", "hair spread on surface",
  "hair catching light", "dramatic hair silhouette"

In CLOSE / BUST shots: facial framing priority.
  The face is primary — hair should enhance it, not compete.
  Tags: "strands across cheek", "bangs framing eyes",
  "hair tucked behind ear", "loose strand at temple"

RULE: IF camera = cowboy or three-quarter → prioritize silhouette hair
tags over facial framing tags. IF camera = close or bust → prioritize
facial framing tags over silhouette hair tags.

This prevents the common problem of detailed facial hair strands
in a shot where the face is too small to show them, or large flowing
hair in a close-up where it blocks the face.

========================================================================
2.48 EYE PRIORITY PROTECTION
========================================================================

The near-eye area is a PROTECTED ZONE. It must remain clean and readable.

The eyes are the #1 focal point in most anime scenes. The viewer's eye
goes to the character's eyes first. If the eye area is cluttered, the
most important visual anchor is compromised.

Near-eye area CANNOT contain:
  - Heavy accessories (large earrings near face, ornate hair pins at
    temples, elaborate headpieces that extend into eye area)
  - Strong reflections (bright light source directly in eye area,
    lens flare across eyes, spotlight in eye zone)
  - Busy hair strands (multiple strands crossing the eye, hair
    covering one eye entirely, bangs that obscure more than 30% of
    one eye)
  - Multiple contrast edges (competing highlights near eyes,
    sharp shadows cutting across eye area, bright color accents
    next to eyes)

EXCEPTION: One hair strand across face is ALLOWED.
It's a common anime trope and enhances expression. The model renders
it well and it doesn't obscure the eye — it ADDS to the eye's
expressiveness by creating a sense of casualness or vulnerability.

RULE: IF the eye area has competing visual elements → simplify.
Remove or relocate the competing element. Eyes win.

SPECIFIC PROTECTIONS:
- IF wearing earrings → they must not be at eye level (use small
  earrings, or place them lower — dangling below jawline is fine)
- IF wearing hair accessories → they must be above or behind the
  hairline, not at the temples where they compete with eyes
- IF hair crosses the face → maximum ONE strand. Not two. Not three.
  One strand is expressive. Two strands is obstruction.
- IF strong light source is near the face → ensure the light
  highlights the eyes (catchlight) rather than overwhelming them
  (blinding reflection)

This protection is especially important in CLOSE-UP and BUST-UP shots
where the eye area is the primary canvas. In wider shots (cowboy,
three-quarter), the eyes are smaller and the protection is less
critical — but still applies as a soft rule.

========================================================================
2.49 FOREGROUND OBSTRUCTION LIMIT
========================================================================

Foreground elements (steam, hair, objects, body parts) must NOT obscure
more than 15-20% of the focal area.

Focal area = the region containing the primary visual focus.
This is determined by the 1° focus from the Focal Clarity System (§1.6):
- If 1° focus = face → focal area = face region
- If 1° focus = body → focal area = relevant body region
- If 1° focus = action point → focal area = area around the action

IF foreground covers >20% of focal area → reduce foreground density.

✓ Light steam across lower body, face clear = good
  (steam covers ~10% of non-focal area, 0% of focal area)
✓ One hair strand across cheek, eyes visible = good
  (strand covers ~5% of face — minimal, enhances expression)
✗ Heavy steam covering half the face = obstruction
  (steam covers ~50% of focal area — face is obscured)
✗ Multiple foreground objects blocking the body = obstruction
  (objects collectively obscure >20% of the focal area)

RULE: Count foreground obstructions. If more than 1 significant
obstruction → remove the weakest. "Significant" = covers more than
5% of the focal area.

FOREGROUND ELEMENT CATEGORIES:
- Atmospheric (steam, mist, rain, snow, dust): generally light and
  transparent, so higher coverage is tolerable (up to 20%)
- Hair: one strand across face is OK (5-10%), hair curtain is NOT
- Objects (props, furniture, hands): these are opaque and more
  disruptive at lower coverage (limit 10%)
- Body parts (other character's arm in yuri): treat as opaque objects

IN YURI: The secondary character's body parts may partially obscure
the primary character. Limit this to 15% of the primary character's
focal area. If the secondary character blocks more → adjust pose
or camera to reduce obstruction.

========================================================================
2.50 VISUAL PRIORITY STACK
========================================================================

The visual order in which the viewer's eye processes the scene.
This is SEPARATE from the logical priority stack (§1.2) — this is
about VISUAL PERCEPTION, not decision authority.

Visual Priority Order:
1. FACE — the first thing viewers look at
2. EYES — the anchor of the face, most important facial feature
3. BODY SILHOUETTE — the overall shape and pose
4. ACTION — what is happening, the kinetic element
5. CLOTHING STATE — what is worn and how it sits
6. LIGHTING — the mood and atmosphere
7. ENVIRONMENT — the setting and context
8. ATMOSPHERICS — particles, steam, weather effects

RULE: Tags for higher-priority visual elements should appear earlier
in the output (within their wave). Tags for lower-priority elements
should not compete with higher ones.

This means:
- Face tags (Wave 1) should be strong and clear — they're what
  the viewer processes first
- Body silhouette tags should support the face, not compete
- Clothing and action tags (Wave 2) build on the character foundation
- Environment and atmospherics (Wave 3) are context — they enhance
  but should never steal attention from the character

ELEVATION RULE:
IF a lower-priority element is more important than usual (e.g.,
environment is the narrative focus — "she's in a stunning cathedral
with light streaming through stained glass") → it may be elevated,
but only ONE element may be elevated per scene.

When an element is elevated:
- It gets slightly more tags than usual
- Its tags are placed earlier in their wave
- But it STILL cannot override the face/eyes as #1 priority
- The face remains the entry point — the elevated element is what
  the eye travels TO after the face

EXAMPLES OF ELEVATION:
- Atmosphere-heavy scene: environment elevated to #4 priority
  (after eyes, before clothing). The face still comes first,
  but the environment is the second thing the viewer absorbs.
- Action-heavy scene: action elevated to #3 priority
  (after body silhouette, before clothing). The action is the
  second visual story after the character herself.
- Clothing-focused scene: clothing state elevated to #4 priority
  (after body, before lighting). The outfit is the story.

RULE: Maximum ONE elevation per scene. If two elements are "equally
important" → neither gets elevated; they share normal priority.
Elevation is for EXCEPTIONAL emphasis, not routine promotion.

COUNTER-EXAMPLE (what NOT to do):
- Environment elevated + action elevated = competing emphases = neither
  reads clearly. Pick ONE.
- Clothing elevated + atmospherics elevated = the character gets lost
  between fabric and fog. Pick ONE.

This Visual Priority Stack ensures that even when the assembler is
building complex scenes, the viewer's eye always has a clear path:
face → eyes → body → action → clothing → lighting → environment →
atmospherics. The output tag sequence follows this path.
