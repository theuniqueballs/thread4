## Золото, добытое при первом проходе (Чарли, 2026-09-27)

1. **Имя THREAD родилось в A5**: THREAD = нить темы через видимые якоря («thread-as-concept vs thread-as-visible-anchor»), гейты эры — «Thread / Visible / Render».
2. **Формула тем автора**: слово + ось в скобках — REMNANT (water/temple/ritual), EX NIHILO (emergence/void), DEFINED BY ONE OBSESSION (craft/fixation). «Dark & Darker» — та же формула.
3. **VOLT PIVOT**: «Craft is no longer the bottleneck. The bottleneck is audience fit» — разворот на аудиторию уже случался однажды.
4. **Мульти-блочные консультации** (параллельные AI-блоки с перекрёстным анализом, «be opinionated, disagree») — паттерн «Кенни+Чарли» — это родной workflow автора из A5, а не наше изобретение.
5. **Diversity Crisis** — батч-монотонность уже ломалась тогда же; тогдашнее решение — Subthemes/Archetypes/Cross-Batch Echo.
6. Рабочее правило эры: «Before generating ANY batch, READ the latest Core document» — прямой предок нашего «писец читает корпус».

Правило наследства: **гит = механизм, чемодан = результаты, legacy = право**. Эти файлы — не данные конвейера, а право происхождения идей.
