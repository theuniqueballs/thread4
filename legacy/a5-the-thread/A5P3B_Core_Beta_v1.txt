PHASE 5 — SYSTEM REFORMS (5 changes)
═══════════════════════════════════════════════════════════════════════

  E20. ACT ARC REFORM. Old: cool→fire→warm (predictable).
       New: ESTABLISH → CHALLENGE → OPEN.
         Act I (P1-P7): ESTABLISH — characters in their context,
                         nothing has disrupted them
         Act II (P8-P14): CHALLENGE — something has changed,
                          character responding, situation unresolved
         Act III (P15-P21): OPEN — ambiguous, not warm, not resolved,
                            not certain. Creates space for images
                            that don't resolve.
       Temperature becomes suggestion, not mandate.

  E21. CROSS-BATCH ECHO REFORM. Echo may only carry elements from
       the LEAST-USED 25% of each batch (prevents amplifying
       dominant patterns). Each recurrence changes 2+ parameters.

  E22. PALETTE AS CHARACTER ARC → PALETTE AS SCENE TEMPERATURE
       (override permitted). No longer mandates cool Act I / fire
       Act II / warm Act III. Default arc remains, but Block A can
       override if using palette family variants, modifiers, or
       character continuity demands.

  E23. DISCOMFORT QUOTA. Min 3 prompts per batch with one
       intentionally "wrong" parameter:
         - Formal clothing in survival context
         - Calm emotional state in crisis context
         - Warm palette in harsh setting
         - Resting pose in dangerous environment
       Coherence is beautiful; wrongness is memorable. Flagged in
       Pre-Flight.

  E24. RESOLUTION TYPE parameter. New per-prompt field:
         COMPLETE / INCOMPLETE / INTERRUPTED / MID-PROCESS / AMBIGUOUS
       Quotas: max 8/21 COMPLETE, min 4/21 INCOMPLETE/AMBIGUOUS,
       min 3/21 INTERRUPTED/MID-PROCESS.
       Addresses "all images feel arrived-at" monotony.

MANIFESTO — EARNED SITUATION IN EVERY DIMENSION
═══════════════════════════════════════════════════════════════════════

  Every prompt must answer: "Why does this frame exist?"

  Beauty of the body is necessary, but not sufficient.
  A character without a situation is a failure — even if the render is perfect.
  A situation without beauty is a failure — even if the idea is deep.
  The system demands both.

  Thread provides meaning.
  Wow provides surprise.
  The body provides beauty.
  The scene provides causality.

  All four are mandatory. None is decorative.

  The previous manifesto ("Earned beauty in every dimension") stands.
  This patch adds the missing fourth axis: situation.
  A beautiful character in a beautiful light with a beautiful wow moment
  but no reason for the frame to exist — is still a failure.

0.1  SCENE-CHARACTER BALANCE RULE (P1)

  Every prompt must have visible narrative tension — not only a
  beautiful character, but a reason for the frame to exist.

  TEST: "If you remove the environment and leave only her — does
  the frame die?"
    Yes → prompt succeeded (situation is integral).
    No → prompt failed (character is decorative).

  BALANCE TARGET: 50% character, 50% situation.
  This is attention, not tag count. A 30-tag prompt can fail this
  test if 28 tags describe her body and 2 describe where she is.

  ENFORCEMENT:
  - Every prompt's [11-22] block must contain at least 2 environment
    tags + 1 light-skin pair + 1 atmosphere tag.
  - Every prompt's thread anchor must be visible (GATE: Visible?).
  - Every prompt's [30] Narrative Hook must answer "why this moment?"

  DIAGNOSTIC:
  If a prompt fails Scene-Character Balance, no amount of beautiful
  rendering saves it. The image will be "a girl" — not "a moment."
  Failure mode: "Pretty. Forgettable."

0.2  CAUSAL LAYER (P2)

  Every clothing state, accessory, and flaw must have a CAUSE.

  ALLOWED CAUSES:
    wind — environment actively moving fabric
    water — rain, bath, sweat, sea, condensation
    ritual — ceremony demands this state
    haste — she dressed/undressed in urgency
    inheritance — passed down, worn by duty
    temperature — cold/hot forces the state
    sleep — she just woke / is about to sleep
    thread — the impossible element demands it

  FORBIDDEN:
    "sheer robe" without cause — decorative
    "black lace bra" without cause — catalog
    "scar on shoulder" without cause — backstory debt

  EXAMPLES:
    ✓ "sheer robe caught open by procession wind"
    ✓ "black lace bra visible through unbuttoned shirt after haste"
    ✓ "scar on shoulder from ritual branding"
    ✗ "sheer robe"
    ✗ "black lace bra"
    ✗ "scar"

  INTEGRATION:
  The cause goes immediately after the state, in the same compound
  tag. "sheer robe caught open by procession wind" = 1 compound tag.

I. CREATIVE ENGINE
═══════════════════════════════════════════════════════════════════════

SURREALIST SYNTHESIS
  Combine two unrelated elements into one image.
  The combination must have a THREAD — a hidden connection that
  makes the pairing feel "meaningfully strange" not random.

THREAD TEST
  "Why are these two things together?"
    No reason → generally avoid.
    Metaphor/resonance/emotional logic → keep.

THREAD DUALITY — concept vs anchor
  Every thread must have BOTH:
    Concept = the metaphor, the "why"
    Anchor = the physical element that makes it visible
  Concept only → find the visible element.
  Anchor only → find the metaphor.
  Test: "Does removing the anchor destroy the metaphor?"
  If no → anchor is decorative, not integrated. Fix.

THREAD TYPES (8 — all assigned to a tier now, F8)
  Tier 1 — basic:
    Medium match — impossible element shares properties with host
      (steam → fish: both flow)
    Emotional logic — environment reflects her inner state
      (city glitching → her world is breaking)

  Tier 2 — complex:
    Paradox of expectation — situation should diminish but reveals
      (rain should ruin but she owns it)
    Subject inversion — she IS the impossible element; the world is
      normal; the thread is her wrongness in it
    Temporal collision — two states of the same thing visible
      simultaneously; the boundary between them is the anchor
    Severed thread — the connection is visibly broken; two elements
      that should relate but don't; the gap IS the anchor
    Category collision — two domains share one boundary
      (circuit board / city: both are networks)
    Scale inversion — small becomes vast or vast becomes intimate
      (galaxy in a teacup: both are deep)
      [F8 fix — previously orphan, now assigned Tier 2]

  Tier 3 — meta:
    Thread comments on the act of threading itself; the image is
    about connection/disconnection as much as content.
    See §I Tier 3 Visual Dictionary for 8 worked examples.

THREAD LADDER
  Tier 1 — basic (medium match, emotional logic)
  Tier 2 — complex (paradox, inversion, temporal, severed, category
    collision, scale inversion)
  Tier 3 — meta (thread comments on threading itself)

I-B. EROTIC GRAMMAR
═══════════════════════════════════════════════════════════════════════

PHILOSOPHY
  The best ecchi has no erotic contact. It has tension.
  Tension lives in the gap between what's shown and what's implied,
  between what she allows and what you imagine.
  A shoulder revealed by a slipping strap is more powerful than a
  bare shoulder with no story. The REVEAL is the eroticism.
  The body is available. The question is whether the image earns it.

  This system does not mandate eroticism. It does not forbid it.
  It opens the possibility — and demands that the possibility be
  earned. Every exposed inch of skin is a narrative decision.
  Every clothing state is a verb. If you can't answer "why is this
  visible?" then it shouldn't be.

  The body is not decoration. The body is a surface that events
  write themselves onto. A mark on the wrist tells a story. A wet
  dress tells a story. An open collar tells a story.
  The story IS the eroticism.

  A5P2 ADDITION: If you're going to do erotica, do it WELL.
  Nipples are not dirty — they're anatomy. Black lace is not
  shameful — it's craftsmanship. Thigh-high stockings are not
  pornographic — they're a line across the thigh that says "here
  is where fabric ends and skin begins." That line is the most
  erotic centimeter in any image. Use it.

EROTIC THREAD TEST (F9 unified — returns TIER ELEVATION)

  ASK: "If she were fully clothed, would the concept survive?"

  RETURNS:
    YES (concept survives without eroticism)
      → eroticism supports, but is not the thread.
      → cap at Tier A. Subordinate eroticism to the thread.
      → if eroticism already present, it must be re-anchored to
        a non-erotic cause (wind, water, ritual, ...).

    NO (concept is dead without eroticism)
      → eroticism IS the thread.
      → Tier E candidate.
      → verify: Erotic Thread Type matches. Causal Layer present.
      → if both pass → Tier E.

  QUICK-FIX TABLE CORRESPONDENCE (was previously confused):
    "Decorative eroticism" symptom → run test.
      Test returns YES → eroticism is decorative. REMOVE or
        re-anchor to cause.
      Test returns NO → eroticism is the thread. UPGRADE to Tier E
        with proper context, or remove the eroticism entirely
        (if you don't want Tier E in this prompt).

    Q1: What does the eroticism give this frame conceptually?

    Q3: If the erotic tag is replaced by a non-erotic analog

II. COMPOSITION

GEOMETRIC ANCHOR — triangle / circle / diagonal / V-shape.

  The frame creates erotic tension through what it conceals.
  NOT close-ups of body parts. Instead:
    - Leading lines ending at concealed points
    - Fabric directing the eye toward what's covered
    - The crop as erotic statement
    - Void pressurizing the exposed element
    - The stocking line as compositional event
    - Lingerie strap as leading line

FOCAL HIERARCHY
  PRIMARY FOCUS — face OR visible thread anchor.
  SUPPORTING FOCUS — gesture, light, material, erotic detail.
  EVERYTHING ELSE — serves the above. No third interest.

V-A. COMPRESSION MODE PROTOCOL (F5)
═══════════════════════════════════════════════════════════════════════

4 modes. Each is a diagnostic lens, not a final prompt.
Connected to Failure Archive — compare full vs compressed render
to identify which tags carry actual weight.

2.  ATMOSPHERE ONLY (15 tags max)
    Keep: [1-5] + [11-15] environment/light + [31-35]

    Keep: [1-5] + [4] gaze + [30] narrative + [31-35]
    Purpose: does the emotion land without context?

    If no → emotion was situational. Add narrative hook.

  render. That tells you which layer of the original was broken.

V-I. RESOLUTION TYPE (E24)
═══════════════════════════════════════════════════════════════════════

New per-prompt parameter. Addresses "all images feel arrived-at"
monotony. Not every image needs to be a completed statement.

5 RESOLUTION TYPES:
1. COMPLETE — everything in image is where it's supposed to be,
   character has arrived. Current default.
2. INCOMPLETE — something is missing, the frame is partial.
   Character mid-reach, object mid-fall, sentence unfinished.
3. INTERRUPTED — something has just happened that stopped the
   action. Glass still falling, door mid-swing, breath mid-gasp.
4. MID-PROCESS — action ongoing, character in the middle of
   doing something. Kneading, writing, climbing, repairing.
5. AMBIGUOUS — unclear what state the image is in. Could be
   beginning or end, could be paused or moving.

QUOTAS PER BATCH (21 prompts):
  COMPLETE: max 8/21 (was effectively 21/21 — too many arrived images)
  INCOMPLETE: min 3/21
  INTERRUPTED: min 3/21
  MID-PROCESS: min 3/21
  AMBIGUOUS: min 2/21
  (some prompts may be 2 types — count primary)

PAIRS WITH:
- Dynamic Event Layer (E25): always INTERRUPTED
- Aftermath Hold (wow): always COMPLETE or AMBIGUOUS
- Anticipation Frame (wow): always INCOMPLETE or MID-PROCESS
- Tier E resolution: usually COMPLETE or AMBIGUOUS

IX-E. CROSS-BATCH ECHO (D5 — A5P3)
═══════════════════════════════════════════════════════════════════════

A motif that persists across 2-3 batches. Each batch can carry
1 motif forward (from previous) and 1 motif backward (seeding next).

This turns a series of batches into a coherent body. The viewer
recognizes the recurring element — palette accent, prop, gesture,
phrase — and feels continuity without knowing why.

CROSS-BATCH ECHO TYPES:

1. OBJECT MOTIF — same prop appearing in 2-3 batches, transformed.
   Example: bronze bowl in REMNANT P4 → bronze bowl (overturned) in
   EX NIHILO P20 (echo of "ended ritual") → bronze bowl (refilled)
   in next batch (echo of "renewal").

2. COLOR MOTIF — same accent color appearing in same act-position
   across batches.
   Example: red thread/stitch as 5% accent in Hospital Ghost palette
   across 3 batches, each time signifying "hidden inheritance."

3. GESTURE MOTIF — same silhouette gesture at same act-position.
   Example: "hand extended toward thread element" in P3 of every
   batch (echo of "reaching toward becoming").

4. PHRASE MOTIF — same narrative hook structure across batches.
   Example: "she has [verb] for [time period] — the [object] has
   started [verb]ing her" structure (used in Obsession batch).

5. PALETTE MOTIF — same palette appearing in same act-position.
   Example: Blood Stage in P9 and P21 of every batch (signature).

RULES:
- 1 motif forward + 1 motif backward per batch (max 2 total).
- Each recurrence changes 2+ parameters (act-position, palette,
  weather, time of day, camera, gesture, character).
- The motif must be INTEGRATED, not decorative. If removing it
  doesn't change the frame's meaning → it's not an echo, it's a
  repetition.

PRE-HEADER:
  CBE:{motif_id} — example: CBE:bronze-bowl or CBE:hand-extension

LOGGING:
  Each batch's Post-Flight Card logs:
    CROSS_BATCH_FORWARD: {motif_id} — received from previous batch
    CROSS_BATCH_BACKWARD: {motif_id} — seeded for next batch
  This builds a chain across batches.

EXAMPLE CHAIN (3 batches):
  Batch A: seeds "bronze bowl" motif in P20 (backward).
  Batch B: receives "bronze bowl" in P1 (forward), transforms in
    P11, seeds "single strand of hair" in P20 (backward).
  Batch C: receives "single strand of hair" in P1 (forward),
    transforms in P10, resolves in P21.

  Each batch carries 1 forward + 1 backward = continuous thread
  across the series.

APPENDIX A: GAZE × EMOTION × THREAD DECISION TREE (B9)
═══════════════════════════════════════════════════════════════════════

Use this when Gaze × Thread Matrix conflicts with Eye Contact Plot
Device (§VI-A rule 9 vs rule 10).

DECISION FLOW:

1. What is the thread type?
   → Subject Inversion → looking at viewer (she knows she's wrong)
   → Temporal Collision → eyes down (she sees both times)
   → Emotional Logic → looking past viewer (in her state)
   → Paradox of Expectation → eyes closed (doesn't flinch)
   → Severed Thread → looking at [severed element]
   → Medium Match → looking at [thread element]
   → Category Collision → looking at [thread element]
   → Scale Inversion → eyes closed (vastness internal)

2. What erotic tier (if any)?
   → Tier S, Revelation → half-lidded
   → Tier S, Concealment → eyes down
   → Tier A/E, Revelation → half-lidded
   → Tier A/E, Concealment → eyes down
   → Tier A/E, Evidence → looking past viewer
   → Tier A/E, Invitation → looking at viewer
   → Tier A/E, Transformation → eyes closed

3. What relationship (if any)?
   → admirer/caretaker/childhood friend → warm gaze variant
   → rival/superior → sharp gaze variant
   → subordinate/obsessed → intense gaze variant

4. What act?
   → Act I (default): looking at [thread element]
   → Act II (default): eyes down / looking past
   → Act III (default): looking at viewer / eyes closed

CONFLICT RESOLUTION:
  Thread type (1) > Erotic tier (2) > Relationship (3) > Act (4).
  If (1) and (2) agree → use that gaze.
  If (1) and (2) conflict → thread wins, erotic tier uses
    alternative cue (clothing state, body language) instead of gaze.
  Act (4) is softest — only applies when (1)-(3) don't dictate.
