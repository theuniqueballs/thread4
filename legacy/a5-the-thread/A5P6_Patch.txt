           skeleton: "Anime key visual. [Camera]. [Setting]. 1girl...

§1. OC SEPARATION RULE (PROBLEM 4)
═══════════════════════════════════════════════════════════════════════

  Main batch (HYBRID vN) = 21 prompts, ALL non-OC characters.
  OC prompts (Core_OC_Themed_Prompts_vN) = separate file, 3+ prompts.

§2. QUALITY-LAST PROTOCOL (PROBLEM 2)
═══════════════════════════════════════════════════════════════════════

2.1 PRINCIPLE

Tsubaki 2 prioritizes the FIRST 10-15 tokens of a prompt. Those tokens
must be CHARACTER-DESCRIPTIVE (who she is, what she looks like), not
quality-meta or camera-setting.

Quality tags ("Masterpiece, best quality, anime artstyle") go at END.

2.2 NEW PROMPT BLOCK STRUCTURE

Every prompt = 3 blocks, in order:

  ── BLOCK 1: CHARACTER (first 10-15 tokens, tag-flow) ──
  1girl, [hair descriptor], [eye descriptor], [body type], [skin],
  [expression], [clothing state], [pose verb], [setting key noun]

  Example:
  "1girl, very long black hair single white streak, red eyes
  confrontational, tall curvy womanly build large bare breasts, obsidian
  skin flushed, post-peak bliss, torn ceremonial robe open at chest
  X-tape on bare nipples, back arched on operating table, abandoned
  operating theater,"

  ── BLOCK 2: ATMOSPHERE (middle, prose with explicit descriptors) ──
  [Setting detail]. [Action/pose detail]. [Clothing detail explicit].
  [Body detail explicit]. [Light detail explicit].
  [Concept integration per DICE-D].

  ── BLOCK 3: QUALITY (end) ──
  Vivid saturated colors, rich color palette, high color contrast.
  Anime key visual, anime illustration, hand-drawn anime style,
  cel-shaded anime, painterly anime background, anime character design.
  Masterpiece, best quality, anime artstyle.

2.3 BANNED FROM BLOCK 1 (start of prompt)

  "Anime key visual." (was at start — moved to Block 3)
  "Masterpiece, best quality" (was at end — stays at end)
  Camera codes ("Wide.", "Bust framing.") — moved to Block 2
  Setting descriptions ("The abandoned operating theater.") — setting
    KEY NOUN only in Block 1, full description in Block 2

2.4 BLOCK 1 LENGTH RULE

Block 1 = 10-15 tokens (comma-separated descriptors).
Block 2 = 80-150 words (VOLT) / 120-200 words (NICHE).
Block 3 = fixed ~30 words (quality tags).

§3. DICE RANDOMIZATION SYSTEM (PROBLEM 1 + 5)
═══════════════════════════════════════════════════════════════════════

3.1 PURPOSE

Every prompt rolls 8 dice. Each die has 6-12 variants. ~26M combinations.
Ensures NO TWO PROMPTS EVER share the same structure — within batch
and across batches.

3.2 THE 8 DICE

── DICE A: OPENING STRUCTURE (10 variants) ──
A1  character-first        — "1girl, [hair], [eyes]..."
A2  pose-first             — "[Pose verb], [body state]..."
A3  setting-key-first      — "[Setting noun]. [Character]..."
A4  action-first           — "Mid-[verb], [body]..."
A5  object-first           — "[Object] on [surface]. [Character]..."
A6  sensory-first          — "[Sound/smell/texture]. [Character]..."
A7  body-part-first        — "[Body part descriptor]. [Body type]..."
A8  time-first             — "[Time of day]. [Weather]. [Character]..."
A9  breath-first           — "[Breath state]. [Character]..."
A10 absence-first          — "[Thing] is gone. [Character]..."

── DICE B: BODY DESCRIPTION ORDER (8 variants) ──
B1  hair→eyes→body→skin→marks
B2  body→skin→hair→eyes→marks
B3  skin→marks→hair→eyes→body
B4  eyes→hair→marks→body→skin
B5  marks→body→skin→eyes→hair
B6  hair→skin→body→eyes→marks
B7  body→marks→eyes→hair→skin
B8  skin→hair→eyes→body→marks

── DICE C: CLOTHING DESCRIPTION STYLE (8 variants) ──
C1  garment-first          — "She wears [garment]..."
C2  state-first            — "[Garment-state], [garment]..."
C3  reveal-first           — "[Garment] [reveals/conceals] [body part]..."
C4  fabric-first           — "[Fabric] [garment], [state]..."
C5  absence-first          — "[Body part] bare, [garment] [state]..."
C6  action-clothing        — "[Action] reveals [garment] [state]..."
C7  tactile-first          — "[Fabric] against [skin], [state]..."
C8  layer-first            — "[Layer 1] over [Layer 2], [state]..."

── DICE D: CONCEPT INTEGRATION (6 variants) ──
D1  concept-as-noun        — "The [theme] is [X]..."
D2  concept-as-action      — "She [verbs] the [theme]..."
D3  concept-as-absence     — "The [theme] is not here..."
D4  concept-as-transform   — "The [theme] has [changed] her..."
D5  concept-as-question    — "Is the [theme] [X]?"

── DICE E: LIGHT DESCRIPTION STYLE (8 variants) ──
E1  source-direction       — "[Color] glow from [off-frame location]..."
E2  effect-on-skin         — "[Color] edge on [body part]..."
E3  shadow-contrast        — "[Color] glow vs [color] shadow..."
E4  atmospheric-wash       — "[Color] wash across [space]..."
E5  light-as-action        — "[Color] light [verb]s [body part]..."
E6  light-absence          — "[Body part] in [shadow color]..."
E7  dual-light             — "[Color] from [dir 1], [color] from [dir 2]..."
E8  light-caustic          — "[Color] light [pattern] on [body part]..."

── DICE F: CLOSURE STYLE (12 variants) ──
F1  stillness              — "She does not move."
F2  incomplete-action      — "She has not yet [verb]ed."
F3  object-detail          — "The [object] is [state]."
F4  sensory-detail         — "The [sense] [verb]s."
F5  time-stretch           — "The [time-unit] [verb]s."
F6  body-detail            — "Her [body part] is [state]."
F7  absence-detail         — "The [thing] is gone."
F8  weather-detail         — "The [weather] [verb]s."
F9  question               — "Will she [verb]?"
F10 command                — "Do not [verb]."
F11 single-word            — "[Word]."
F12 dialogue-fragment      — "'...'"

── DICE G: SETTING DESCRIPTION ORDER (6 variants) ──
G1  location→time→weather
G2  weather→location→time
G3  time→weather→location
G4  location→weather→time
G5  sensory→location→time
G6  location→sensory→weather

── DICE H: POSE DESCRIPTION STYLE (8 variants) ──
H1  static-pose            — "She [pose]s."
H2  kinetic-pose           — "Mid-[verb], she [pose]s."
H3  implied-pose           — "Her [body part] [state] implies [pose]."
H4  camera-pose            — "From [angle], she [pose]s."
H5  pressure-pose          — "[Force] on [body part], she [pose]s."
H6  balance-pose           — "Weight on [body part], she [pose]s."
H7  breath-pose            — "[Breath state], she [pose]s."
H8  gaze-pose              — "Eyes [direction], she [pose]s."

3.3 DICE ROLL NOTATION

Each prompt declares DICE roll in pre-header:
  DICE:A3-B7-C2-D1-E5-F8-G2-H4

3.4 DICE RULES

  1. Every prompt rolls all 8 dice.
  2. No two prompts in same batch share the same 8-dice combo.
  3. No prompt in batch N shares 8-dice combo with any prompt in
     batches N-1, N-2, N-3, N-4, N-5 (5-batch window).
  4. Each die value used min 2× per batch (forces variety, prevents
     one-value dominance).
  5. Each die value max 4× per batch (prevents overuse).
  6. Cross-batch: track all DICE rolls in cross_batch_log.md.

3.5 DICE-DRIVEN WRITING

When writing a prompt, roll DICE first, then write body following the
rolled structure. This forces actual structural variety, not just
code-variety.

§4. PH-LESS CONSTRUCTION (PROBLEM 3)
═══════════════════════════════════════════════════════════════════════

4.1 PRINCIPLE

PH (Prompt Helper) was rewriting prompts because they were too prose-
heavy and required interpretation. Without PH, prompts must be SELF-
SUFFICIENT — Tsubaki 2 renders correctly from raw prompt.

4.2 PH-LESS RULES

  RULE 1: EXPLICIT DESCRIPTORS
    Use Tsubaki-known tags directly. Not poetic interpretation.
    WRONG: "her hair spills like liquid night"
    RIGHT: "very long black hair, straight, individual strands visible"

  RULE 2: TAG-FLOW CORE
    Block 1 (character) = comma-separated tags, not prose.
    Block 2 (atmosphere) = prose BUT with explicit descriptors embedded.
    Block 3 (quality) = tags.

  RULE 3: NO AMBIGUITY
    Every body part, clothing item, pose, light source must be explicitly
    described. PH was filling gaps; without PH, no gaps allowed.

  RULE 4: CONCRETE OVER ABSTRACT
    WRONG: "the primal is the storm"
    RIGHT: "storm-wind pushing her hair, rain on her skin, lightning
            flash freezing the moment"
    (Concept still present, but rendered as concrete visual details
    that Tsubaki can draw, not abstract noun-phrases.)

  RULE 5: ANCHOR TAGS
    Every prompt must contain these Tsubaki-anchor tags somewhere:
    - 1girl (Block 1)
    - [hair color] hair (Block 1)
    - [eye color] eyes (Block 1)
    - [skin color] skin (Block 1)
    - [clothing item] (Block 1 or 2)
    - [pose verb] (Block 1 or 2)
    - [setting noun] (Block 1 or 2)
    - looking at viewer / looking away / gaze [direction] (Block 2)

4.3 PH-LESS ANTI-PATTERNS (banned)

  - Vague emotional appeals ("the loneliness of the space")
  - Abstract concept sentences without visual anchor
  - Implicit actions ("she seems to be waiting")
  - Ambiguous body positions ("she is positioned somehow")
  - Poetic substitutions ("crown of night" for hair)

4.4 PH-LESS ALLOWED

  - Atmospheric prose (with explicit descriptors embedded)
  - Concept sentences (DICE-D, but with concrete imagery)
  - Metaphor (if grounded in visual detail)
  - Emotional tone (if expressed through body/expression, not abstract noun)
